# 色卡

第 1 步定"风格配色"、第 3 步写场景图、第 4 步写即梦时用。配色是整个画面的事:背景、衣服、手、指甲、道具、窗外、光,包只是其中一块颜色。先定一组色卡,再按它分配画面里的每样东西,最后才把包放进去。

## 怎么用
- **每条选一组**:按季节(发布日期往后 2-6 周)和这条的感觉,从下面的风格或季节里挑一组,第 1 步写进【怎么拍】的"风格配色",用户可以换。同一个窗口里用过的这条不再用。
- **先看包落在哪一层**:包的颜色要能落进这组色卡的某一层(同色系或同明度带),或者正好是它缺的那个对比色;落不进去就换一组。包有花纹时,画面别处不出现花纹。
- **五个颜色分给画面里的东西**,按 60-30-10 定面积:
  - 只拍手和包:包本身占三四成,它就是"30";座椅、墙、车门、大面积背景是"60";袖子、指甲、杯子、围巾这些小物件是"10"。**这时色卡的辅色没地方放,就把它放到大面积上**:座椅、车门、墙直接用色卡里那个有态度的颜色(森林绿、海军蓝、酒红、深棕),不要大面积都用最浅的中性色;否则画面只剩"浅色 + 包",又变成同一个色系,发素。
  - 真人出镜:背景和衣服是"60"和"30",包和一两样小物件是"10"。
  - 天空、窗外这种大面积也算进比例里,颜色写死,不让它随便出一块艳蓝。
- **深浅要齐**:画面里至少有一样东西落在最深那层、一样落在最浅那层,中间有过渡;颜色全挤在中间那一段,画面就灰、闷。
- **饱和度二选一**:要么大部分低、只有一个颜色高(点缀),要么全部都低;几个高饱和的颜色混在一起就乱。
- **冷暖七三或八二**:一边主导,另一边只做陪衬(比如暖棕的画面留一块冷灰或一角蓝天)。
- **点缀不超过一成**:同一个点缀色放在两样小东西上做呼应(围巾和指甲同色),面积加起来不超过一成。
- **自检顺序**:先定主色(60)→ 再定最深和最浅 → 再定辅色(和主色同温,或者是掺了灰的弱对比色)→ 最后定点缀(只选一个,面积最小,饱和度可以最高)→ 整组看一遍灰度整不整齐。
- **写进提示词**:每个颜色写成"东西 + 材质 + 颜色名 + HEX"(例:matte taupe-grey leather seat (#887770));再写一句这组色卡取自什么场景(例:the mood of a golden autumn forest),模型会往那个氛围去取色和打光。
- **光按本 skill 的规则**:下面各风格写的"光"只当参考;实际一律明亮、柔和、偏暖,不用斜阳、不用阴天(用户要才用)。深色系的风格做成"明亮光线下的深色调":颜色和质感照用,光不压暗。
- **显贵、显廉价**:低饱和、掺灰、深浅跨度大、点缀克制、深色够深(酒红不是大红,墨绿不是草绿)、颜色像天然材质(石、麻、木、皮、黄铜)就显贵;大面积高饱和纯色、没有深浅层次、纯白纯黑塑料感平涂就显廉价;灰里带脏黄绿、深浅全在中间、没有最深最浅就显灰暗;颜色超过三四种还一样大、没有主次就显杂乱。

## 五、按包的颜色配(真人出镜写衣服时先看这里;关系怎么选见 `styling.md` 第一节)
每种包色给 2-3 套配法和适合的背景;只取纯色,同一个窗口轮换。下面写的单品只是例子,学的是颜色和深浅关系;裤子可以换成裙子配厚丝袜、短裤配及膝袜、连衣裙,毛衣可以换成衬衫、蕾丝吊带、针织背心(`styling.md` 第一节"单品不设默认")。
- **棕、焦糖、驼**(大地色,同色系或相邻色)
  - 驼色大衣 + 巧克力粗针织 + 奶白直筒裤 + 焦糖色短靴呼应包(深浅:毛衣最深、大衣中间、裤子最浅)
  - 深咖大衣 + 奶白针织 + 深棕直筒裤 + 一处酒红点缀(围巾或唇色)
  - 背景:金黄的秋天树、褐石老街、木头和暖光的咖啡店;不配和包同色的大面积墙
- **黑**(中性色,同色系或暖中性)
  - 炭灰大衣 + 黑高领 + 黑直筒裤,靠质感分开(亮面皮包配哑光羊毛)
  - 驼色大衣 + 奶白针织 + 深色牛仔 + 黑色乐福鞋呼应包
  - 背景:奶白石头老楼、浅色街道、有暖光的橱窗
- **奶白、米、浅灰**(浅中性色,同色系)
  - 燕麦大衣 + 奶白针织 + 浅驼阔腿裤,包是最浅那一层,靠质感跳出来
  - 巧克力大衣 + 奶白高领 + 深棕裤,浅色包在深色大衣上跳出来
  - 背景:深一点的砖墙、深色木门、秋天的深色树干
- **酒红、牛血红**(深红,相邻暖色或同色系)
  - 巧克力大衣 + 驼色针织 + 深棕直筒裤,唇色或指甲呼应酒红
  - 浅一点的酒红羊绒毛衣 + 深一档的牛血红包 + 驼色大衣把两块红隔开
  - 背景:金黄的树、奶白石头房子;不配红砖墙(会糊)
- **正红、樱桃红**(亮色,中性暖色底点亮)
  - 燕麦大衣 + 奶白针织 + 浅驼阔腿裤,唇色或一点袜口呼应红
  - 背景:奶白石头老楼、金黄的树、一面常春藤绿墙(绿只在背景,不进衣服)
- **橄榄绿、墨绿**(秋冬当季,相邻色)
  - 驼色大衣 + 奶白针织 + 深棕裤 + 橄榄色围巾或鞋呼应
  - 背景:秋天的树、木头门廊
- **蓝(钴蓝、牛仔蓝)、粉、黄**(亮色)
  - 奶白、燕麦、灰的中性底,一处呼应;不配相邻的亮色
- 一身黑配亮色包、全身好几样同一种亮色:像广告,不用。
