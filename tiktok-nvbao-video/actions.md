# 动作库:手和包

第 2 步写画面、第 4 步写时间轴时从这里挑。都是参考,不是必选清单;按这只包、这个卖点、这个场景挑,也可以用库外的动作。动作大多从爆款里拆出来。

**怎么用**
- 卖点要有画面依据,但不按秒数凑动作数;对表达有帮助的才演;一个卖点换着角度演 2-3 下;动作要有变化(换手、换部位、换高度),不全是同一只手在同一个位置;不写成必选套餐。
- 每个动作标了:**稳 / 慎用**(即梦能不能做好)、**小 / 大**(说话时能不能一起做)、**双手**(自拍、对镜不能用的标出来)。
- 默认从"稳"里挑;"慎用"的(接触点多、路线长,即梦容易穿模、多手指、包变形、带子乱)一条最多一个,只给 1-2 秒、动作放小、这一格只做它;生成翻车先删它或换成稳的。
- 每个手法写"一次",关键处停半拍、约 2 秒,不来回摸、不慢动作,也不一闪而过(挠例外,本来就是来回的,见第三类)。
- 一格只写一个接触动作(手碰提带、肩带上肩、包贴到身上、别人的手碰包)。
- 讲品的手可以由拍的人引出来(第七类);她自己对着镜头表演的动作一条最多一个。

**口播和手怎么配**(说到哪类卖点,就从哪类里挑;手比这个词早半拍到位)
- 软、皮感、纹理、肌理 → 第三类(有纹理的面优先来回挠)
- 拉链、安全感、开合 → 第四类"开合和结构"
- 隔层、内袋 → 第四类"开合和结构"、第五类
- 装得下、能装什么 → 第四类"容量"
- 不勒肩、宽肩带、背着舒服 → 第五类"肩带和背法"、第二类"扶着肩带"
- 好看、廓形、背上的样子 → 第二类
- 配件、挂件 → 第五类"配件"

## 一、手怎么摆(每个动作都守)
- 给镜头看手的侧面或四分之三侧面(小指那一侧),手背、手心不平着对镜头;手掌面大致和镜头平行,指尖不朝镜头戳(会被透视压短)。
- 手指微微错开、自然弯,中指略低一点;不并死、不张开、不做鹰爪;拇指不往外翘。
- 手腕有一点小折角,不锁直,也不折成直角。
- 力度是"轻轻提着",不攥;只用两三根手指挂提带,其余放松;不按出指坑;没有青筋、指节不发白(即梦约束里写)。
- 两只手做不一样的事:一只提、一只扶,一高一低;不对称地抓着包两边。
- 手指避开包正面的 logo、锁扣和五金(专门讲它们的那一下除外)。
- 慢慢做,在手指线条最舒展的那一下停半拍。

## 二、拿包、提包、上身
- 结构感的硬包、小包:提到手腕高度,手指伸长勾着提手 → 精致、挺括|稳|小
- 大托特、软包:低位放松地提着,看得出包的大小 → 比例、能装|稳|小
- 托特:手指勾着提手和包身连接的地方提起来 → 提手结实、廓形|稳|小
- 从座位、腿上、桌上把包提起来,提到画面中间停半拍,软包自然垂下 → 廓形、软塌|稳|大(只拍手和包;真人出镜不默认放下包)
- 单手提着提带,手腕慢慢转,让包转到四分之三侧面再转回来 → 侧面、厚度|稳|小(花纹包只转到四分之三)
- 一只手提、一只手托住包底,看廓形 → 稳、看得清正面|稳|小|双手
- 挎在手肘,前臂弯起托着 → 手肘背法、比例|稳|小
- 斜挎着走几步再停下 → 上身效果|稳|大(走动按内容安排)
- 侧身让包贴着腰,看轮廓 → 背上的样子、贴身|稳|大
- 背着包半转身停住,让人看到背面的样子,再转回来 → 背上的样子|稳|大
- 手扶着肩带贴着肩,停半拍 → 背着舒服、不勒|稳|小
- 肩背、腋下夹着,侧身让包的轮廓被看见 → 背上的样子(真人出镜)|稳|大
- 开箱:包从防尘袋或盒子里露出一半,一只手捏住提手一下拿出来,停半拍 → 到货、送礼|慎用|大(包装只演商品附送的;只写一个动作,袋子不跟着变形)
- 换肩:从一边肩换到另一边 → 两边都能背|慎用|大
- 短短抱一下包,再回到斜挎 → 喜欢、软|慎用|大
- 换背法:斜挎换手提、手拎换成挂在手肘、单肩换成手提 → 一包多背|慎用|大(只换商品真有的背法;对表达有帮助才换,不强制)
- 不建议:甩包、转圈、连续慢转一圈、抛起来接住 → 改成提起来停半拍

**讲细节怎么拿**(真人出镜讲细节时包拿在手里,不背着介绍;拿法跟着正在讲的部件走)
| 讲什么 | 包怎么拿 |
|---|---|
| 包型、正面、花纹 | 一只手拎着提手提到胸前,正面朝镜头,停半拍(两条提手的包写成"一只手握住两条提手,两条提手在手上方分成两道弧,各自连到包的两侧") |
| 侧面、厚度 | 拎着提手,手腕慢慢转到四分之三侧面再转回来(所有包最多 45 度) |
| 廓形、挺不挺 | 一手提着,一手托住包底 |
| 材质、手感 | 一手拎着,另一只手指腹顺着包面抚过去、按一下看回弹,或指甲来回挠 |
| 打开、看里面 | 包挂在身上或转到身前,两只手把提手、肩带往两边拉开,或捏住包口两边掰开(见第四类"讲里面怎么打开") |
| 口袋、拉链 | 包拎在胸前,另一只手的手指沿口袋或拉链划一次 |
| 肩带、提手 | 捏住肩带把截面转给镜头;或整只包被肩带吊着提起来,看它垂下来 |
- 一只手拿,另一只手做动作,两只手不同时抓包;包在胸前到腰之间,正面朝镜头,不挡脸也不挡正面;手按第一类摆。
- 从肩上取下来、背回去各算一格的唯一接触动作,1-2 秒,动作小。

## 三、讲材质(先想这种材质卖的是什么)
- 皮面、PU、荔枝纹:指腹顺着包面抚过去;拇指按下去停半拍再松开,看皮面回弹 → 软、有韧性|稳|小
- 有纹理的面(荔枝纹、压纹、粗布):指腹顺着纹理轻轻搓一下 → 肌理|稳|小
- 来回挠:一手拎着包到胸前,另一只手的指甲在包面上快速来回挠 2-3 下,幅度小,1.5-2 秒就停,镜头稍微靠近 → 纹理、手感|稳|小(适合灯芯绒、编织、草编、荔枝纹、压纹、帆布;麂皮、绒面、漆皮不挠,会留痕或像在刮坏它;有沙沙声的材质口播可以带一句 "Listen to that")
- 挠了不留痕:指甲用力划过皮面,再用指腹一抹,表面干净 → 耐刮|慎用|小(评论或页面写了防刮、耐磨才演;一条最多一次,1-2 秒)
- 软包、填充包:轻轻揉一把,松手看它弹回来 → 软、回弹|稳|小
- 抓一把包身,看它是软的还是挺的 → 软硬|稳|小
- 捏一下包边,让封边和车线对着镜头 → 做工|稳|小
- 指节轻敲一下五金 → 五金扎实|稳|小
- 麂皮、绒面:指腹顺着毛轻轻滑过去,不按(会留痕)→ 绒感、颜色|稳|小
- 软布、涤纶、尼龙:捏起包角,松手看它垂下来;手掌在包面上轻轻抚过,布面跟着微微起伏 → 软、垂|稳|小
- 编织、草编:指尖顺着纹路走一段 → 做工、纹理|稳|小
- 绗缝、压纹:指尖顺着一格格纹路划过去,侧光把纹理照出来 → 做工|稳|小
- 亮面、漆皮、涂层帆布:把包转半个角度到光里,让光在表面流过去 → 光泽|稳|小(透明涂层写"自然的轻微反光")
- 挺括:手掌顺着包的上沿抚过去,再拍一下包身,看它立着不塌 → 挺括|稳|小
- 不建议:用力拧、扯 → 看着像要弄坏

## 四、开合和结构、容量
**讲里面怎么打开(不穿模的固定做法,所有拍法都按这个)**
原则:两只手只碰提手、肩带或包口边缘,把包口往两边拉开、掰开;不一只手提着肩带、另一只手去拉包口(即梦会把肩带画断),不一只手攥两条提手(会画成一条),手不深伸进包里扒。按包型挑一种:
- 两条提手或两条肩带的包:两只手各握一条,往两边一拉,包口跟着张开,往镜头这边歪一点|稳|小|双手
- 拉链包(单肩带、链条、小包、双肩包):不演拉拉链时,提示词写清"拉链第一帧就是拉开的,拉链头停在包口[左/右]端,全程不再拉动";两只手捏住包口两边的边缘往外分开|稳|小|双手
- 磁扣的包:自然打开,两只手轻轻把提手往两边一带,磁扣"啪"地自己分开,包口顺势张开;不用力掰|稳|小|双手
- 按扣、敞口的包:两只手捏住包口两边轻轻往外分开|稳|小|双手
- 翻盖包:可以演掀盖,物理动作写细:包挂在身上或转到身前托住;一只手的手指捏住翻盖前沿正中(有扣舌就捏扣舌),往上、往后掀,翻盖沿着包顶那条折线翻过去,搭在包背面或垂在包后;翻盖下面有磁扣的写"磁扣分开",有针扣的只写翻盖掀起、针扣跟着翻盖走、不解开;掀开以后停在掀开的样子;写一句"肩带仍连在包两侧的[哪里],翻盖整片翻过去,不变形、不断开";再按上面的做法分开包口。不演就写"翻盖第一帧已掀开,搭在包背面"|稳|小
- 包要有地方托着,两只手才空得出来:斜挎、单肩挂在身上,或者双肩包转到身前、肩带还挎在两只胳膊上;不靠一只手提着
- 第三视角:她自己用两只手拉开或掰开,拍的人不伸手开包,只把镜头凑近、从上往下看进包口约 2 秒再退回来
- **关上**(不需要关就不关,停在打开的样子收尾也行):关上单独占一格,只做这一件事;拉链写清哪只手捏拉链头、从哪一端拉回哪一端,另一只手扶在哪;翻盖写清沿包顶那条折线翻回来、整片盖在包正面,有针扣只写盖好、不写扣针扣;磁扣写两只手把包口合拢、磁扣"啪"地吸上;按扣、敞口写两只手把包口合拢;同样写一句"肩带仍连在包两侧,全程不断开"
- 打开以后停在打开的样子讲,不写"自己合上";那一格写一句"两条肩带(提手)仍连在包两侧的[哪里],全程不断开";包里只看得到两三样东西,颜色和包拉开;拉链隔层只露上沿

**开合和结构**
- 两只手撑开包口,往镜头这边倾 → 能装、内里|稳|小|双手
- 拉链从头拉到尾一次 → 拉链、安全感|慎用|小(拉链或安全感是卖点时演;拉链包默认第一帧是拉开的)
- 双头拉链合上,手掌在包上拍一下 → 安全感、收得住|慎用|小(和上一条算同一次)
- 翻开隔层给镜头看 → 隔层|稳|小
- 指一下、捏开内袋口一角 → 内袋|稳|小
- 磁吸、按扣小开合一下 → 开合方便|稳|小
- 翻盖包掀起盖子(按上面"讲里面怎么打开"的翻盖写法把物理动作写细)→ 内里|稳|小
- 抽绳收紧再放开 → 收口|慎用|小
**容量**
- 把包口往镜头这边歪一下,露出里面的东西,停半拍 → 能装|稳|小
- 手伸进包里到手腕,比一下深度 → 深、能装|稳|小
- 两手把包口撑到最宽 → 口大、好拿|稳|小|双手
- 手从里面撑一下侧壁 → 宽、能装|稳|小
- 手指数着说装了几样(两三样以内,手指一样样点里面的东西)→ 能装什么|稳|小
- 捏住里面一样东西的边,往上抬一点再放回去 → 真放得下|稳|小(不整个拿出来)
- 把一样东西(平板、书)放进包里,停半拍 → 能装|慎用|大(一镜到底时一条最多一件;装包展示跳切时一个镜头装一样,连装 4-6 样;东西颜色和包拉开)
- 装满后提起来,包照样立得住或塌得好看 → 不变形|稳|大
- What's in my bag 式往外掏:慎用,一镜到底时最多掏两样(跳切时不限),一样占一格,掏出来停一下就放回去或放在旁边|慎用|大
- 不建议:一件件掏一大堆、往里连环塞(一镜到底做不出来);手伸进贴身的死角(腋下夹着的包里、背在身后的包里)

## 五、口袋、五金、肩带和背法、配件
- 手指沿着外侧口袋的拉链划一次,停半拍 → 有口袋|稳|小
- 拍一下鼓起来的口袋 → 口袋能装|稳|小
- 把五金转到光里;指尖点一下五金 → 五金|稳|小
- 指腹沿着车线走一段 → 做工|稳|小
- 把包底翻向镜头,手指沿底边的缝线划一下或轻敲一下 → 底部、加固|稳|小|双手
- 指尖点一下商品自己的 logo → 品牌标|慎用|小(字样多、字小的包不用)
- 不建议:从口袋里掏手机、钥匙 → 改成拍一下鼓起来的口袋
**肩带和背法**
- 捏住宽肩带,把截面转给镜头看宽度 → 宽、不勒|稳|小
- 两只手各抓肩带一头往两边拉开,停半拍 → 宽肩带、结实;双提手的敞口托特也用它打开包口(见第四类"讲里面怎么打开")|稳|小|双手
- 手顺着肩带滑到调节扣,停半拍 → 能调|稳|小
- 小幅调一下肩带长短 → 能调|慎用|小(只在肩带能调时演,动作小)
**配件**(商品自带、页面写明才演)
- 碰一下包挂,让它晃一下 → 挂件|稳|小
- 把流苏拢一下转给镜头 → 流苏|稳|小
- 锁扣、按扣开合一下 → 扣子|慎用|小

## 六、讲颜色、花纹、比例
- 正面转向镜头停住 → 颜色、花纹|稳|小
- 转半个角度到窗光里,颜色被照亮 → 颜色(讲颜色那一格用自然柔光)|稳|小
- 手腕上的袖子、指甲和包同框,做颜色呼应 → 配色|稳|小
- 真人出镜:背上身朝镜头走两步再停 → 比例、整身|稳|大(全条唯一一段走动)
- 只拍手和包:包旁边放一样大小熟悉的东西(平板、水杯)当尺子 → 大小|稳|小

## 七、拍的人的手(第三视角,或固定机位有人走进画面)
次数不限,做什么按那一刻现想,也可以一次都没有;只露手和小臂;同一时刻一只手;手的样子全片不变;一格最多两件事,手伸进来算一件,碰到包就是这一格唯一的接触动作。
- 拍的人伸手要翻她的包,她顺手打开给看 → 容量、内里|稳|小
- 拍的人帮她翻开内袋 → 内袋|稳|小
- 拍的人伸手托一下包底 → 重量、廓形|稳|小
- 拍的人帮她把肩带扶正、把包正面摆向镜头 → 正面、背上的样子|稳|小
- 拍的人帮她拉一下拉链 → 拉链|慎用|小
- 拍的人伸手要拎走,她笑着拍开、把包往怀里收 → 喜欢、护着|稳|小
- 她把包递给拍的人掂一下,再接回来 → 轻(页面写了重量才说)|慎用|小(一条一次)
- 拍的人伸一根手指点一下包,她转过来展示 → 正面|稳|小
- 她展示完回头看拍的人,等对方打分 → 反应|稳|小

## 八、说话时的身体和手(真人出镜)
- 生活里的小动作(让人是活的,不讲品的时候穿插):把碎发别到耳后、把墨镜推上头顶、换一只脚站、拢一下大衣、整理一下围巾、笑着低头、边说边用空着的手比划|稳|小
- 重心在左右脚之间慢慢换;一只手搭在包上沿,另一只手做动作|稳|小
- 手落到要讲的地方那半拍垂眼看一眼,说到要点抬眼看镜头;说话时头基本稳,笑的时候可以轻轻晃、微微歪一下头;不大幅点头、转头|稳|小
- 说到重点词,上身往镜头稍微倾一下再回正|稳|小
- 把头发别到耳后、拨一下刘海|稳|小
- 说完手顺势收回:搭在包上、顺手别一下头发、扶一下包底,不僵在半空,也不写成"垂在身侧不动"|稳|小
- 上身以后的小展示(挑一个,按号卡性格):半转身看一眼侧面再转回来;低头看一眼包笑出来;把头发拨到肩后;拍一下包|稳|小
- 不讲品的句子(开头、促单):手在胸前轻轻转一下,像跟朋友聊天|稳|小
- 冷天:手缩进袖子、下巴埋进围巾、呼一口白气笑出来|稳|小

## 九、带情绪的展示(让介绍不干巴)
- 被夸以后垂眼看一眼包,嘴角压着笑|稳|小

## 十一、爆款常见组合(参考,不是公式;组合里慎用的只留一个)
- 软皮托特:轻揉一把看回弹 + 抓一把包身 + 手伸进去比深度 + 托底看廓形

## 十二、上身和收尾展示动作(只由她一个人做)
装包模板第 4 段、上身段、结尾 CTA 前后从这里挑 2-3 个顺着做,从不同的组里挑、类型不同(比如一个姿势 + 一个手势 + 一个生活收尾,不挑三个转身、看镜头这种同一类),一个接一个、每个停约 1 秒、不定格;包始终在画面里看得清(正面朝外,在胯边、腰侧或手里);同一个号连着两条不用同一组,记进变化卡。前三组的姿势参考了 ai-pose-gallery 的站姿和可爱手势(只借说法,不用它的图;性感类、双人类、跪趴躺都不收)。

**姿势(从一个动作顺到这个姿势)**
- 回眸:背着包往前走两步,回头看镜头笑,包在胯边露出正面|稳|大
- 撩发:一只手把头发拨到肩后,另一只手搭在包上沿|稳|小
- 别发:把碎发别到耳后,顺势低头看一眼包笑|稳|小
- 侧身叉腰:一只手叉腰,侧过身,让斜挎的包贴在腰侧|稳|小
- 重心落一边:重心放到一条腿上,另一边胯微微出来,手搭在包上|稳|小
- 摸后脑笑:一只手摸一下后脑勺,不好意思地笑,看一眼包|稳|小
- 扭身展臂:一只手提着包,另一只手往外一展,上身轻轻扭一下|慎用|大
- 头发被风带起:转头那一下头发被带起来,包在身侧|慎用|小
- 蹲下回头:蹲下,包落在大腿边,回头冲镜头笑|慎用|大
- 蹲着托腮:蹲着一只手托腮,包放在膝上|慎用|小

**手势(上半身,另一只手扶着包)**
- 双手捧脸:被夸或看到包时,双手捧脸笑(这时包背在身上)|稳|小
- 食指戳脸:一只手食指戳一下脸颊,另一只手扶着包|稳|小
- 脸边比 V:一只手在脸边比 V,另一只手扶包|稳|小
- 辣妹 V:手背朝外比 V|稳|小
- 脸侧比心:一只手在脸侧比心|稳|小
- 手指框:两只手比一个框,把包框在里面(只拍手和包也能用)|稳|小
- 拜托手势:双手合十,像在说"求你们去买"(CTA 时用,包背在身上)|稳|小

**上身收尾(带出生活感)**
- 对着橱窗或镜子看一眼自己,顺手调一下肩带|稳|小
- 往后退两步,让镜头拍到全身再停住|稳|大
- 把手机塞进包里拉上,推门出去|稳|大
- 拎着提手,包在胯边跟着走路轻轻晃|稳|大
- 穿上外套,再把包从外套里拎出来挎到外面|慎用|大
- 链条包把双链拉成单链,从单肩换成斜挎|慎用|小
