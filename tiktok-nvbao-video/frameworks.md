# 框架库

框架 = 这条靠什么打动人(机制)。这里只给思路和开场,不给时间线:结构跟着买点那个瞬间走(`02-script.md` 第三节)。

## 怎么用
0. **框架是工具箱,不是必走的路**:检查标准是"这段的目的达到了没有",不是"框架走对了没有";目的到了,顺序和形式都能改。
1. 先看第 1 步的四问,再挑一个最顺的机制;核对"适合",和这只包、这个拍法对不上就换。
2. 每个框架写了"四问"怎么排,照着排(没写痛点的,痛点一句带过或只演;好看型的款,痛点之后接向往);剧情按这件事真实发生的顺序写。
3. 单人拍法(固定机位、自拍、只拍手和包):[拍] 的话改成她自己说,直接对观众说、自问自答。有人拍时第一句由拍的人说的框架,单人时改成她自己引出来。
4. 同一个窗口里前面用过的框架,这条换一个。
5. 库里没合适的可以自己编,交付时标"库外新写"。
6. 用户说"换个框架":列 2-3 个不同机制,每条一行 `框架|开场一句|为什么适合`,每轮不重复。
7. 框架里的开场句只示意机制,按这只包和这两个人重新说,不整句照搬。

## 底层心法
1. **好看要被看见**:该做的动作就做,让人感受到这只包值;镜头跟着动作走(`02-script.md` 第五节)。
2. **顾虑当场打脸**:拍的人(单人时她自己)说出观众最怕的,她用一个动作回答,比说十句都可信。
3. **卖点是被引出来的**:她松弛不推销,拍的人伸手翻包、想拎走,她顺手打开给看、笑着拍开。
4. **最好看的那一下往后压一点**,留个悬念。
5. **一条只有一个场景**:别的场合、别的颜色只能说,不能演;背法按 `02-script.md` 第五节:真人出镜要有背法展示,只演商品真有的,最多换一次。

## 一、对话反差(第三视角首选)
- **F31 偶遇惊讶 + 松弛回应**:拍的人在反差场合惊讶("你背这个去健身房?"),她松弛回一句,越问越露出这只包的好。适合看着精致其实很能装、很省事的包。钩子 14、4
  四问:开头(拍的人惊讶)→ 塑品(越问越露出好)→ 促单
- **F33 误会揭晓**:拍的人误会("你带了两个包?""这是我的吧?"),她揭晓真相再当场证明。适合容量惊人、多色、看着是 A 其实是 B 的包。钩子 14、3
  四问:开头(误会)→ 塑品(揭晓 + 当场证明)→ 促单
- **F37 伸手翻包**:拍的人伸手要翻她的包,她顺手打开给看,里面装了一整天的东西。讲品的手由对方引出来,最自然。钩子 14、3
  四问:开头(伸手)→ 塑品(容量、口袋)→ 软 CTA(拍的人也要)→ 促单

## 二、顾虑打脸
- **F23 怀疑打脸**:拍的人质疑("电脑放不进去吧""装满肯定变形"),她不服,当场装给你看。适合容量、挺括、不变形是卖点的包。钩子 14、2
  四问:痛点(质疑就是顾虑)→ 塑品证据先行(当场证明)→ 塑品优势和利益 → 促单
- **F01 痛点 + 当场解决**:先说一个人人都懂的烦("东西永远沉在包底"),边说边演这只怎么解决。适合痛点一句话能说清的包。钩子 2、5
  四问:痛点 → 塑品 → 促单

## 三、效果先行
- **F22 结果先行**:第一帧就是最好看的那一下(背上身侧过去的轮廓、提起来时软包垂下的形状、正面转到光里),拍的人追问。适合廓形、颜色、比例一眼好看的包。钩子 1
  四问:塑品(最好看的效果)→ 痛点(以前那只)→ 促单
- **F35 隐藏细节**:拍的人发现一个细节("还有口袋?"),她得意地再带出第二个藏着的设计。适合口袋、隔层、可拆肩带、附赠小包(商品页写明才演)的包。钩子 3、14
  四问:塑品 1(第一个细节)→ 塑品 2(藏着的第二个)→ 促单

## 四、反转
- **F09 假抱怨反转**:她假抱怨("这包害我买不了别的包了"),正话反说塞卖点,最后揭晓"应该再买一个颜色"。单人最顺。钩子 4
  四问:痛点(假抱怨)→ 塑品(正话反说)→ 促单
- **F12 看着贵**:"That had to be expensive." 或 "My coworker asked what brand this is.",近看材质和做工。适合看着贵的包;不报价格,不说平替。钩子 6、4
  四问:塑品(看着贵)→ 证据(近看做工、五金、车线)→ 促单
- **F05 同类的坑**:点出同类包的坑("大托特一放水杯就鼓"),当场证明这只不一样。只说"别的同类",不点名。钩子 5、2
  四问:痛点(同类的坑)→ 塑品(比普通款强在哪)→ 促单

## 五、身份与场景
- **F17 身份点名**:叫出人群 + 一个痛点("每天带电脑去上班的姐妹")。适合人群明确的包(通勤、学生、带娃、健身)。钩子 7
  四问:开头 + 痛点(叫出人群)→ 塑品 → 促单
- **F29 跟拍做一件事**:带着时间和要做的事开场("十分钟后出门"),跟着她装包、出门,卖点在真实动作里发生。第三视角、只拍手和包都行。钩子 10、14
  四问:促单的痛点当开头(时间紧)→ 塑品在动作里 → 促单回扣
- **F34 一包多场合**:"One bag, three plans.",只演眼前这一个,别的场合只说。适合百搭、能上班也能约会的包。钩子 11、10
  四问:塑品(一包顶几个)→ 痛点(不用每天换包)→ 促单
- **F07 向往画面**:开场就是理想画面(秋日副驾、早晨玄关、度假出发),再讲为什么好用。适合季节氛围强的包;证明颜色那一格用自然柔光。钩子 1、13
  四问:塑品(理想画面)→ 利益 → 促单(季节、假期)

## 六、情绪与极简
- **F19 情绪爆发**:一句强情绪("Whoever put four pockets in this bag, thank you."),再说为什么这么激动。情绪饱满但只演七成,不喊。钩子 8
  四问:塑品(惊喜的设计)→ 痛点(以前没有)→ 促单
- **F28 极简**:短句,一句一个动作,说清楚就够。适合设计简单、卖点就一两个的包。钩子 2、1
  四问:痛点 → 塑品 → 促单,一句一个动作

## 动作别空转
- 每个动作都要让人看到一个好看的地方或一个卖点:提起来是为了看廓形,歪开包口是为了看容量,转到光里是为了看颜色和材质。
- 没有目的的转包、走来走去,不算。
