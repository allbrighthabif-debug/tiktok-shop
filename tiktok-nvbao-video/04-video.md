# 第 4 步:即梦视频提示词

交付:上传清单 + 一条完整的即梦 Seedance 2.5 提示词(中文,台词用原文)。整条一次生成,时长按第 2 步(默认 18 秒),声音由即梦出。交付前内部逐格自查,查出来直接改好。

## 一、上传清单
**只拍手和包**
- **@图片1 = 场景图**(第 3 步生的):写"@图片1 是视频的第一帧和场景参考:场景布局、颜色、光线、手的肤色和指甲、包的样子都严格按它"。
- **@图片2 = 包的商品图**(可选):有白底图传白底图;没有就传商品页里包最清楚、画面里没有人的那张;都带模特就不传。写"@图片2 只取这只包的花纹、颜色、五金和细节,不取背景"。演打开包、包是满格花纹或有字样时尤其要传。

**真人出镜**
- **@图片1 = 同框图**:写"@图片1 是她背着这只包的样子:衣服、身材、包和背法都按它;画面里只有她一个人"。
- **@图片2 = 人脸四视图**:写"只取她的长相、发型、发色和妆容,四个角度是同一个人;图上的分格、背景不要出现在视频里"。
- **@图片3 = 场景图**(可选);没有就把场景写成文字。
- **@图片4 = 包的商品图**(可选,同上)。

- @音频1 音色参考:用户给了才用。每个 @ 写清它负责什么;没上传的不写。
- 即梦上限:图最多 30 张;素材越少越稳。参考图分辨率不要比输出的视频高。
- **怎么测省钱**:整条用 2.5 的样片模式,先出 480P 样片抽卡,满意了再升 1080P。2.0 mini 最长 15 秒,只拿来测 5 秒左右的片段。

## 二、提示词结构(按这个顺序)
```
【素材】@图片1 ……;@图片2 ……(没有的不写)

【整体】[谁(或只有手)、包、在哪、做什么核心动作]。竖屏 9:16,时长 [N] 秒,一次生成,全程一个镜头,不切镜。视频第一帧和 @图片1 一致,画面已经在运动中,不从静止开始。iPhone 17 竖屏实拍,主摄 1x,平直透视、不变形,眼平机位,[镜头固定、画面稳定 / 轻微手持晃动 / 手持跟拍,画面跟着动作晃动];画面明亮、曝光充足,光线柔和偏暖,颜色、光线、色调严格保持 @图片1;颜色干净自然、饱和度和对比度正常,手、包和人脸光线充足;画面清晰锐利、对焦准确,包的材质纹理、车线、五金和花纹都清楚;肤色自然,不过度磨皮。
[运镜,按第三节本拍法]

【包】包严格按 @图片1[和 @图片2]。[只写 2-3 个最容易画错的:颜色和花纹、提带怎么连、五金、口袋位置、开合状态(拉链第一帧就是拉开的)]。包怎么动:[提起来时软包自然垂下 / 挺括不变形],动作小,不甩、不转圈,花纹保持不变、不弯不糊。[透明涂层写"自然的轻微反光"。]

【手 / 人物】
[只拍手和包:画面里只有她的手和小臂,不露脸;手的肤色、指甲、袖子严格按 @图片1;手指放松、微微错开,提提手只用两三根手指,轻轻提着,不攥、不按出指坑,没有青筋;左右手各干什么写清。她的声音是画外音。]
[真人出镜:长相、发型、发色、妆容严格按 @图片2;身材、衣服严格按 @图片1,不变瘦。头上:[耳饰、发饰]。她说话时看着镜头。第三视角:画外拍摄者是她的[关系],不露脸,声音在画外;画外拍摄者的[左/右]手:[肤色、指甲、袖子],第 N 秒伸进画面做什么。]

【场景】[有场景图:严格保持 @图片1(或 @图片3)的布局、颜色和光线,补背景里在动的东西。没场景图:按 `scenes/rules.md` 写底子、物件、痕迹,颜色按色卡。]色卡:[色卡名和五个颜色,各分给什么],整体是[色卡取自的那个场景]的氛围。光:[从哪来、方向、软硬、冷暖],全片不变。

【声音】整体说话状态:美区年轻女生和朋友聊天的状态,音调起伏大,语速偏快,爱笑,句尾常上扬;重音自然,不咬字、不加大音量;开头两句音调更高、语速更快、带笑;不是念稿;[真人出镜:口型自然,和每个字对上;说话时头不点、不转]。主口气:[即梦原话]。节奏紧凑:第一帧同时就是第一句台词的第一个字,前面没有空白;句与句之间停顿不超过 0.5 秒。女主:[号卡的声音]。[另一个人:画外音,不入镜,音色和女主至少两样不同。][环境声、动作声:车门、拉链、布料、钥匙]。没有音乐,没有别的人声。

【时间轴】
0-3 秒|台词(说话人):"……"(第一帧就开口)|语气|镜头|画面:先……然后……最后……
……
最后一格|……(硬 CTA:说完立刻结束)

【约束】连续:包的颜色、花纹、形状、五金、提带全程不变;[手的肤色和指甲 / 脸、发型、衣服、身材]全程不变。干净:没有字幕、文字、logo、水印,不出现参考图的分格和背景,没有多出来的手指、手和人,画面里只有这一只包。镜头:全程一个连续镜头,不切镜、不跳切。包:花纹不弯不糊不跳,字样不乱,五金不变形,提带和肩带不穿过身体和手,包里的东西不乱、不凭空增减。台词:只说以上台词,不要平读。画质:不要发灰、偏暗、低对比、偏色;不要模糊、运动模糊。[场景:从场景文件的避坑里挑 1-2 条。]
```
时间轴每格的"镜头"开头写"接着上一格",只写一个连续的镜头动作;不写"近景""特写""推近",要近就写"镜头往包的[哪里]靠近一点"(只拍手和包)或"拍摄者走过去凑到跟前"(第三视角),看清约 2 秒再回来。每件事只说一次。

## 三、运镜(按拍法,写进【整体】)
- **只拍手和包**:镜头固定在[驾驶座胸口高度 / 床边 / 桌前],看向包,画面稳定或轻微手持晃动;包在画面正中间;讲细节时镜头往那一块靠近一点,停约 2 秒再回到原来的构图;不写"手机",不画出拿镜头的手。
- **第三视角**:手持跟拍,镜头跟着她的动作走;第一帧镜头就在动;拍摄者在开场那个方向附近(正前、左前、右前),离她两到三米,不换方向、不绕着她转、不倒退着走;要看清的细节拍摄者走过去凑近,看清再退回来;拍摄者不露脸;不写"手机"。
- **固定机位**:镜头固定,在她腰到胸口高度;变化靠她走近走远、转身。
- **对镜自拍**:画面是镜子里的样子;她一只手拿手机在胸口到下巴高度,手机全程在同一只手;唯一可以写手机的拍法。
- **前置自拍**:前置镜头,手臂长度,略高往下拍,胸口以上;一只手在画外持镜头,另一只手在画面里;不写"手机"。

## 四、写法要点
- **台词**逐字照第 2 步,原文放引号里,不翻译、不改词;星号去掉,重音写进这格的语气。
- **语气**照抄 `emotion.md` 的即梦原话;只拍手和包时只写声音,不写脸。
- **手的动作写清七样**:哪只手、起点 → 路径 → 终点、快慢、停多久、眼睛看哪(真人出镜)、落在哪个词上(手比这个词早半拍开始,说到它时到位停住);同一时刻只有一只手做复杂的动作;两只手做不一样的事;一格最多两件事。
- **包的动作**:提起来、放下、歪开包口、转向光、翻底,每个写清从哪到哪、停在什么样子;转包最多转到四分之三侧面;拿起来的东西要放下。
- **开场**:第一格台词写在最前面,"第一帧就开口";写清手正在做什么、这件事接着做到下一格。
- **讲卖点的格**:她停着(或手停在包上),包的正面朝镜头,手在说的那个部位上。
- **近景补背景**:局部近景的格子补一句"背景里能看到……"(从【场景】里挑 2-3 样),不然背景会被画空。
- **光**写四样:从哪来、方向、软硬、冷暖;全片不变;不写雾、烟、光晕、逆光;讲颜色那一格写"自然柔光、只微暖",防止深棕发红、黑色发蓝。
- **口型和空白**(真人出镜):说话时不整个转身、不点头;一句台词不拆到两格;没人出声不超过 1 秒;说完最后一句立刻结束。
- 不写 "fast""电影感""高级感"这类空词;速度用"慢 / 中 / 快(慎用)"。

## 五、交付前自查(内部做,查出来直接改好)
1. 手做得出:左右手各干什么写清;拿东西的手不做别的;不横跨身体。
2. 东西有来处:每样东西出现前就交代在哪;包里露出来的东西第一帧就在包里。
3. 包:颜色、花纹、五金、提带写对;开合状态和规格卡一致(拉链包不演拉拉链);动作小;画面里只有这一只包;没有像赠品的东西。
4. 情绪对库:只用 `emotion.md` 的名字和原话。
5. 节奏算账:每格秒数够说完这格的词(每秒约 2.7 词);句间不留空白。
6. 开场:第一帧和 @图片1 一致、已经在动;第一格台词写在最前面;第 3 秒以内开始讲包。
7. 构图:包在画面正中间;讲包的格包是对比最强的东西;镜头只靠近、不写特写。
8. 促单对:软 CTA 一次、购物车只在这里说;最后一句是硬 CTA,说完立刻结束;没用 `cta.md` 禁用清单里的句子。
9. 配色:【场景】里写了色卡和"颜色、光线严格保持 @图片1"。
- 手、道具、方向、情绪、秒数这些直接改,不问。只有要改定稿台词的字词才问,而且只给一个确定改法。

## 七、生成出来有问题时(一次只改一处)
- 包变样、花纹弯了糊了 → 那几格减大动作,【包】重申"严格按 @图片1 / @图片2",多写一个最容易错的特征;上传白底商品图当 @图片2。
- 字样乱 → 凑近的格子改成拍纹理和五金,不拍字;约束重申"商品自己的字样不变,没有别的字"。
- 透明涂层变成塑料袋 → 写"自然的轻微反光";减少反光的动作。
- 肩带穿过身体、提带和手指缠在一起 → 写清带子从哪连到哪、挂在哪;那格手的动作减一个。
- 五金变形 → 写清颜色和形状;那几格不让手挡住五金。
- 包里画乱 → 包里只留两样东西,颜色和包拉开;歪开包口的时间缩短。
- 颜色、光和图不一样、画面发灰 → 【整体】和【场景】重申"颜色、光线、色调严格保持 @图片1",光写亮、写方向;删掉阴天、雾这类词。
- 窗外的景在动(车里)→ 写"车是停着的,窗外的景静止不动"。
- 冒出参考图的分格、背景 → 重申"只取长相 / 只取包"。
- 开头晚一两秒才说话 → 第一格台词挪到最前面,写"第一帧就开口";还晚,就多生成 1 秒,剪映里剪掉开头。
- 手僵、像在摆拍 → 写"手指放松、微微错开,轻轻提着";两只手做不一样的事;删掉"举起""展示"这类词,换成具体动作。
- 镜头乱动、跳镜头 → 每格"镜头"写"接着上一格";一格只写一个镜头动作;约束重申"全程一个连续镜头"。
- 画外音从人嘴里说出来(真人出镜)→ 那句标清"画外音,不入镜";两个人的音色写得更不一样。
- 结尾拖尾巴 → 最后一格写"说完立刻结束"。
- 同一个问题改 3 次不行:减大动作、去掉手入画、次卖点只留一个;再不行告诉用户这只包 AI 难做。

## 八、发布包(用户发 2 或说"出发布包"才出)
```
【发布文案】1-2 句,不超过 150 个字符,像本人随口说的,带一个痛点、结果或笑点;不写 "link in bio",不写价格;没有评论截图不写"买家说"
【标签】3-5 个:带货标签 1(#TikTokShop、#TikTokMadeMeBuyIt 轮换)+ 包型词 1-2(口播里说过的那个,如 #totebag #hobobag #crossbodybag)+ 场景或风格词 1(#workbag #fallaesthetic)+ 需求词 0-1;不用 #fyp、#viral
```

## 九、照爆款复刻(用户要求时)
- 用户自己把爆款转成灰模视频传 @视频1:写"@视频1 是动作参考:严格按 @视频1 的手和包的动作、节奏、景别和运镜;不参考它的颜色、背景和声音"。
- 时间轴按爆款的秒数分格,每格写"动作同 @视频1 的 X-Y 秒",只补台词、语气和包的外观细节。
- 镜头数照灰模;一句台词不跨两个镜头(只拍手和包的画外音可以跨)。
- 配色和场景照样按我们的色卡和场景图。

## 十、改提示词
- 讨论时只回答;用户说"改"或给了改法,只出改动的那几格;说"出完整版"才给整条。
- 改到台词回第 2 步,改到配色、构图、包的样子回第 3 步。
