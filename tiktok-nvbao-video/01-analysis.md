# 第 1 步:商品分析

卖鞋时先读 `shoes.md`,和这里冲突以它为准。

只给要看的:评论提炼(有才出)、规格卡、买点瞬间、四问、怎么拍、场景选项、待核实;第一次做再加号卡。分析过程在内部做。交完停;规格卡从用户确认起锁死。

## 一、输入
- 商品图、详情页:商品事实的唯一来源。
- 尺寸图:没有就问;用户说没有,尺寸写"缺",台词不说尺寸,只用实物比(放得下平板这类必须图上有依据)。
- 号卡:用户贴了就照用;第一次做、没有号卡,按第五节起一张。
- **活动信息**:券、折扣、买赠、包邮,有哪些、是不是长期的;用户没说就问一句,没有就写"无"。标题里的 Black Friday 这类短期活动不进台词。
- **评论截图**(可选):先出【评论提炼】,再融进下面各项,原话附在用到的地方。评论是中文译文时,台词里还原成自然的英文口语。
- 图上有几个颜色、几只包,问清卖的是哪只;多色只拍一个色。
- **老商品**:用户发回之前锁定的规格卡和四问,直接进第 2 步。

## 二、规格卡(最优先,定了就锁死)
只从商品图、详情页、尺寸图取,每项标来源(〔图〕〔文字〕〔评论〕);看不出来的写"待核实",后面不说、不画、不演。写具体:颜色写到能分辨(巧克力棕、酒红、奶白底黑格);结构写到部件和位置。
- **包型**:用美国人的叫法(tote、hobo、slouchy、crossbody、shoulder bag、underarm、bucket、satchel、baguette、barrel、clutch),软还是挺括
- **颜色**:拍哪个色(理由见【怎么拍】),其余颜色列出来
- **尺寸**:宽 × 高 × 厚(cm 和 in)
- **能装什么**:用实物说(13 寸电脑、10.9 寸平板、水杯、健身衣服、一本书),只写图上标的或评论里说的
- **背法**:手提、挎在手肘、单肩、腋下、斜挎、双肩;几条提带或肩带、各从哪里连出来;提带长短、落差,肩带能不能调、能不能拆;文字写了但图上没有的(比如斜挎带)进待核实,没确认前不演
- **背上落在她身上哪里**:按尺寸和提带落差估(包底落在腰、胯、大腿上部;挎在手肘时贴着腰侧),生图和即梦都照它;落差没写就写"估";商家有模特图时照模特图写(真人实拍的落点是对的),图不上传
- **材质和表面**:页面写的材质原话(100% polyester、vegan leather、PU、canvas、genuine leather);看上去是哑光、亮面、绒面、透明涂层;页面没写真皮就不写真皮
- **五金**:颜色(金、银、枪色、深色)和位置;没有金属五金也写清
- **内袋和隔层**:几个、在哪、拉链还是敞口
- **开合**:拉链、磁扣、按扣、翻盖锁扣、敞口;它决定能不能演打开:敞口、磁扣直接演;拉链包第一帧就是拉开的,不演拉拉链(拉链或安全感是卖点时才演一次拉到底、合上拍一下);翻盖锁扣慎用
- **重量**:页面写了才写
- **配件**:附送的小包、可拆肩带、包挂;只写商品页写明的
- **价格**:只记录,台词不说
- **活动**:没有写"无"
- 后面每一步写到包都照它;动作、造型和规格冲突时改别的,不改规格。只有用户能改规格。

## 三、四问(观众从刷到到下单要过的四道关)
先定**买家画像**:消费观念(看颜值、看实用、看性价比、图省事,选最主要的一个)、地域气候;有评论时加上谁在买(附原话)。默认主力是 25-35 岁的上班族、研究生、年轻妈妈、健身的人。只在内部用,不把观众说窄。
再判断这只包是**好看型**(默认:卖背上的样子、颜色、材质、气质)还是**功能型**(商品页的主卖点就是一个功能:能装电脑、多口袋、防泼水、轻);功能型也要说背上好看;好看型的痛点后面接向往。
**七样卖点过一遍**:包型和廓形、颜色和花纹、材质和手感、容量、背法、口袋和隔层、做工和五金。挑评论里说得最多的当核心,挑一个她没想到的当惊喜。
**再列 3-5 个买点瞬间**(交付里给出来,用户可以换):每个一行,写场景(谁、几点、在哪、在做什么)+ 看得见的麻烦 + 她心里那句;有评论时,评论里最多人说的排第一。场景优先挑包被看见、被用到的那一刻(进门放下、从包里拿东西、背上出门、上车放到副驾)。选最多人遇到、最痛、这只最能解决、即梦拍得出来的那个,写清为什么;四问都围着它。
1. **为什么要用(开头)**:一个具体的生活瞬间 + 一个看得见的麻烦 + 她心里那句话(英文一句 + 中文,可以直接当钩子)。开场动作必须是她在做的真事,不编戏剧性假剧情。再定一句**背上这只包,她是什么样的人、要去哪**,写进【怎么拍】的"风格"。
2. **痛点(好看型再接向往)**:具体场景,说得轻、生活化、能笑着说出来(拎两个包、钥匙沉在包底、包一放水杯就鼓、一身基础款没有亮点)。好看型的痛点从种草反推,向往落回痛点的那个场景,同一个时刻前后对照。
3. **为什么用这款(塑品,最重要)**:2-3 组 FABE,按核心需求、次要需求、惊喜卖点各一组;18 秒用核心 + 惊喜两组,时长更长再加一组。FABE 是查漏工具:写完查一遍有没有漏,不要求每层都写进台词:
   - **F 设计**:规格卡上的具体设计
   - **A 比普通款强在哪**:和普通款、她以前那只、别的牌子比都行(不说平替);比的那一点要有依据
   - **B 对你意味着什么**:背上、用起来的样子和感觉,带形容词,落到一个具体的气质(看着贵、松弛、利落、甜);台词里先说这一层
   - **E 怎么证明**:让它被看见的动作(`02-script.md` 第五节、`actions.md`),再加拍的人或同伴的反应、评论原话、页面上的真实数据;顺带打消最大的顾虑(太大显笨、廉价、装满变形、东西沉底)
   - 每组后面标:即梦 能做 / 慎用 / 难拍 [来源]。满格花纹、字样多、透明涂层、拉链开合标"慎用"。
4. **为什么马上买(促单,软 CTA 一次 + 硬 CTA 一次,`cta.md`)**:
   - **机制**:只写真的、长期有效的活动;没有写"无"
   - **爽点**:背上被夸、一包装下一整天、一包顶几个、看着贵(不报价格)
   - **时机**:马上要到的那件事(感恩节出门、开学、回办公室、旅行),按发布日期(`cta.md` 节点日历)
   - **替她选**:哪个色(有依据)
   - **软 CTA**:拍的人要链接或伸手要拎走、她顺口说在哪买
   - **硬 CTA**:机制 / 爽点 / 对同伴说在 TikTok Shop / 链接放下面了,四种按变化卡选(`cta.md`)

**评论怎么用**(有评论截图时)
- 全部读完,按"谁在买 / 喜欢什么 / 烦什么 / 怕什么 / 为什么现在买"归类,第一块出【评论提炼】:每类列说的人多的原话(原文 + 中文)。
- 融进上面各项;用到的地方附原话;不露用户名,不编评论。
- 包本身的性能说法(耐磨、不变形、防泼水):明显是这件商品自己的评价才当证据写进台词。

## 四、怎么拍
一句话推荐:身份 + 拍法 + 谁拍 + 场景 + 风格配色 + 氛围 + 拍哪个颜色 + 时长,各带一句理由;用户指定了哪项就照用。
- **身份**:按这只包背去哪挑(上班族、研究生、老师、健身、带娃、出差),每条可以不一样(`occasions.md`)。
- **拍法**:不设默认,按包和场景推荐一种:
  - 包要背上身才看得出大小、比例,或者包是整身唯一的亮点 → 真人出镜(第三视角、固定机位、对镜自拍)
  - 卖点在容量、口袋、材质、细节,场景是车里、床上、桌上 → 只拍手和包
  - 想要对话和笑点 → 第三视角;前置自拍只适合小包和上半身
- **真人出镜怎么上身**(选真人出镜时写一句):默认一开场包就已经在她身上(背着、拎着、挎着、夹着),直接在身上塑品;功能卖点要在桌上演(装电脑、分区、杯袋)才先在桌上或手里讲,再上身。上身段、背法展示每条都要有(`02-script.md` 第五节)。
- **谁拍**:男友、闺蜜、同事、路人,或她自己;只拍手和包写"她自己"。
- **场景 + 风格一起推荐**(【场景选项】):给 5-8 个选项,每个选项是一个场景配一种风格配色,用户回一个字母,场景和风格就一起定了。
  - 每行写:字母 + 场景 · 风格(这个风格在这个场景里的样子,比如"副驾 · 老钱风(森林绿复古车)")+ 一个具体时刻 + 为什么适合这只包(几个字)+ 偏高级 / 偏日常。
  - 风格从 `palettes.md` 的风格和季节色卡里挑,按季节(发布日期往后 2-6 周)、包的颜色落在色卡的哪一层、这只包的气质;场景和风格怎么搭看 `palettes.md` 第三节。
  - 选项要拉开:至少一个偏日常的(普通的车、普通的家、真实的生活痕迹)、至少一个偏高级的(老钱风、复古车、精致的布置);风格不重复。
  - 首推标 ★;同一个窗口用过的场景和色卡不再列;编号用字母,不用数字。
  - 用户说"日常一点""高级一点":同一个场景换偏日常或偏高级的风格,其余不动。
- **风格配色**(首推那个选项的展开):写清色卡名、五个颜色、各自分给画面里的什么东西(六三一)、点缀色放在哪两样小物件上;包落在色卡的哪一层。真人出镜时色卡只分给衣服和小东西,场景保持真实地方本来的颜色,风格靠选什么地方、什么衣服带出来。用户选了别的字母,第 2 步开头按选中的风格重写这一项。
- **氛围**:按七样各写一句:光的方向、软硬、明暗反差、色温、时间、前中后层次、道具点出的时刻。默认明亮、柔和、偏暖的白天;不用斜阳、阴天。
- **颜色**:小屏看得清;花纹选最清楚的那个色;能和场景、她的肤色拉得开。
- **时长**:最低 18 秒;按要讲的卖点多少推荐(18、20、22、25 秒这类),写一句理由,用户定。

## 五、号卡
**真人出镜的号**:用户贴角色卡就照用(结构:【角色】外观、身高体重、一句身形词、声音、语言、指甲、标志、人脸四视图有没有;身边的人;说话味道;口头禅;促单说法;常去场景;常用拍法;主风格;当季走法;习惯;上一条变化卡)。
**只拍手和包、第一次做没有号卡**:起一张简版,用户说"可以"就一直用:
- 手:肤色深浅 + 冷暖调
- 声音:音色、音高、语速、口音(即梦【声音】每条照抄)
- 语言:英语 / 英西混说 / 西语
- 说话味道:在积极、真诚的底色上选一种(甜、爱自嘲、松弛、冷幽默、飒)
- 口头禅 2-3 个、她自己的促单说法 2-3 种
- 最后一行:上一条变化卡
指甲不写进号卡,每条按包和色卡配。

## 六、提醒(有才写)
- 季节和发布时对不上;颜色和她的肤色冷暖冲突;包的大小和场景对不上(大托特去晚宴)。
- 评论里集中的差评(异味、线头、比想的小):写进来,第 2 步用诚实提醒的说法主动说,再给办法。
- 满格花纹、细格纹、字样多、透明涂层:即梦难做,第 2 步动作放小。
