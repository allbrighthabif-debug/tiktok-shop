# 第 1 步:商品分析

卖鞋时先读 `shoes.md`,和这里冲突以它为准。

只给要看的:评论原话(有才出)、规格卡、【这条怎么卖】、怎么拍、场景选项、待核实;第一次做再加号卡。选题七关、买家画像、四问、FABE、九条、部件清单、顾虑、即梦能不能做,都在内部做,不写出来;用户发"出分析"才完整列出来。交完停;规格卡从用户确认起锁死。

## 一、输入
- 商品图、详情页:商品事实的唯一来源。
- 尺寸图:没有就问;用户说没有,尺寸写"缺",台词不说尺寸,只用实物比(放得下平板这类必须图上有依据)。
- 号卡:用户贴了就照用;第一次做、没有号卡,按第五节起一张。
- **活动信息**:券、折扣、买赠、包邮,有哪些、是不是长期的;用户没说就问一句,没有就写"无"。标题里的 Black Friday 这类短期活动不进台词。
- **评论**(可选,截图或用户粘贴的原话都算,按同一套处理):先出【评论原话】,再融进下面各项,原话附在用到的地方。评论是中文译文时,台词里还原成自然的英文口语。
- 图上有几个颜色、几只包,问清卖的是哪只;多色只拍一个色。
- **老商品**:用户发回之前锁定的规格卡和四问,直接进第 2 步。

## 二、规格卡(最优先,定了就锁死)
只从商品图、详情页、尺寸图取,每项标来源(〔图〕〔文字〕〔评论〕);看不出来的写"待核实",后面不说、不画、不演。写具体:颜色写到能分辨(巧克力棕、酒红、奶白底黑格);结构写到部件和位置。
- **包型**:用美国人的叫法(tote、hobo、slouchy、crossbody、shoulder bag、underarm、bucket、satchel、baguette、barrel、clutch),软还是挺括
- **颜色**:拍哪个色(理由见【怎么拍】),其余颜色列出来
- **尺寸**:宽 × 高 × 厚(cm 和 in)
- **能装什么**:用实物说(13 寸电脑、10.9 寸平板、水杯、健身衣服、一本书),只写图上标的或评论里说的
- **背法**:手提、挎在手肘、单肩、腋下、斜挎、双肩;几条提带或肩带、各从哪里连出来;提带长短、落差,肩带能不能调、能不能拆;文字写了但图上没有的(比如斜挎带)进待核实,没确认前不演
- **背上落在她身上哪里**:按尺寸和提带落差估(包底落在腰、胯、大腿上部;挎在手肘时贴着腰侧),生图和即梦都照它;落差没写就写"估";商家有模特图时照模特图写(真人实拍的落点是对的),图不上传
- **材质和表面**:页面写的材质原话(100% polyester、vegan leather、PU、canvas、genuine leather);看上去是哑光、亮面、绒面、透明涂层;页面没写真皮就不写真皮
- **五金**:颜色(金、银、枪色、深色)和位置;没有金属五金也写清
- **内袋和隔层**:几个、在哪、拉链还是敞口
- **开合**:拉链、磁扣、按扣、翻盖锁扣、敞口;它决定能不能演打开:敞口、磁扣直接演;拉链包第一帧就是拉开的,不演拉拉链(拉链或安全感是卖点时才演一次拉到底、合上拍一下);翻盖锁扣慎用
- **重量**:页面写了才写
- **配件**:附送的小包、可拆肩带、包挂;只写商品页写明的
- **价格**:只记录,台词不说
- **活动**:没有写"无"
- **锚点图**:从商家图里挑最清楚、正面、没有人、看得清整只包的那张当即梦的 @图片1,写"用商品图第 N 张";不重绘。只有两种情况才出白底重绘提示词(`03-image.md` 第三节):商家图全是模特图或背景乱到看不清包;或者生成过一次包画错了。
- **容易被看错的地方**(写进第 4 步【包】,用一两句话钉住):材质和表面(哑光还是亮面、反光有多少;商品图有大块反光时尤其要写,不然会被画成塑料)、包身和带子是不是同一种料、带子和提手一共几条、商品自己的字样在哪;不重复描述花纹和字样的细节。
- 后面每一步写到包都照它;动作、造型和规格冲突时改别的,不改规格。只有用户能改规格。

## 三、选题和怎么卖(全在内部做,交付只给【这条怎么卖】)
TikTok 是内容找人:刷到的人本来没打算买包,选题决定她停不停下来,所以先定选题,四问和塑品都围着它。

**选题从哪来**(按优先级):评论原话里的处境("I use it for nursing school")→ 心动的四条(好看、显贵、被看见、当季)→ 这只包最强的真实卖点(规格卡)→ 时间节点(发布日期往后 2-6 周的节日、换季、开学、出行,`cta.md` 节点日历)→ 搭配和气质(为了配哪件衣服、想变成什么样,`styling.md`)。买家的顾虑放进塑品里打消,不单独当选题。
**先写用户会说的 3 句话**:是处境,不是卖点(I'm so done carrying two bags / every bag I own looks wrong with this coat);有评论先从评论原话里找,找不到才自己写;挑最具体的一句当开头的底子。
**按卖点选打法**:功能型的包(容量、分区、轻)→ 开头埋一个能当场验证的问题(电脑放不放得下、装满了会不会塌),前 3 秒就开始验证;好看型的包 → 闺蜜聊天,靠心动和情绪;看着贵的包 → 靠"看起来比实际贵"留悬念,不提任何品牌、不说平替。
**包常用的选题类型**(同一个窗口轮换;大容量、通勤上学、一个包撑一天是真实视频里出现最多、播放最高的,功能型包优先用):一个包撑一整天;为了配某件衣服而买;被看见(路人或朋友问哪买的);新的开始(新工作、开学、搬家);去一个场合(旅行、节日、约会、周末);换季第一只包;告别旧包(以前背两个、以前总翻包);到货开箱("finally came");送礼(送妈妈、送闺蜜、节日,11-12 月是旺季)。开箱写法见 `02-script.md` 第八节。
**每个选题内部想三层**:功能(能装电脑)→ 场景(一个包从早背到晚)→ 母题(把日子过得有条理)。母题用轻的、积极的:有条理、有自己的样子、被认真对待、新的开始、对自己好一点;不用沉重的、不制造焦虑;台词不把母题念出来。开头埋一个问题,塑品里解开一半、上身解开一半,视频里一定解开。
**七关**(内部想 5 个,过不了就换):
1. 停留:能写成一句她会说的话,带具体的时间、地点或东西,让人觉得"这就是我"
2. 心动而不是辩解:指向"我想要",不是"它不差"(只证明不廉价、不难搭的选题不当主线)
3. 破圈:25-35 岁的女生大多遇到过,不是一小群人的事
4. 包是答案:这个处境由这只包最强的真实卖点回答,这只包的各个部件都能顺着它说出来
5. 能拍:一个地方、一条线就能拍完,即梦做得出来
6. 有下单理由:带着时机、身份或结果
7. 不重复:和这个窗口里前几条的选题不一样
交付只给过关的 3 个:★ 推荐一个,两个备选,每个一行;三个里至少一个是出人意料的(换视角:路人、男朋友、妈妈、同事;反差:很贵气的包配很日常的糗事;借时节;从一个具体的小瞬间切入;一句反常识的话开头)。

**女生买包看重的九条**(内部逐条写这只包的答案,缺的写待核实):
- 心动:① 好看,而且让我显得好看(颜色、廓形、和她的衣服搭)② 看着贵(材质、五金、车线)③ 被看见(被夸、被问哪买的、像"那种女生")④ 当季、正流行(`trends-fw2026.md`)
- 放心:⑤ 装得下我的一天 ⑥ 舒服(轻、肩带不勒)⑦ 一包多用(场合、背法)⑧ 耐用(不掉皮、不变形、装满立得住)
- ⑨ 值这个价:交给商品卡;台词只说"值"不说价(`cta.md` 第 8 条)
开头和选题从心动里找;塑品当场证明放心;前面把"看着贵"立住,价格留给商品卡。

**塑品按部件过一遍**(这只包身上真有的每一项都要讲到或拍到,没有的跳过;嘴上说到、手上演到,不只交给画面;顺序和串法见 `02-script.md` 第五节):
1. 包型和廓形:什么包、多大、软还是挺
2. 颜色:什么色,配上她的衣服什么效果
3. 材质和纹理:什么料子、什么纹理,摸上去怎么样,最好打个比方
4. 设计亮点:蝴蝶结、绗缝、翻盖、锁扣、编织、口袋造型、独特的轮廓,这只包和别的包不一样的地方
5. 肩带和提手:几条、多宽、多长、能不能调、能不能拆,背着勒不勒肩(有依据才说)
6. 里面:能装什么(具体的东西,一边说一边装,只说规格卡、评论里有依据的)、隔层、内袋、拉链
7. 做工:车线、五金、封边、包底,装满了立不立得住
8. 上身效果和背法:这只包真有的背法 → 落在身上哪里 → 背上以后整身怎么变 → 最后才是气质词
9. 搭配:她身上那件具体的衣服,配上包以后看得见的变化
10. 顾虑:打消一个(怕廉价、怕软塌、怕太大、怕勒肩)
- 深浅:最打动人的 1-2 项讲透,配 2-3 个动作;其余每项一句话加一个动作,或者一个动作带出两项(手顺着肩带滑下去,同时说宽度和颜色)。内容多,时长常要 22-25 秒。
- **可以主动说一个真实的小缺点**:必须来自评论或规格卡(五金偏轻、拉链有点涩、装满了有点勒肩),不碰核心卖点,说完马上接"还是值得"或"还会再买"。没有依据就不说,不编。
- 身体参照(可选):包的大小是卖点或顾虑时(大托特怕显笨、小包怕装不下),说一句她多高、包落在哪(按角色卡的身高和尺寸图);其他时候交给画面。只说身高,不说体重身材。

**四问**(四个目的,内部对一遍):开头让她停下来;痛点让她认出自己;塑品让她觉得好、觉得值,并且信她;促单让她现在就买,而且觉得价格比心里的低。
- 痛点:具体场景,说得轻、生活化、能笑着说出来(拎两个包、钥匙沉在包底、包一放水杯就鼓、一身基础款没有亮点)。
- 塑品查漏:FABE(F 设计 → A 比普通款强在哪,有依据,不说平替 → B 对你意味着什么,说成生活后果 → E 怎么证明:动作、拍的人的反应、评论原话)。每个卖点标即梦 能做 / 慎用 / 难拍;满格花纹、字样多、透明涂层、拉链开合是"慎用"。
- 促单:机制(只写真的、长期有效的活动)、爽点、时机(节点日历)、替她选哪个色(有依据)、软 CTA、硬 CTA 四种(`cta.md`)。

**评论怎么用**(截图或粘贴的原话)
- 全部读完,内部按"谁在买 / 喜欢什么 / 烦什么 / 怕什么 / 为什么现在买"归类;交付只出【评论原话】3-5 句:说的人最多、能直接当台词的(原文 + 中文)。
- 选题的"用户会说的 3 句话"先从这里找;口播优先用评论原话;不露用户名,不编评论。
- 包本身的性能说法(耐磨、不变形、防泼水):明显是这件商品自己的评价才当证据写进台词。

## 四、怎么拍
一句话推荐:身份 + 拍法 + 谁拍 + 时长 + 气质 + 包饰,各带几个字的理由;场景和风格配色在【场景选项】里定;用户指定了哪项就照用。
- **身份**:按这只包背去哪挑(上班族、研究生、老师、健身、带娃、出差),每条可以不一样(`occasions.md`)。
- **拍法**:不设默认,按包和场景推荐一种:
  - 包要背上身才看得出大小、比例,或者包是整身唯一的亮点 → 真人出镜(第三视角、固定机位、对镜自拍)
  - 卖点在容量、口袋、材质、细节,场景是车里、床上、桌上 → 只拍手和包
  - 想要对话和笑点 → 第三视角;前置自拍只适合小包和上半身
- **真人出镜怎么上身**(选真人出镜时写一句):默认一开场包就已经在她身上(背着、拎着、挎着、夹着),直接在身上塑品;功能卖点要在桌上演(装电脑、分区、杯袋)才先在桌上或手里讲,再上身。上身段、背法展示每条都要有(`02-script.md` 第五节)。
- **谁拍**:男友、闺蜜、同事、路人,或她自己;只拍手和包写"她自己"。
- **气质**:按选题和包从 `styling.md` 第九节挑一种(精致、慵懒、利落、松弛……),定她穿什么(单品不设默认,裤、裙、短裤配丝袜、连衣裙轮换,`styling.md` 第一节)、包怎么背(第十节三种背法;从这只包真有的背法里选,每条换着用,不默认挂肩);文案里说"好搭"就说这身具体的衣服。
- **包饰**(可选):按气质配一样(丝巾、丝带、小毛绒、钥匙扣、小吊坠),规则见 `styling.md` 第五节;商品自带装饰就用自带的。
- **场景 + 风格一起推荐**(【场景选项】):给 5 个选项,每个选项是一个场景配一种风格配色,用户回一个字母,场景和风格就一起定了。
  - 每行写:字母 + 场景 · 风格(这个风格在这个场景里的样子,比如"副驾 · 老钱风(森林绿复古车)")+ 一个具体时刻 + 为什么适合这只包(几个字)+ 偏高级 / 偏日常。真人出镜挑地点时看它本来的颜色和这身衣服呼应不呼应(`styling.md` 开头"高级感的底层逻辑"),季节的东西从 `palettes.md`"季节氛围清单"挑。
  - 风格从 `palettes.md` 的风格和季节色卡里挑,按季节(发布日期往后 2-6 周)、包的颜色落在色卡的哪一层、这只包的气质;场景和风格怎么搭看 `palettes.md` 第三节。
  - 选项要拉开:至少一个偏日常的(普通的车、普通的家、真实的生活痕迹)、至少一个偏高级的(老钱风、复古车、精致的布置);风格不重复。
  - 首推标 ★;同一个窗口用过的场景和色卡不再列;编号用字母,不用数字。
  - 用户说"日常一点""高级一点":同一个场景换偏日常或偏高级的风格,其余不动。
- **风格配色**(首推那个选项的展开):写清色卡名、五个颜色、各自分给画面里的什么东西(六三一)、点缀色放在哪两样小物件上;包落在色卡的哪一层。真人出镜时色卡只分给衣服和小东西,场景保持真实地方本来的颜色,风格靠选什么地方、什么衣服带出来。用户选了别的字母,第 2 步开头按选中的风格重写这一项。
- **氛围**:按七样各写一句:光的方向、软硬、明暗反差、色温、时间、前中后层次、道具点出的时刻。默认明亮、柔和、偏暖的白天;不用斜阳、阴天。
- **颜色**:小屏看得清;花纹选最清楚的那个色;能和场景、她的肤色拉得开。
- **时长**:最低 18 秒;按要讲的多少推荐(按部件都讲到常要 22-25 秒),写一句理由,用户定。

## 五、号卡
**真人出镜的号**:用户贴角色卡就照用(结构:【角色】外观、身高体重、一句身形词、声音、语言、指甲、标志(可以写一样她常用的包饰,当辨识度)、人脸四视图有没有;身边的人;说话味道;口头禅;促单说法;常去场景;常用拍法;主风格;当季走法;习惯;上一条变化卡)。
**只拍手和包、第一次做没有号卡**:起一张简版,用户说"可以"就一直用:
- 手:肤色深浅 + 冷暖调
- 声音:音色、音高、语速、口音(即梦【声音】每条照抄)
- 语言:英语 / 英西混说 / 西语
- 说话味道:在积极、真诚的底色上选一种(甜、爱自嘲、松弛、冷幽默、飒)
- 口头禅 2-3 个、她自己的促单说法 2-3 种
- 最后一行:上一条变化卡
指甲不写进号卡,每条按包和色卡配。

## 六、提醒(有才写)
- 季节和发布时对不上;颜色和她的肤色冷暖冲突;包的大小和场景对不上(大托特去晚宴)。
- 评论里集中的差评(异味、线头、比想的小):写进来,第 2 步用诚实提醒的说法主动说,再给办法。
- 满格花纹、细格纹、字样多、透明涂层:即梦难做,第 2 步动作放小;字样多、花纹满的包转动不超过 15 度,不翻包底。
- **仿冒风险**:这只包长得像不像某个大牌的经典款(轮廓、扣件、标志性设计)?官方规定和品牌产品相似五六成也不能推广;像的话直接提醒用户别做这只,而不只是台词避开品牌名。

## 七、交付格式
```
当前:第 1 步 商品分析|下一步:等你确认(回选题编号 + 场景字母,如"1A";发 1 用 ★)
```
