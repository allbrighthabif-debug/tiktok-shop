# 第 2 步:文案 + 分镜

卖鞋时先读 `shoes.md`,和这里冲突以它为准。

只交 **2a 文案**(每段台词 + 一句简短画面 + 中文对话),停,等用户确认;确认后直接进第 4 步(需要出图时先进第 3 步)。每格的手、表情、眼神、镜头写在第 4 步的时间轴里;用户发"出分镜"才单独出详细分镜。检查都在内部做,有问题才用一句话说。

## 零、怎么写(先读这一节)
总原则见 `SKILL.md`:购买理由、使用情境、拍摄地点是三件不同的事;每条先想怎么讲才自然、才吸引人,再决定在哪拍、演什么、说什么。下面的方法按内容挑,不是必选项。
1. **先读 `taste.md`**,知道用户要什么感觉、嫌过什么。
2. **先按 `SKILL.md`"文案内核"的顺序想**(内部):先定人物关系,再定卖什么(痛点或心动、2-3 个关键卖点各配一个当场证明、最后怎么推),然后才写;写之前读 `voice-samples.md` 最前面的范例。再想清楚这条怎么发生:谁在做什么;她(或拍的人)为什么会注意到这只包;购买欲怎么一层层形成;依据是什么——商品事实、买家报告、虚构剧情分清(`01-analysis.md` 第三节"评论怎么用");关键结构没确认的,不写进依赖它的动作和台词。拍法和地点已经在第 1 步方案里选好,这里按内容调整,不反过来让布景决定说什么。
3. **购买理由合理累积**:按这只包的实际和这条的创意挑几个理由,不规定数量和种类;前后有联系,让她一层层更想要。一个画面可以同时表现好看、搭配和实用;画面已经说明的台词不必重复,但允许自然强调。不要求每句都承担一个新卖点或完成一个证明动作;自然的确认、喜欢、玩笑、重复、短回应、停顿都可以有。理由讲不清、拍不清就少放一个,不硬塞、不加快语速。
4. **照爆款的劲一口气写出整段对话和关键动作**:想清楚这个人、这一刻、身边这个人,她会怎么说、怎么动,从头写到尾;每一句、每个动作都有来由(上一句话、上一个动作或当时的处境)。这一步不提前给每段分配销售任务,不逐项填四问、部件、FABE、变化卡。
5. **再分时间轴**:按写好的内容切段、分秒数;每段的目的只在内部对,不写进交付稿,不用来生成对话。
6. **写完查漏**:部件清单(`01-analysis.md` 第三节)、FABE、八爪鱼只查有没有漏掉对这条有用的东西;漏了的放进已有的对话或动作里(被问到、拿出来用、画面里看到),放不进就不讲,不在后面加说明句;不要求清单上每项都讲。最后记变化卡(第三节),和上一条比较。
7. **最后过一遍必须准确的**:
   - 每段的词数和这一段的动作装得下(按每秒约 3.3 词算到每一段,不只看全条平均)
   - 谁的哪只手正拿着什么,能不能做下一个动作(拿着手机的手、拿着杯子的手不能再去拉包)
   - 结尾说的购买理由,前文有没有铺垫和依据
   - 关键结构(开合、口袋、扣子)和使用经历有对应依据:商品事实、买家报告(只支持它明确说的)、还是虚构剧情;虚构的不标成评论依据
   - 包的结构前后一致(提手几条、长肩带装着还是取下),状态变化有明确的动作交代;一格只有一个接触动作,慎用动作按 `actions.md`
   - 文案、画面描述、即梦提示词三者之间不冲突
   - CTA 是一句完整的话,不说 "orange cart"、"Shopping cart, go" 这种碎片;没有机械对称、刻意排比和广告腔

## 一、输入
- 第 1 步定了的规格卡、选题、九条和部件清单、四问、身份、拍法、谁拍、气质、包饰、场景、风格配色、氛围;评论原话
- 号卡:语言、声音、说话味道、口头禅、促单说法、上一条变化卡、近期实际拍过的场景记录(地点 + 主要事件 + 拍摄关系)
- 爆款参考(有的话,见第十一节)

## 二、五种拍法
- **只拍手和包**:她坐着或站着,镜头只拍她的手和包,她不露脸,台词是她的画外音(不用对口型)。镜头和机位见第八节。先写清谁拿手机、手机在哪,三种选一种:① 她自己一只手拿手机拍,画面里只有另一只手能动,做不了两只手的动作;② 手机固定(放在三脚架、手机支架上,或靠着东西立着,写清在哪、离包多远、什么角度),机位全程不动、画面稳定,两只手都能用,要看清细节就把包往镜头这边转、送近一点,不写"镜头靠近";③ 另一个人拿手机拍,可以手持、可以凑近看细节,她两只手都能用,拍的人的手不入画。画面里要两只手同时动(拉两根抽绳、两手撑开包口),只能用②或③。
- **第三视角**:别人拿手机跟拍,主摄 1x,离她两到三米;两只手都能用。拍的人和两个人的关系见第七节。
- **固定机位**:镜头不动,放在腰到胸口高度;景别靠她走近、退后。
- **对镜自拍**:一只手拿手机,另一只手展示;包挎在手肘或肩上,镜子里看得到全身比例。
- **前置自拍**:胸口以上近景,一只手能动;只适合小包和上半身的卖点。

## 三、这一条怎么讲(先想清楚怎么发生,写完再记变化卡)
- **包是画面的重点**:讲包的时候包看得清、在画面里突出、能看出大小。
- **变化卡(写完以后记,用来和上一条比较,不提前指定每段的任务)**:
  1. 选题(第 1 步定的)和开头方式(第八节"开场方式")
  2. 讲法和购买理由:这条用什么讲法(自拍口播 / 旁白演示 / 第三方互动 / 装包展示……),打算让她一层层看到哪几个理由;塑品的线(第五节)可选,和上一条不一样
  3. 素材类型
  4. 主口气(第九节)
  5. 两人来往(有第二个人时写):谁是谁、什么关系、谁拿手机;对话怎么一句接一句往下走(第七节);单人拍法写"无"
  6. 促单:怎么收(直接说 / 对话里收尾 / 有没有软 CTA、放哪,`cta.md`)
  6b. 排法(装包展示才写):A 先开后讲 / B 先讲后开 / C 撕膜开场 / 现排,和上一条不一样
  7. (促单的具体说法见 `cta.md`:机制 / 爽点 / 对同伴顺口说 / 链接放下面了)
  8. 色卡(第 1 步定的那组)
  **怎么用**:写完以后对照上一条;如果和上一条几乎一样(同样的开头、同样的来往、同样的地点和事件),看看是不是内容本来就该这样,是就保留并注一句为什么,不是才换;不为了不一样而强行换句式、类型或互动方式。
- **素材类型**(参考,按内容选,也可以混用):
  - 达人测评:当场装给你看、当场换背法,短句配动作。给功能型的包用。
  - 人设口播:她像跟朋友说话一样一口气说下来。只拍手和包常用。
  - 剧情演绎:一个小故事、有冲突,两人有来有往。只用第三视角,或固定机位加画外的朋友。
  - 情景种草:边做事边顺嘴说(装包出门、上车、到工位),讲到卖点时停下手上的事展示。
  - 装包展示:能装、隔层多、功能多的包常用;包是画面主体,打开、装或掏、上身、CTA 怎么排按内容定(见"装包展示模板")。
  - 第三方互动:拍的人拿手机、在现场说话和反应,两个人的交流带出产品展示和购买理由(第七节)。
- **谁先开口不固定**:有人拍时拍的人可以起头,她也可以先开口;按这一刻谁先有话说。单人拍她说第一句。
- **四问是四个要达到的目的,不是工序**,每一问只有一个目的,达到就行:开头让他停下来;痛点让他认出自己;塑品让他觉得这只好、觉得它值,并且信她;促单让他现在就买,而且觉得价格比他心里的低。骨架固定:钩子开头 → 中段 → CTA 收尾;痛点、塑品在中段,顺序能换、能合并。销售链路按人性走:先看到好(具体画面)→ 觉得值(把价值抬高)→ 信她(第一人称的经历,替看的人着想)→ 价格留给商品卡,点进去觉得比预期低;台词不说价格数字。
- **全程利他**:替看的人着想、说真话:适合谁、怎么选、要注意什么(按商品页和评论说),他才信她。
- 常见排法(参考,可调):顺着来(开头 → 痛点 → 塑品 → 促单);结果先行(塑品的效果 → 痛点 → 促单);促单当开头(马上要到的那件事 → 塑品 → 促单回扣);当场证明开头(一句顾虑,当场证明 → 塑品 → 促单);真人出镜常用:上身氛围 2-3 秒 → 站定证明卖点 A → 站定证明卖点 B → 促单。
- **比重**:讲产品的部分要讲清楚;开头和来往的对话不拖。
- **底线**:第一帧有看头、一下能懂;讲到的东西画面里看得清;节奏靠自然的动作、表情、展示重点和必要的剪辑,不按秒数凑画面变化;最后有促单。

## 四、字数和节奏
- 时长最低 18 秒,按第 1 步推荐的定;字数按时长算:按爆款的语速,英语、西语都按每秒约 3.3 词(18 秒约 59 词);每秒不超过 3.5 词。
- 开头尽快开口;句与句之间按动作和停顿安排,给看包、换动作留时间,不为填满而说。

## 五、怎么写(方法库,按内容挑)
1. **开头**:目标是一下就清楚、有吸引力。可用的方法:好看开场(包和穿搭、动作、环境一起让人想"我也想这样背");把选题说出口(她的处境或一个心动点,带一个具体参照);她的观点或态度;一个真实的瞬间;两个人的互动;一个能当场验证的问题。按内容挑,不固定。
   - **开头的梗只绕一层,一秒能懂**:能用画面看懂的优先(毛绒包夹在胳膊下像抱着一只狗);要靠背景知识再联想一步才懂的不当开头。自测:只看第一帧、只听第一句,没见过这只包的人能不能马上懂,要想一下的就换。
   - **包踩中当季潮流就说出来**:常放在前面(`01-analysis.md` 九条下面的"追潮流")。
   - 别人一上来夸包、问哪买的(路人叫住、闺蜜问包)也是可用的开头;要写得像真的交流,检查人物关系、对话承接、反应触发和展示原因(第七节)。
2. **损失感(可选)**:落在真实的小麻烦上,让她认出自己(临出门还在换包、必需品装不下、包和当天穿搭不搭、东西不好取);前面有铺垫,后面由包的真实特点解决;不夸大。
3. **讲产品**:
   - **一种常用骨架(可选)**:心动 → 处境 → 讲产品(穿插上身)→ 回到心动 → 促单;结尾回应开头的处境或怀疑。
   - **部件清单查漏**(`01-analysis.md` 第三节):服务于这条购买理由的部件才讲、才演;其余可以只在画面里出现,或不提。有花纹的包,花纹通常是让人停下来的那个点。
   - **可以主动说一个真实的小缺点**(评论或规格卡有依据才说,不碰核心卖点,说完马上接还是值得或还会再买,比如 "Honestly, the only thing is the zipper's a little stiff — but I'd buy it again."):说真话比一味夸更可信。说"好搭"就说出具体搭配并穿在身上,不说空的 goes with everything。身体参照可选:大小是卖点或顾虑时说一句身高和包落在哪。
   - **塑品的线**(可选,参考上一条,不为换而换):
     - 跟着她的动作走:手上做的事带出下一句(往身前一拉 → 落点;手伸进去 → 能装;手搭回包面 → 材质;一抬头,衣服和包同框 → 搭配)
     - 由远到近再回到远:整身(上身、搭配)→ 包(颜色、形状)→ 手上(材质)→ 包里(能装)→ 退回整身收尾
     - 先结果后原因:先说背上的效果,再一层层说为什么(颜色、廓形、厚度、能装),最后回到那个效果
     - 跟着时间线:她的一天,到哪说哪
     - 句和句之间用连接词把因果接上(so、and、plus、that's why、the best part),顺序怎么换听起来都是顺着说下来的;一个动作可以同时带出两项(塞进开衫,顺口说颜色和它搭)。
   - **说成她能得到什么**:什么设计 → 在什么时候用得上 → 给她带来什么(不说 big capacity,说 laptop, planner, my lunch, one trip);要有依据,画面能证明的交给画面。
   - **嘴上结果前置**:先说背上、用起来是什么样(B),再顺带说是哪个设计做到的(F、A);E 交给手上的证明动作。
   - **描述包本身**:讲包时说清它长什么样、好在哪(廓形、颜色、材质、口袋、容量),形容词用在包身上;只说"so cute"不算。
   - **要看清细节时,手在那个部位上**:摸材质、捏提带、指五金、拉开口袋,把这一块转向镜头停约 2 秒;观众已经看清的不必再指一遍、说一遍;不强制每句都碰包。
   - **讲细节时包拿在手里**:不背着介绍(背着时手只能在胯边摸,看不清正面、打不开包口);从肩上取下来提到胸前,正面朝镜头,一只手拿、另一只手做动作;拿法跟着正在讲的部件走(`actions.md` 第二类"讲细节怎么拿")。包始终在她手上或身上,不放到桌上。
   - **一句别塞满卖点**:一句话从口袋跳到穿搭再跳到材质会听着乱;一个画面可以同时表现好看、搭配和实用,台词不用硬拆;自然的重复和呼应可以有。
   - **能装是理由时给画面依据**:打开给人看里面,怎么打开按包型从 `actions.md` 第四类"讲里面怎么打开"挑(两只手把提手、肩带拉开或把包口掰开,拉链、翻盖第一帧就开着,不一手提肩带一手拉包口)。
   - **每类卖点可以怎么被看见**(参考,手法细节在 `actions.md`):
     - 廓形、软塌:把包提起来停一下,让包身自然垂下来;放回座位,看它自然落下的样子(只演商品本来就软塌的包,轮廓按商品图,不塌扁);真人出镜背上肩侧个身看轮廓和比例
     - 颜色、花纹:正面转向镜头停住,转到光里;讲颜色那一格用自然柔光
     - 材质:皮,指腹划过、按一下看回弹;有纹理的面(灯芯绒、编织、草编、荔枝纹、压纹、帆布),指甲来回挠 2-3 下;麂皮绒面,指腹顺毛轻滑,不按、不挠;编织,指尖顺着纹路走;软布,捏起包角松开看它垂下;亮面、涂层,让光在表面流过去
     - 容量:把包口往镜头这边歪一下,露出里面按她身份装的东西(名词要具体);最多捏起其中一样抬一下就放下;装满了照样立得住或塌得好看
     - 背法:真人出镜换背法(手拎换成挂在手肘),背法写清哪边肩、带子从哪到哪、包落在身上哪里、手在哪(`04-video.md`【包】);只拍手和包把肩带或提带拉长给人看
     - 口袋:手指沿着口袋拉链划一次;捏开内袋口一角;不演从口袋里往外掏东西
     - 做工、五金:指腹沿着车线走;把五金转到光里;把包底翻向镜头
     - 挺括:手掌顺着包的上沿抚过去,拍一下包身,看它立得住
   - **功能卖点要有证明镜头**(商品页或评论写了才演,一个卖点一个镜头,约 2 秒):
     - 轻:两根手指勾着提带单手拎起来,手腕不吃力
     - 软:手指按一下包身,松手慢慢弹回来
     - 容量:按她身份装满了,包口照样合得上、或者还能再塞进一样
     - 分区:电脑顺着滑进自己的隔层,旁边的东西不乱
     - 杯袋:水杯插进去,包晃一下杯子照样立得稳
     - 拉链、安全感:一把拉到底,双头合上拍一下(拉链或安全感是卖点时才演,演一次)
   - **上身效果和背法**(真人出镜时常用,对表达有帮助才演):
     - 包在哪不设默认:开头、中间、结尾包在肩上、手肘、手里还是怀里,按那一刻她在做什么定(刚进门挂在手肘、从车里出来拎在手里、刚从衣柜里拿出来抱在怀里、走在路上斜挎着);要看清细节时拿到手里;上身效果对这条有帮助时演,放哪段不限。包的位置全条最多换 2-3 次,每次换(从肩上取下、背回去)单独一格、1-2 秒、动作小,写清哪边肩、带子怎么挂。
     - 上身段可以一个镜头连着拍,从 `actions.md` 第十二节挑 2-3 个顺着做,每个停约 1 秒就靠一个动作顺到下一个,不定格,同一个号连着两条不用同一组(例:挎上肩、低头看一眼包笑 → 顺势侧身叉腰 → 回头冲镜头比个 V);不走 T 台、不转圈、不模特定格;镜头跟着她轻轻晃。
     - 在身上的样子按规格卡的背法:能背的(单肩、斜挎、腋下、双肩)背上身;只能提的(短提手、top-handle、手拿包)就拎在手里、挎在手肘、夹在腋下,包在身体旁边,从肩到髋入画,看得出包和人的比例。
     - 边走边背着包的镜头尽量短(走动最容易穿模、带子乱),讲品时停下来;换背法嵌进场景切换里讲(通勤时单肩,进地铁换斜挎),不单独演。
     - 背法:只演这只包真有的;不强制演两种,换背法对这条有帮助时再演,可以在同一个地方顺手换;每次换给 1-2 秒,换的那一下单独一格;不演调肩带、扣斜挎带。
     - 促单时包还在身上,最后一眼是在人身上的样子。
   - **卖点在场景里亮**:可以用这三种,按内容选:眼下正在做的事、之前背它去过的地方、接下来要背它去的地方;不条条写成 "I took this to…"。
   - **主次**:购买理由可以有几个、一层层累积,不规定数量;每个都要讲清、有依据,讲不清就少放。
   - **吹**:她是这只包的头号粉丝;吹感受、吹态度,不吹假事实(`humor.md` 四之二)。
4. **促单**:需要,但接住已经形成的购买意愿;可以直接说,也可以在对话里自然收尾;软 CTA 可有可无,不固定占两个位置(`cta.md`)。

另外:
- 季节按发布日期写。
- 幽默积极向上:调侃可以先损一下,马上转成夸;不说包丑(`humor.md`)。
- 剧情经历可以编(背去哪、谁问了、谁想抢),具体到某一个人、某一件事;笼统的"好多人问过我""大家都在买"要有已售或评论依据才说;使用证言要有详情页或评论依据。
- 台词不说价格。台词围着这只包,但说成生活里的话:当时在做的事、两人之间的玩笑可以当由头,包在聊天里被注意到、被问到、被用到,卖点顺着带出来。

## 六、说话的口气
- **写之前先读 `voice-samples.md` 里 2-3 条样本**(对话体或单人口播,按这条的拍法挑),照它的节奏写;**再按 `words.md` 开头的"文案用词写法"写,从后面各节挑词**。英文用美国人日常的说法,不从中文翻过去(不说 very convenient、the feeling is super soft;说 so easy、it's like butter);中文对话只当翻译看。
- **塑品段怎么说**:
  - FABE、八爪鱼都是查漏工具,只在写完以后用(第零节):写完查一遍缺哪一爪,不要求每爪都念。八爪鱼 = 一个卖点当头,往外伸几条触手(摸起来、用起来、动起来、别人看到、和以前那个比、带去哪),每条落成一个画面,不重复。
  - 先说结果,再说是哪个设计做到的;用陈述句,口气笃定。
  - 可以用反问把结论交给观众(不是真问,问完直接接下一句),前面要有具体的事实垫着。拍的人可以自然地问,不限个数。
  - 不写自问自答("leopard with lace? Yes."),念出来像在念稿;想回应观众心里的疑问,用 "And yes, leopard works with lace." 这类说法。
  - 不说叠词(so so、really really、super super)。
  - 形容词要挂在看得见、摸得着的东西上;空洞的夸(cute、gorgeous、amazing、perfect)和抽象词(quality、style、vibe、aesthetic)不单独当卖点讲。查法:这句能不能拍出来。这条只管讲卖点的那句;看到、摸到、用到之后的情绪反应(so cute、obsessed、I know、stop),她和拍的人都可以说。
  - 删形容词测试:把形容词删掉,句子什么都不剩,就是空洞的,重写。
  - 说她自己用着发生了什么(第一人称经历,I carried it all day),不空夸;包长什么样、好在哪照样要具体说;经历的内容要有规格卡、评论或详情页依据;立场是她替你试过了,你直接拿结论,不压人买。
- **口播多用这些**:演示动词;反应可以短,解释顺着说(用 and、so、like 连下去,可以改口、加半句);直接夸、情绪满(stunning、so soft、I'm obsessed);痛点到解法;"你以为……其实……"的反设;感官词少而准;颜色和搭配一句;人设或场景挑 1-2 个讲透;按规格替人着想(适合谁、怎么选)。
- **口播避开**:价格数字;平替、dupe、同款;库存紧迫;按钮话;一口气报一长串场合;空洞的华丽形容词;中文网络话术直译。
- **让人想得出画面**,整段要有画面,不逐句硬凑;每段从下面挑着用:
  - 形容词,落在包身上(slouchy、roomy、buttery、structured、rich-looking)
  - 有动作感的动词(toss、slide、sling、stuff、grab、dig)
  - 具体的名词(laptop、leggings、rolled-up hoodie、keys、water bottle),不说 stuff、things
  - 时间和场景(7 a.m., before pilates, Thanksgiving drive)
  - 比较(以前要拎两个包、普通托特一塞就鼓)
- 事实按规格卡:台词里说能装什么只说图上标的、评论里说的(装包展示画面里装的小件可以自由挑,大件按尺寸判断);页面没提软不软就不说 soft;台词里的数字和规格(盎司、寸、几个口袋、材质成分)每一个都要能在规格卡里找到出处,找不到就删。夸包的形容词也要有出处:看得出来的(纹理、廓形、颜色)按商品图;摸了、用了才知道的(soft、durable、sturdy、lightweight)只按评论或页面;都没有就换成图上看得出的说法,不替商品加卖点。 主观的喜欢(觉得颜色好看、喜欢这样搭、看着就开心)可以自然说,不当规格核验。
- 想要卡壳的感觉,直接写进台词、少量用("It's, like— it fits everything."),不让即梦自己发挥(会多出台词、口型乱)。
- 像真人聊天:缩写、口头禅、半句话、笑出声;okay so、wait、honestly、like、literally 一句最多一个;Gen Z 的梗一条最多一个(主力买家 25-35 岁)。
- **避免机械对称、刻意排比和广告腔**("Empty, it flops. Laptop in, it stands." 这种工整的对照、为了押节奏硬凑的三连);自然的重复、呼应、对比可以有,按人物语气来,不规定次数,也不强制长短句交替。
- **评论**:能借来的使用观察、感受、说法就借,改写成顺口的话并标"(评论改写)";不要求每段都从评论里找。买家报告(身高、使用时长、次数、个人经历)不变成主角的真实经历,一个买家装得下的东西不扩大成容量保证。
- **库里的句子只学说法,不照抄**;同一个窗口里,任何一句都不重复。
- 接话快,可以打断、抢话、接对方半句;但两个人不同时出声(即梦会口型乱)。
- 内部检查:每句念出来,像在念商品描述或广告就重写;听完脑子里没有画面也重写。

## 七、第三视角和第三方互动拍摄(可选方式,和自拍口播、旁白演示并列)
- **先定清楚**:谁拍、两个人什么关系、谁发布这条;再安排对话和结尾。不设默认使用频率,也不固定谁先开口。
- **主角一直在真实地做事**:包要么是被别人注意到(拍的人被包吸引),要么是她开心地主动分享;卖点是被问出来、用出来的,不是她站好了宣讲;拍的人的心动替观众先心动。
- **拍摄关系**:拍的人拿手机,同时可以提问、夸、表示怀疑或感受,必要时伸出空着的一只手参与;被拍的人负责回应、使用和展示包。观众站在拍的人的位置看,拍的人的反应就是观众的观察入口。拍的人在现场说话,不写成画外旁白;拍的人是谁、和她什么关系(朋友、同行的人、设定好的搭讪)要说得通,不写成她自拍。
- **从人物当下的注意力出发**:对方注意到了什么;为什么愿意继续聊;什么发现引出了展示;展示之后为什么产生新的兴趣。允许顺着当时的注意力换话题,不要求句句像严密论证;但拍的人不是按时提出下一项卖点的工具。惊讶、调侃、抢包、护包、促单都可以用,自然不自然取决于当时的关系和交流,不按固定顺序走。她为什么拿起包、为什么转过来、为什么打开某个地方,都能从当时的交流里找到原因。
- **反应要有具体触发**:看到整体搭配才夸外观,摸到才说手感,看见装进去才说能装;什么都没发生就不连着喊感叹词。摸一下只证明手感,不证明耐用、承重。
- **情绪按触发变化**:被叫住先反应,明白来意放松,听到具体夸赞开心,对方有兴趣她才更愿意展示;不是从头到尾一种卖货笑容;她可以看拍的人、低头看包,再把注意力移回来。
- **对话接得上**:对方刚说的话影响下一句怎么回;允许短回应、追问、停顿、说一半;不是一篇独白拆两个人念;girl、oh my gosh、are you serious 这类不是必备词。最后谁说链接在哪,要和这条视频是谁发的对得上。
- **镜头为什么动**:因为拍的人靠近、她转身、要看清细节;看清了再回到人物反应;两个人停下来说话时镜头也可以停,留手持的细微变化就行。拍的人一只手拿手机、另一只手碰包时写清分工;她持包的手、包的位置、肩带状态前后接得上;不一次塞太多接触动作。
- 这些检查的是人物关系、对话承接、反应触发和展示原因;不规定这种方式的使用频率,也不要求一镜到底、拍的人先开口、追赶、拍肩或触摸。
- **核心是两个人的关系**:闺蜜互相夸、想抢包;男友笑着调侃、真心夸;同事压低声音惊喜;路人真诚惊喜。
- **她和拍的人都不做夸张的惊讶脸**(张大嘴、捂嘴、往后仰):一看就是表演,25-35 岁的买家最反感;被夸时大方接住:"Aw, thank you!" "Stop, thank you!" 加一个真心的笑,顺口说一句信息或态度(在哪买的、一个小细节、不带数字的划算),也可以回夸对方一句("Love your coat too!");不扭捏、不害羞低头,也不激动。
- **拍的人起头(可选)**:第一句可以跟这一刻有关:她的打扮、状态、要去哪,调侃、误会、催她("Why are you dressed up for a Tuesday?" / "¿Esa no es mi bolsa del 2004?");也可以是被她的包、她这身吸引而叫住她。
- **拍的人的反应可以外放**:美国女生之间爱互相捧场(hype girl),真看到好看的会大声激动("Stoooop."、"No way."、"I'm obsessed."、"I need that."、倒吸一口气、笑出声、伸手要摸);每次都要有触发,放在真有东西被看见的时候。
- **拍的人每句短**;反应真、声音和情绪可以拉满,脸是自然的开心(不张大嘴、不捂嘴、不往后仰)。拍的人说观感要有触发(摸到了才说软、看见装进去才说能装),不凭空替她报卖点。
- **拍的人的手**:拍的人一只手拿着拍,另一只手和手里的东西随时可以伸进画面,次数不限,做什么按那一刻现想(翻包、托包底、帮拉拉链、扶正肩带、要拎走);按剧情需要,可以一次都没有。为了即梦稳定只守这几条:
  - 只露手和小臂;同一时刻一只手;手的样子全片不变(肤色、指甲、袖子和她明显不一样)
  - 一格最多两件事,手伸进来算一件;手碰到包就算这一格唯一的接触动作
  - 左右手分工写清(她的哪只手、拍的人的手各干什么)
- **讲品的手可以由对方引出来**:朋友伸手翻包,她顺手打开给看;朋友要拎走,她拍开、护着包。她自己对着镜头表演的动作一条最多一个。
- 调侃积极:先损一下可以,马上转成夸,笑着说。

## 八、画面
- **开场**:第一帧有看头、一下能懂——在动、看得到包、有情绪,按内容取舍;画面已经在运动中,不从呆站开始。
- **第三视角开头不呆**:第一帧她已经在做一件事,手上有事,不写干等、发呆、站着不动;单纯走路、拖着箱子走、迈步摆姿势不算真事;做什么按这条的场景和身份现想(把外套搭到箱子上、看一眼手机再收起、调一下肩带、把包往身前一拉)。不用并排跟着走开场(会变成走秀):从侧面拍时她是停着在做事;走动按内容安排。她正经开口前,身体已经朝向镜头,或者在正在做的事里顺势转过来;不边走边扭头说话,边走的那几秒只让拍的人说话,或者她说一句短的、不看镜头。镜头方向不限(正面、侧面、背后都行);从背后或侧面拍时靠身体的动作带出活力,包在画面里看得清。她转向镜头那一下:是在做的动作里顺势转过来,不是听到一句话才慢慢回头;转的时候脸上已经有表情;转身单独一格,不和讲卖点挤在一格。拍的人先开口、她又正对着镜头时,反应从第一帧就开始。
- **每格都写她的表情**:不说话的格子也写;背对镜头的格子写身体状态。开头两格的表情和动作比全片高一档。
- **路人叫住**(可选):路人当拍的人,只出声、不露脸;她正在路上或在做事,被叫住先反应再停下、转身接话;讲产品时可以停下来;按第七节检查关系、承接、触发和展示原因。
- **开场不急**:一格最多两件事;一格只有一个人说话,最长约 3 秒,两个人一来一往就拆成两格;第一句不等动作和反应做完。开头两句不用放慢类情绪(得意、真诚安利、慵懒有张力)。
- **开场方式**(参考,按这条内容现想,不为和上一条不同而换):
  - 只拍手和包:第一帧包随手放在副驾或床上,手正要去拿、把包提起来;包放在腿上,两只手正把包口拉开;手正把包放上桌;结果先行(第一帧就是提起来软包垂下的那一下)。
  - 第三视角:刚到一个地方、手上正在做事(刚推开门停在门口把包往身前一拉、刚下车正关车门、刚停下正把外套搭到箱子上);做到一半被叫住(正在关车门、正把包挎上肩);拍的人伸手要翻包;反差(背着很好看的包在做很日常的事);街头采访式(远一点的全身,她手里拿着一样生活里的东西朝镜头这边走来,拍的人的手伸进画面挥一下加一句 "Excuse me—",她愣一下笑出来,2 秒内停下、正对镜头开口;是选项之一,不当默认)。
  - 固定机位:第一帧她已经在画面里,往旁边走两步停下,把包往身前一提。
  - 对镜自拍:举着手机走到镜子前刚站定,包挎在手肘;走进电梯转身对着电梯镜。
  - 前置自拍:坐在停着的车里,刚关上车门,包已经在腿上,手正把包口拉开。
- **开场动作必须是真事**,不编戏剧性假剧情;不限于上面、动作库或场景文件里的清单,是她这一刻真会做的事,清单只当参考,可以现想。
- 场景文件里写的出场如果是"走过来""走向门口",写开场时改成第一帧她已经在画面里、停着在做事。
- 摊手、顶胯、回头定格这类亮相动作不放第一帧,只放在接上拍的人那句话以后、被夸、结尾。不用摆拍类动作:走 T 台定格、面无表情停一下再笑、从门后探出头。
- **构图:包在画面正中间**:左右居中,上下在中间或略偏上;画面底部有文案和商品卡、右边有点赞那排按钮,包不往这两块靠。只拍手和包时包占画面宽度六到八成(场景图那一帧约六成);讲细节时正在讲的那一块放在画面中间。座椅、背景、窗外一层层排在包的四周和后面。
- **观众先看脸**:人一入画,眼睛先去找脸。要讲清包的细节时,镜头框到半身、包提到胸腹前更清楚;只是带过、或在走动中,包在画面里看得见就行。
- **视线**:她看哪,观众就看哪。眼睛在包和镜头之间走,不全程盯着镜头:手落到要讲的地方那半拍,垂眼看一眼包;说到要点、反问、促单,抬眼看镜头。说话时头基本稳,笑的时候可以轻轻晃、微微歪一下头;不大幅点头、转头(口型会乱);真要低头看,放在两句之间或这句开口前。
- **要看清细节时停下来讲**:展示细节、做复杂的手部动作(打开、按扣、拉抽绳)时她停下来、包朝镜头更稳;只是顺口提一句、或画面已经看清的,不用停、不用正面摆给镜头、不用碰包。
- **手和台词怎么配**:讲包本身、要看清细节的句子配一个动作,手比卖点词早半拍开始,说到那个词时到位、停住;说完手顺势收回(搭在包上沿、扶着包底、顺手别一下头发),不僵在半空;不做双手对称的讲课手势;两只手做不一样的事。
- **手的样子**(`actions.md` 第一类):给镜头看手的侧面;手指微微错开、自然弯;提提手只用两三根手指挂着,手腕有一点小折角;轻轻提着,不攥;不按出指坑。
- **包的动作要小**:满格花纹、格纹一动就弯:不甩、不转圈,转包只转到四分之三侧面就停(背面不是卖点就不转过去);所有包侧转最多 45 度(四分之三侧面),包底可以翻;转过去的那一面没有商家图时是即梦自己补的,字样偶尔会画乱,某只包测出来字乱了,那只包就退回小角度。字样多的包,凑近时拍纹理不拍字;字样必须一字不差的,只能逐帧检查或后期处理,提示词保证不了。
- **镜头**:
  - 只拍手和包:镜头固定,或者轻微手持晃动;讲细节时镜头往那一块靠近一点,停约 2 秒再回来;写成"镜头往那一块靠近"这类看得见的说法,不用"推近""特写"这种术语(超近特写本身可以用,见 `04-video.md`)。
  - 第三视角:手持,镜头因为有原因才动(她转身、要跟上她、要看清细节就凑近);两个人停下说话时镜头也停,留手持的细微晃动;方向不限,开场在哪个方向,拍的人就一直在那个方向附近,不绕着她转;要看清细节时拍的人凑近,停约 2 秒再退回来。
  - 别的拍法:固定机位靠她走近走远;对镜自拍手机跟着她轻轻晃;前置自拍手臂带着画面一颠一颠。
- **看细节、摸材质**:正常速度做,关键处停半拍(最多 1 秒,然后接下一个动作),整个细节约 2 秒。
- **人和镜头不一起僵住**:人停下来说话时有表情和小动作(换一只脚站、别头发、笑着低头),镜头可以停但保留手持的细微变化;不为了动而动。
- **画面不乱只管前景**:前景的主体 1-3 个(她、包、伸进来的手);背景要丰富、有生活感(`04-video.md`【场景】),杂物放在背景和两边,不堆在包周围,包靠位置和明暗突出;不写雾、烟、光晕、逆光。
- **她在做自己的事**:做事放在开头和过渡;讲卖点时她因为在做的事停下(走到了、坐进车里、等人),专心展示包。走动按内容安排,多场景时每个场景可以有一段合理的走动。
- **包尽快出现在画面里**(可以第一帧就在,也可以被手拎进画面);不演从别处翻半天找出来。
- **开箱**(选题是到货开箱或送礼时用,包和鞋都行;整条做装包展示时按"装包展示模板"):第一帧包就看得见,手已经在动;可以撕一次外层塑料袋或膜,一把抽出来;开箱只占 3-4 秒,马上接塑品和上身;不一层层拆、不剪胶带。包装和实物一致:防尘袋、礼盒、包装纸只演商品页写明附送的,没写就用普通快递袋;盒子、纸袋不带别家 logo,不像附赠。从袋子里抽出来是慎用动作(手、包、袋子同时接触),只写一个动作、动作慢、袋子不跟着变形。
- 拉链包第一帧就是拉开的,不演拉拉链(拉链或安全感是卖点时例外,见第五节)。
- **真人出镜不默认放下包**:包全程在她手上、手肘上或肩上(不放下不等于一直背着,讲细节时拿到手里,见第五节);放包是手、提带、包、身体同时接触,最容易穿模。剧情一定要放(放上桌讲功能),就单独一格,只做这一件事,慢慢放,写清放到哪里。
- **身上手上有什么**:按场景和这一刻定,不固定拿某几样;饮料不是默认道具,场景里本来就该有才放;最多一只手拿生活里的东西,另一只手空着(讲品要用);穿外套时包和带子在外套外面;背法从这只包真有的里面选,每条换着用(手拎、挎手肘、单肩、斜挎、腋下),不默认挂肩;手里的东西不挡包;画面里只有这一只包。
- **场景细节**:分镜里写地点类型、包身边 1-2 样随手放的东西和在动的东西;颜色和光按第 1 步的色卡和氛围;底子和物件全写在第 3、4 步。

## 九、情绪
- 每句标一种,只用 `emotion.md` 里有的名字;重音用 *星号*,一句最多一个、整条最多 3 个;停顿用 /,笑声写进台词 `(laughs)`。
- **底线是积极正向、真诚**;每条一个主口气(`emotion.md` 第一节);开头两句高一档,第三句落回主口气。
- 只拍手和包时,情绪全靠声音:语气、笑声、停顿写清楚。

## 十、别写的
- AI 腔:It's not just X, it's Y / Say goodbye to… / amazing、stunning、game-changer、must-have 这类空洞的夸 / 三个形容词排成一串 / 口号式结尾。
- 广告按钮话、一串参数("18 inch, polyester, 4 pockets")、和商品无关的闲聊。
- 平替、dupe、同款、replica、inspired by、similar to [品牌],点名别家品牌说"不是那个牌子的那只";在别家买的;页面没写的材质和功能(真皮、防水);保证和"最"。

## 十之二、装包展示模板(素材类型"装包展示",可以切镜,20-25 秒)
**什么包用**:能装、隔层多、功能多的包(托特、通勤包、大容量包、多隔层包、保龄球包)。小包、手拿包、晚宴包、毛绒包这类靠好看卖的包不用,走真人出镜、上身为主的拍法。第 1 步【怎么拍】按包推荐用不用。
画面里的人可以只露手、半身或全身;装包那段多半只露手,包是画面主体。
**排法不定死**,按包挑(写完记进变化卡),也可以按这一条现排;装包展示也可以加入第三方互动、生活小故事:
- A 先开后讲:放下 → 拉开或掰开 → 装或掏 → 外面的设计近景 → 上身 → CTA(里面最有看头的包)
- B 先讲后开:放下 → 外面的设计近景 1-2 个 → 拉开或掰开 → 装或掏 → 上身 → CTA(外观最抓眼的包)
- C 撕膜开场:包落下时还套着塑料袋或膜,一把撕开抽出来(只撕一下,袋子丢到一边不再碰)→ 接 A 或 B(要"新到手"的感觉)
**节奏**:开头尽快给看头(包落下、打开,或一个抓眼的近景),不让观众等;每个镜头要有信息或情绪,不放凑时间的镜头(拍一下包、包立住了、按魔术贴、手松开收走这类);上身和 CTA 一般在后面,按内容可以调整。
**机位**:装包和设计近景用第一视角(从她眼睛的角度往下看)或正上方俯拍,镜头贴近包口,包占画面宽度六到八成,背景只剩一块面。
**背景颜色看包**:深色、饱和色的包(墨绿、黑、酒红、深棕)用白色或浅灰的床单、桌面,光要亮、只微暖,不用一整片暖米色(会把包的颜色压闷);浅色的包用深一点的面(深色地毯、深木桌)。
下面是各段怎么做:
1. **开头**:手拎着包从画面左边、右边或上面进来放下,第一帧包只露一部分、正在移动,可以带一点动作的模糊,构图随手一点,很快落定;或者手抓提手把包提起来再松手;或者第一帧东西已经平铺在包周围;落定后打开或先给一个外观近景。撕膜可选。
2. **中段,四种玩法挑一种或自己组合**(可以跳切,一个镜头约 0.5-1 秒,镜头数按东西多少定;可以换机位、凑近;最大、最惊喜的东西常放前面,藏着的设计常留到后面):
   - **往里装**:先把东西举到镜头前停一下,再放进专门的隔层或口袋,看它装得有条理(隔层多的包)
   - **往外掏**:从包里一样样拿出来,最大的(电脑)第一个(容量大的包)
   - **平铺装包**:东西整齐铺在包四周,一样样装进去,地上越来越空、包越来越鼓(容量大的包,第一帧最抓眼)
   - **隔层导览**:机位跟着每个口袋走,电脑进电脑格、杯子立在杯袋、笔插在笔槽,最好的设计(翻开的收纳仓、暗袋)留到最后一下(功能多、口袋多的包)
   东西可以自由挑,也可以用评论里提到的:口红、唇釉、粉饼、化妆包、香水、护手霜;手机、耳机、充电宝、平板、笔记本电脑;钱包、卡包、钥匙、墨镜、眼镜、抓夹、纸巾、免洗洗手液;水杯、易拉罐、饭盒、零食;笔、本子、书;大包还可以装开衫、围巾、健身衣服、折叠伞。可以带品牌(品牌靠外形认,少露 logo 上的字;台词不点名、不对比),不放大牌老花这类;东西颜色各不一样、和包拉开。大件(电脑、平板、水杯、饭盒、衣服)按规格卡尺寸判断装不装得下,装不下不演。
3. **收尾小瞬间(可选,2-3 秒)**:拉上拉链,往外口袋塞手机、纸巾这类小东西,夹一个包饰(抓夹、挂件)。
4. **上身(可选,常用)**:人出镜,半身或全身;从 `actions.md` 第十二节挑 2-3 个只由她做的展示动作顺着做(姿势、手势、上身收尾、带情绪的展示都可以混着挑),每个停约 1 秒、不定格,同一个号连着两条不用同一组,记进变化卡;背法对表达有帮助才换。
5. **CTA**:按 `cta.md`。
**声音**:旁白或现场说话都可以(装包那段旁白不对口型),内容是好看在哪、能装什么、装得多有条理,优先用评论改写(第六节);可以加一句字幕从头挂到尾、放在画面上方不挡包,发布前在 TikTok 或剪映里加;可以加一首轻的热门音乐,压在人声下面。
**背景**:俯拍、近景的背景用简单、有质感的面(有褶皱的床单、木地板、地毯、木桌),可以露一角床边或抱枕;上身那段按【场景】写丰富。
即梦写法:按镜头分段写(镜头 1……镜头 2……),【约束】里把"不切镜"换成"按时间轴分镜头,每个镜头里包的样子、颜色、带子、五金和光都一样";第一帧写成"包正从画面右边被手拎进来,只露出一半,带一点动作的模糊,1 秒内落在画面中间"。

## 十一、照爆款写
- **输入**:爆款视频的提示词(反推的,带时间轴),或者爆款的台词、分镜截图;规格卡和四问照第 1 步。
- **先拆时间轴**:每一段几秒、在做什么动作、手怎么拿包、什么景别、怎么运镜、有没有切镜。交付最前面加一行:`爆款拆解:钩子 … / 结构 … / 改动 …`。
- 台词按四问重写,说到卖点时对上那一段的动作;和原片不能连续 6 个词相同;原片的价格、效果、经历不搬。
- 原片有切镜:照原片的切法,或按内容选一镜到底;即梦做不稳的切法拆成分段生成。
- 场景和配色默认按我们的(第 1 步的场景和色卡);用户说"照原片"才照原片。

```
【CTA】

【中文对话】

逐句查:通过 / 逐句查:改 N 处|改了什么(为什么)|……(必写,一行,见 `SKILL.md` 文案内核)

```
- 选题、开头、关键台词内部各想 5 个以上再挑,不交第一个想到的。
- 每段的目的(让人停下 / 喜欢它 / 用得上 / 看见依据 / 觉得值 / 促单……)只在内部对,不写进交付稿;内部每段问一句"这一段让她更想看、更想要了吗",不要求每段都塞一个新卖点。
- 画面每段只写一句,够用户判断台词和动作对不对得上就行;细节写在第 4 步时间轴。
- 每段里不放中文;中文对话放最后,逐句翻台词,只翻说的话。
- 内部查完再交(必须准确的,和第零节第 7 步同一套):规格一致、客观描述有出处、没有价格;待核实的没演;关键结构和使用经历分清是商品事实、买家报告还是虚构剧情;包的结构前后一致、状态变化有交代;每段词数按每秒约 3.3 词算到每一段;谁的哪只手拿着什么、能不能做下一个动作;一格一个接触动作;结尾的购买理由前文有支持;画面描述和台词不冲突;CTA 是完整的一句话。再看一眼创作:开头一下能懂、有吸引力;购买理由前后有联系、有依据;对话接得上、反应有触发;没有机械对称、排比和广告腔;英文是美国人的说法。
- **改文案**:用户说哪几句不满意,只出那几句的新版本(连带改那一段的一句画面),其余不动;用户指出整段对话刻意、结构有问题时,整段重写,不只换词;用户说"出完整版"才整条重出。

**"出分镜"**(可选口令,平时不出):用户想在生图前先看动作排得对不对时才出。台词照 2a 定稿一字不改;每格写清手的动作(哪只手、从哪到哪、停在哪个词上)、表情、眼神、镜头;格式照 `04-video.md` 的时间轴,光和布景不写。改只出改动的那几格。

**"出 N 个开头变体"**:在 2a 用,只换开头那一段(台词 + 一句画面),其余一字不动;每个变体用不同的开头方式,编号 A / B / C。
