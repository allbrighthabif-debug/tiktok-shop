# 场景细节:一周饮食 · 郊区中产家庭(含拉美裔)
用法:配合家里场景挑 2-3 样细节;另见 `rules.md`。

**工作日早餐(忙、自助、半成品)**
吃:Cheerios 或 Cinnamon Toast Crunch 麦片;烤 Thomas' 英式麦芬抹黄油;烤面包机里蹦出来的 Pop-Tarts、Eggo 华夫饼淋糖浆;煎培根、炒蛋、微波热的 Jimmy Dean 早餐三明治。大人喝 Keurig 胶囊或滴滤咖啡加奶精 / 燕麦奶;孩子喝大桶 Tropicana 橙汁或巧克力奶。
用:Lodge 黑色铸铁锅或掉色的不粘平底锅,黑色尼龙或硅胶铲;不锈钢双片或四片烤面包机;Keurig 旁散落 K-cup;孩子用五颜六色的耐摔塑料碗,或 Corelle 白色耐热盘碗;大人用印着标语的厚陶瓷马克杯。
在哪:不在正式餐厅。厨房中岛的高脚凳上,或早餐角小圆桌;桌上没收的纸巾、拆开的麦片盒、车钥匙、iPad。

**孩子午餐便当(分格、多零食)**
吃:密封袋装的 PB&J 三明治(去边或切两个三角)或火鸡芝士三明治,或 Lunchables;一条 string cheese;小袋薯片、Goldfish、Cheez-It;一盒 Mott's 苹果泥或 Go-GURT 挤挤酸奶;小密实袋装的无籽红葡萄、苹果片、小胡萝卜配蘸酱;Capri Sun 果汁袋或儿童保温吸管杯。
用:Bentgo Kids 多色塑料分格便当盒或不锈钢分格盒,装在恐龙、独角兽、迷彩图案的保温袋里;一两个蓝色冰包;Ziploc;卡通餐巾纸;妈妈手写"Have a great day!"便利贴。
在哪做:早上 7 点,妈妈在厨房台面上像打仗一样组装,周围是拆开的零食大包装、保鲜膜、密实袋。

**工作日晚餐(快、大盘、半预制)**
吃:烤箱烤的 Kraft 芝士通心粉;一大烤盘 sheet pan dinner(土豆块、胡萝卜、西兰花 + 鸡胸或烟熏香肠);taco 之夜(Old El Paso 套装,桌上一排番茄丁、生菜丝、酸奶油、芝士碎、salsa 自己卷);意面配罐装红酱和速冻肉丸。
用:铺锡纸的铝或不锈钢大烤盘;双耳大煮面锅;大号圆形白瓷盘或 Corelle 碎花盘;抽屉塑料分隔盒里混放的不锈钢刀叉;taco 配料装在大小不一、不配套的玻璃碗和塑料碗里。
在哪:客厅沙发上边看电视边吃,盘子托在腿上或放茶几;或在餐桌快速吃完,铺塑料餐垫,旁边大纸巾架。

**零食(随时、大包装)**
吃:SkinnyPop 爆米花、椒盐脆饼蘸花生酱、玉米片配 salsa 或牛油果酱、Ritz 饼干;Oreo、Nature Valley 燕麦棒、水果软糖、Kirkland 混合坚果、香蕉、带斑点的红苹果。
用:直接手抓;或 Ziploc 袋、花色小塑料碗;大人用大马克杯装爆米花。
在哪:客厅沙发、卧室床上、书房电脑前;吃完的袋子和杯子散在茶几、边桌、厨房台面。

**周末聚餐 / BBQ(户外、一次性、大分量)**
吃:热狗、自制汉堡肉饼、手撕猪肉、腌鸡翅、肋排,刷厚厚的 Sweet Baby Ray's 烧烤酱;大玻璃碗或一次性铝箔盆装的土豆沙拉、凉拌卷心菜、Bush's 焗豆;红蓝 Coleman 冰桶装满冰块泡着 Bud Light、Dr Pepper、可乐、LaCroix。
用:后院燃气或颗粒烤炉(Weber、Traeger、Blackstone 铁板);超长不锈钢夹子和烧烤刷;Chinet 一次性纸盘、红色 Solo 塑料杯、大量厨房纸、一次性塑料刀叉。
在哪:后院露台或草坪;户外桌椅、折叠露营椅、野餐桌,站着坐着都有,背景有音乐和狗叫。

**拉美裔日常补充**:见 `kitchen.md` 叠加层(comal 烤玉米饼、炖豆子、tamales、caldero 米饭、Bustelo 咖啡、pan dulce 甜面包)。
