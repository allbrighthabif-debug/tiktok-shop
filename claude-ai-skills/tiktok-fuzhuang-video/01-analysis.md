# 第 1 步:商品分析

只给要看的:规格卡、买点瞬间、四问、怎么拍、待核实;有评论截图时最前面先出评论提炼;第一次建号再加号卡。分析过程在内部做。交完停,等用户发 1 或说"继续""定了";规格卡从这时起锁死。

## 一、输入
- 商品图、详情页截图:商品事实的唯一来源。
- 尺码表:没有就问;用户说没有,尺码写"缺",台词就不说码,只说她的身高再用手比长度。
- 角色卡(号卡最上面的【角色】):身高体重、三围、平时穿的码、语言、声音都在这里。卡上没写肤色冷暖调、发质的,从人脸四视图和身材曲线图判断,不问用户。
- **活动信息**:券、折扣、买赠、包邮,有哪些、是不是长期的;用户没说就问一句,没有就写"无"。
- **号卡**:用户贴了就照用,不再提议;第一次建号,用户说"这是 N 号"并给人物信息,这一步起一张(第五节);没说号码就问一句"这是几号"。
- **评论区截图**(可选,可以多张):商品分析包含评论分析,不用问来源;先出【评论提炼】,再融进下面各项(第三节"评论怎么用"),原话附在用到的地方。
- 图上是一整套时,问清卖的是哪件;另一件算搭配。
- **老商品**:用户发回之前锁定的规格卡和四问,就不重做这一步,直接进第 2 步;只说"老品"没发的,请用户发。

## 二、规格卡(最优先,定了就锁死)
- 只从商品图、详情页、尺码表取,每项标来源;看不出来的写"待核实",后面不说、不画、不演。
- 写具体:颜色写到能分辨(酒红、燕麦色);结构写到部件和位置;**有方向的设计写清在穿着者哪一侧**。
- **尺码表和模特图对不上时以尺码表为准**,冲突那一项进待核实。
- 主角穿哪个码:用她的三围对尺码表(`fit-body.md` 第一节);和她平时的码不一样就写清。评论里的身高、体重、穿的码和合不合身,可以当选码依据。
- 价格只记录,台词不说。
- 后面每一步写到衣服都照它;造型、动作和规格冲突时改别的,不改规格。只有用户能改规格。

## 三、四问(观众从刷到到下单要过的四道关,每问打掉一个不买的理由)
**逻辑大于框架**:每一问只有一个目的,达到就行;下面的写法、FABE、八爪鱼都是查漏的工具,不是要填满的格子。
- 开头:让他停下来。
- 痛点:让他认出自己。
- 塑品:让他觉得这件好、觉得它值,并且信她。
- 促单:让他现在就买,而且觉得价格比他心里的价低。
全程**利他**:站在看的人那边说话,替他挑码、告诉他适合谁、哪种身材要注意;说真话,他才信她。
先定**买家画像**:消费观念(看性价比、看品质、看颜值、图省事,选最主要的一个)、地域气候(美国南北差得多,决定换季和痛点促单);有评论时加上谁在买(身份、身材,附评论原话)。它决定塑品重点讲什么、促单用哪种,只在内部用,不把观众说窄。
再判断这件是**好看型**(默认;卖点是上身好看:版型、颜色、设计)还是**功能型**(商品页的主卖点就是一个功能、买家冲它买:不勒、不透、有口袋、不皱、遮肉;功能型也要说穿上好看)。它决定塑品怎么写;两种都要有痛点,好看型的痛点后面再接向往。
**再列 3-5 个买点瞬间**(交付里给出来,用户可以换):每个一行,写场景(谁、几点、在哪、在做什么)+ 看得见的麻烦 + 她心里那句;有评论时,评论里最多人说的痛点排第一。场景优先挑常去、有人看、会专门为它买衣服的场合(`occasions.md`),瞬间落在衣服被看见的那一刻(进门第一眼、拍合照、被夸);要用"脱掉外套露出里面"那一刻时,写成第一帧外套已经搭在手臂上,不演脱。选最多人遇到、最痛、这件最能解决、即梦拍得出来的那个,写清为什么选它;四问都围着它。
1. **为什么要用(开头,让他停下来)**:一个**具体的生活瞬间**,不是"怕透""太素"这种分类。写场景(谁、什么时候、在哪、在做什么)+ 一个看得见的麻烦(好看型:一个想变好看的时刻,比如出门前、约会前、被夸的那一下)+ 她心里那句话(英文一句 + 中文,可以直接当钩子)。开场动作是她这一刻真会做的事(场景文件的"拍衣服怎么用"和 `actions.md` 只当参考,可以现想),不编戏剧性假剧情(丢手机、撞到人这类;路人当拍的人叫住她夸、问哪买可以,`frameworks.md` F36)。再定一句**这身让她变成谁、穿去哪**(一句话,具体到她是什么样的人、要去哪),后面的场景、穿搭、台词都围着它,写进【怎么拍】的"风格"。
2. **痛点(让他认出自己;好看型再接向往)**:痛点必须是**具体场景**:谁、几点、在哪、正在做什么、出了什么看得见的麻烦;不写"太硬""不好搭"这种分类词。说得轻、生活化、积极,能笑着说出来,不吓人;说自己的肉可以,不贬低别人。功能型写不用这件会怎样;好看型也写一个真实的生活麻烦(没得穿、站在朋友旁边像没打扮、约会前换五套),不编功能问题,后面接**向往**:穿上它会是什么样子、去什么场合、别人怎么看她。好看型的痛点从种草反推:塑品最后落到的那种感觉(看着贵、显身材、甜),没有这件时就少了它,这就是痛点;向往落回痛点的那个场景,同一个时刻前后对照。有评论时用评论里真实的麻烦和想穿去的场合。
3. **为什么用这款(塑品,最重要;让他觉得好、觉得值、信她)**:按**核心需求、次要需求、惊喜卖点**各挑一组卖点(惊喜卖点是她没想到的地方,最容易让人"被戳中")。默认 18 秒用核心 + 惊喜两组;做 15 秒时核心一组讲深,惊喜卖点放得下就一句带过。每组做到三件事:觉得好(穿上的样子和感觉,落成一个画面)、觉得值(比普通款强在哪、做工、看着像什么,把他心里的价抬起来)、信她(她自己穿着的经历、拍的人的反应、评论原话、尺码表、页面上的真实数据、一句利他的真话)。写完用下面的 FABE 和八爪鱼查一遍有没有漏,不用每层都填:
   - **F 设计**:规格卡上的具体设计;找卖点时把版型、颜色、面料、工艺、肤感、设计六样都过一遍,再挑最戳的
   - **A 比普通款强在哪**(好看型:比普通款好看在哪,版型、颜色、细节):和普通款、她以前那件、别的牌子比都行(不说"XX 的平替 / dupe");比的那一点要有依据;评论里跟旧的、跟别的牌子比的话优先用
   - **B 对你意味着什么**(好看型:穿上以后的样子和感觉;台词里先说这一层,`02-script.md` 第五节):落到她生活里的好处,带具象的形容词(用在衣服本身,落在一个看得见的画面上,`02-script.md` 第六节);也可以是这件衣服带给她的感觉(情怀:让她想起的某段日子);评论里的爽点优先用;最后落到一个具体的气质或感觉(看着贵、低调、甜、野、松弛),和号卡的风格对得上,只说"so cute"不算
   - **E 怎么证明**:让人感受到这件衣服值:它好在哪,就让那里动起来、被看见,该转就转、该扭就扭、该坐就坐、该捏就捏;从她在场景里做的事自然带出来,不为了展示站好摆拍,每套不一样(`02-script.md` 第五节第 3 条)。再加拍的人或同伴的反应 + 她夸 + 评论原话、尺码表、背书(页面上真实的已售数量、评分);商品页上的硬事实(打版次数、面料成分、特殊工艺)也当证明,一句带过,马上转到穿上什么样,页面没写的不编;顺带打消想买的人最大的顾虑(尺码准不准、实物廉不廉价、透不透、值不值、"我已经有类似的");评论里问得最多的顾虑,写清怎么在她的真实活动里自然带出来打消。
   - 每组后面标:即梦 能做 / 慎用 / 难拍 [来源]。看不见的卖点给替代画面(软→捏一下松开;不透→站到窗光前;弹力→伸手够高处);细条纹、密印花标"慎用"。
   - **八爪鱼**:一个卖点往外伸几条触手:摸起来、穿上去、动起来、别人看到、和以前那件比、穿去哪;每条触手落成一个画面,不是换个形容词再夸一遍。挑最戳的两三条,不用全伸。
4. **为什么马上买(促单,让他现在就买、觉得比心里的价低;软 CTA 一次 + 硬 CTA 一次,`cta.md`)**:评论里的时机、想要的颜色、回购多买、送人,放进下面对应的项。
   - **心里价**:塑品先把他心里的价抬起来(做工近景、看着像什么、拍的人的反应),促单时再往下压一句,不报数字(`cta.md` 第 8 条)。
   - **机制**:只写真的、长期有效的活动(包邮、多件优惠、长期买赠);短期活动、断码、补货不进台词(视频会被推好几天,过期就成误导);没有写"无"。台词不报数字。
   - **爽点**:下单马上能得到的那一下爽(穿上被夸、一件顶几件、出门不用想穿什么、看着贵,不报价格)。硬 CTA 用哪种按 `cta.md`(机制、爽点、对同伴顺口说在 TikTok Shop、链接放下面了)。
   - **痛点**:马上要到的那件事(换季、节日、婚礼季、开学、回办公室),按实际发布日期对得上(`cta.md` 节点日历);可以接在爽点里用。
   - **替她选(利他)**:哪个色、哪个码(尺码只按尺码表,颜色有依据)。
   - **软 CTA** 怎么带出在哪买(拍的人要链接、她顺口说);也可以用**身份推荐**(点名一类人,说就它了)或**从众**:身边某一个具体的人也买了(剧情里编的可以);笼统的"好多人都买了"要有依据(已售、评论)。

制造需求的办法:让人认出自己、场合倒推、和她现在的凑合办法比、一件顶几件。不编没依据的效果,不造假紧迫。

**评论怎么用**(有评论截图时)
- 全部读完,按"谁在买 / 喜欢什么 / 烦什么 / 怕什么 / 为什么现在买"归类,交付里第一块出【评论提炼】:每类列说的人多、点赞多的原话(原文 + 中文),按多少排序;后面的尺码、买点瞬间、四问都从这块出发。
- 融进上面各项:买家画像(谁在买)、买点瞬间和痛点(真实的麻烦、想穿去哪)、塑品(跟旧的比、爽点、顾虑怎么打消)、促单(时机、颜色、回购、送人)、规格卡的尺码(身高体重和穿的码)、提醒(差评)。
- 用到的地方附原话(英文或西语原文 + 中文);不露用户名,不编评论。
- 衣服本身性能的说法(不起球、不缩水、洗了不变形):截图明显是这件商品自己的评价才当证据写进台词;看不出来的只当痛点和说法用。
- 能直接当台词的(口语、短、有画面),原话保留,第 2 步可以整句用(`02-script.md` 第六节)。

## 四、怎么拍
一句话推荐:她这条的身份 + 拍法 + 谁拍 + 场景 + 拍哪个颜色 + 时长,各带一句理由;用户指定了哪项就照用。身份按这件衣服穿去的场合挑(老师、学生、护士、上班族……,`occasions.md`),每条可以不一样;谁拍按这件衣服和场景推荐一个(男友、闺蜜、同事、路人,或她自己拍);常用拍法、常去场景按号的设定。
- 裙子、裤子、连体要看全身和长度 → 第三视角、固定机位或对镜自拍;背面是卖点 → 第三视角或固定机位;上衣、领口、面料是卖点 → 前置自拍也行;想要对话和笑点 → 第三视角。
- 颜色:小屏看得清(太黑看不清细节,太浅先确认透不透);印花选最清楚的那个色;和场景、她的肤色拉得开。
- 场景:从 `scenes.md` 按这件衣服穿去哪选,再看号的设定里她常去的地方;季节只管小道具,节日元素只在节日前 2-3 周到当天用(`scenes/seasonal-decor.md`),不是每条都要季节道具;同一个窗口不重复,少用清单最多一次;场景颜色按衣服定(`styling.md` 第十节);有地方走动、能拉到全身。当季风格查 `trends-fw2026.md`。给 5-10 个场景选项让用户选(交付里的【场景选项】):每个一行,字母编号 + 地点 + 一个具体时刻 + 为什么适合这件(几个字);首推的标 ★;从 `scenes.md` 和号卡的常去场景里挑;这个窗口用过的不再列,少用清单里的最多列一个。编号用字母,不用数字(数字是快捷指令)。
- 风格:从号卡的当季走法里挑一个(`trends-fw2026.md`),整身按它搭(`styling.md` 第一节);同时定一组色卡(`colors.md` 第二节):商品的颜色要落得进这组的某一层,落不进就换一组,同一个窗口用过的不再用;再写一句她穿上变成谁、要去哪(第三节第 1 问)。
- 时长:默认 18 秒;用户说做 15 秒才做 15 秒。这件要讲的特别多(套装、复杂结构、背面和细节都是卖点)时推荐 20 秒,写一句理由,用户同意再做长;用户直接说做几秒就按几秒。超过 15 秒只能用 2.5。

## 五、号的设定(号卡)
**第一次给这个号做**:用户说"这是 N 号",给身高、体重、三围、平时穿的码、语言(想要的长相、声音也一起说);按这些和号码起一张号卡,最上面是【角色】,用户说"可以"就一直用,说"换一个"就重提。两张参考图还没有的,提醒用户发"做参考图"(`03-image.md` 第四节),图做好后从图里补上肤色、发型和身材词。**以后**:用户在新窗口开头贴号卡,照它用,不再提议;老号卡没有"当季走法""标志"的,第 1 步按主风格补上,写进更新后的号卡,不另外问。号卡写这些:
- **【角色】**(号卡最上面一块,就是角色卡,文字):号码、名字;外观(年龄感、是否拉美裔和哪里、肤色深浅 + 冷暖调、发型发色、眼睛、眉毛);妆容;身材(身高、体重、三围、罩杯、平时穿的码、身材自称:petite、midsize、tall 这类);身材词(英文,看着身材曲线图写一次,每张同框图照抄;每个号写自己的,不套固定说法);声音(音色、音高、语速、口音,即梦【声音】每条照抄);语言;指甲、纹身;她的标志(可选:1 样她常戴、常用的东西,让人认出是她,不挡卖点、不和这身风格打架时才戴);两张参考图有没有
- 身边的人(可选):有没有男友、闺蜜、常见的同事,各自怎么相处(比如互相损又护着、闺蜜总想抢她衣服);只记身边有谁、说话的味道,不决定这条谁拍(谁拍每条第四节推荐)
- 说话味道:在积极、真诚的底色上选一种(甜、爱夸张、爱自嘲、冷幽默、飒、松弛);爱笑、语速快的声音配爱夸张,低沉、慢半拍的配冷幽默
- 说话语言:英语 / 英西混说(英语为主,只拉美裔的号)/ 西语(【角色】写明才用);口音地区(比如墨西哥裔加州、波多黎各裔纽约),写进即梦【声音】
- 2-3 个她自己的口头禅(英西混说的号,西语的那几个词也从这里来)
- 她自己的 2-3 种促单说法(按她的声音和说话味道起,每个号不一样;不用 `cta.md` 禁用清单里的句子)
- 常去的 3-4 个场景(从 `scenes.md` 挑,不挑少用清单里的)、常用的 1-2 种拍法
- 主风格(长期不变):从 `words.md` 第三节挑一个,定这个号整体的样子和形容词方向,也定用哪几个按风格的展示动作(`actions.md` 第 5 类)
- 当季走法(跟着风格速查换):在 `trends-fw2026.md` 里挑 1-2 个和主风格对得上的;每条第 1 步在这几个里挑一个,轮着用,整身按它搭(`styling.md` 第一节)
- **这个号的习惯**(变化卡里几个都合适时按它选):偏好的开头方式 3 种、软 CTA 形态 2 种、硬 CTA 偏机制还是爽点;同一种关系的几个号,偏好错开挑。
- 最后一行:上一条的变化卡(用户要号卡或要开新窗口时更新)。
- 不按族裔分配风格和性格。

## 六、提醒(有才写)
- 季节和发布时对不上;尺码表里没有她的码;颜色和她的肤色冷暖调冲突;人设和她的身材对不上。
- 评论里集中的差评(偏小、偏短、线头):写进来,第 2 步用诚实提醒的说法主动说,再给办法。
- 内衣、塑身、泳装:按正常试穿展示,不性感化;效果只写"设计依据 + 推测",不写减重、医疗。
