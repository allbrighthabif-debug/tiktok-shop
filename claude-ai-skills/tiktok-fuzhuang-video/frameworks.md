# 框架库

框架 = 这条靠什么打动人(机制)。这里只给思路和开场,不给时间线:结构跟着买点那个瞬间走(`02-script.md` 第三节)。编号沿用原来的,缺号是服装用不上的。

## 怎么用
1. 先看第 1 步的四问,再挑一个最顺的机制;核对"适合",和这件衣服、这个拍法对不上就换。
2. 每个框架写了"四问"怎么排,照着排(没写痛点的,痛点一句带过或只演,并在开头里;好看型的款,框架里的痛点之后接向往);剧情按这件事真实发生的顺序写,不照着别的条的段落套。
3. 单人拍法(固定机位、自拍):[拍] 的话改成她自己说,直接对观众说、自问自答、对观众吐槽。有人拍时第一句一律由拍的人说:框架里写着她先开口的(比如 F09 假抱怨、F11 反常识),改成拍的人先说一句把它引出来("You're returning those?" 算拍的人这条唯一的问句)。
4. 同一个窗口里前面用过的框架,这条换一个;用户说了这个号最近用过的,也错开。
5. 库里没合适的可以自己编,交付时标"库外新写"。
6. 用户说"换个框架":列 2-3 个不同机制,每条一行 `框架|开场一句|为什么适合`,每轮不重复。
7. 框架里的开场句只示意机制,按这件衣服和这两个人重新说,不整句照搬(和原句连续 6 个词相同 = 重写)。

## 底层心法
1. **好看要被看见**:该做的动作就做,让人感受到这件衣服值;镜头跟着动作走(`02-script.md` 第五节第 3 条)。
2. **顾虑当场打脸**:拍的人(单人时她自己)问出观众最怕的,她用一个动作回答,比说十句都可信。
3. **卖点是被问出来的**:她松弛不推销,拍的人追问,她顺口回答。
4. **最好看的那一下往后压一点**,留个悬念。
5. **一条只有一个场景、一种穿法**:别的场合、别的穿法、别的颜色只能说,不能演。

## 一、对话反差(第三视角首选)
- **F31 偶遇惊讶 + 松弛回应**:拍的人在反差场合惊讶("你穿这个去超市?"),她松弛回一句"随便穿的",越问越露出这件的好。适合看着精心其实很省事的款(连衣裙、连体衣、套装)、有背面设计的。第三视角;固定机位 + 朋友走进画面也行。钩子 14、4|样本 #101-#108 #71
  四问:开头(拍的人惊讶)→ 塑品(越问越露出好)→ 促单;痛点一句带过或只演
- **F33 误会揭晓**:拍的人误会("你昨天不是穿过这件?""这是裙子还是短裤?"),她揭晓真相再当场证明。适合多色款(颜色真实)、看着是 A 其实是 B 的设计。单人时自问自答("Dress or shorts? Both.")。钩子 14、3|样本 #12 #82
  四问:开头(误会)→ 塑品(揭晓 + 当场证明)→ 促单
- **F36 路人叫住**:路人当拍的人(只出声、不露脸)叫住她,夸一句,问哪买的或穿的什么(街拍采访 "Can I ask what you're wearing?" 也算);她马上回头看过来接话,讲卖点时停下来、脚不走,有点不好意思。只演被叫住、被夸、被问,不编撞到人、追着跑这类意外。适合街头感强、上身一眼好看的款;街边、商场外、咖啡馆门口、市集。第三视角(路人拍)。钩子 14|样本 #76
  四问:开头(被叫住、被夸)→ 塑品 → 促单(被问在哪买)

## 二、顾虑打脸
- **F23 怀疑打脸**:拍的人质疑("你穿这个能坐吗?""这不透吗?"),她不服,直接开测。适合有明确顾虑、能用动作打脸的款(瑜伽裤、短裙、白色、弹力牛仔);前置自拍只测上身。钩子 14、4、2|样本 #09 #14
  四问:痛点(质疑就是顾虑)→ 塑品证据先行(当场开测)→ 塑品优势和利益 → 促单
- **F32 尺码先行**:拍的人担心码("Did you size up?"),她报身高和码,当场坐下、下蹲证明合身。适合选码焦虑大的品类(牛仔裤、连衣裙、内衣、塑身、大码);必须有尺码表依据,主角的码按 `fit-body.md` 第一节核对。钩子 14、7|样本 #05 #14 #17 #34 #74
  四问:证据开头(报身高和码)→ 塑品(合身的证明)→ 促单(替她选码)
- **F01 痛点 + 当场解决**:先说一个人人都懂的烦("每件背心都这样"),边说边演这件怎么解决。适合痛点一句话能说清的款。钩子 2、5|样本 #16 #77
  四问:痛点 → 塑品 → 促单
## 三、效果先行
- **F22 结果先行**:第一帧就是最好看的那一下(正在转身、下摆正散开、正从椅子上站起来),拍的人追问怎么做到的。适合上身效果一眼看得见的款(裙摆、垂感、显高);第三视角、固定机位、对镜自拍。钩子 1|样本 #02 #78
  四问:塑品(最好看的效果)→ 痛点(以前那件)→ 促单
- **F30 转身揭晓**:正面看着普通,拍的人一句 "That's it? Kinda basic.",她转过去,背面是记忆点。适合背面有设计的款;对镜自拍用侧身回头,前置自拍不适合。钩子 14、4|样本 #53 #107
  四问:开头(正面看着普通)→ 塑品(背面揭晓)→ 促单
- **F35 隐藏细节**:拍的人发现一个细节("Wait, that has pockets?"),她得意地再带出第二个藏着的设计。适合有口袋、内衬、安全裤、内置胸垫的款。钩子 3、14|样本 #04 #07
  四问:塑品 1(第一个细节)→ 塑品 2(藏着的第二个)→ 促单

## 四、反转
- **F09 假抱怨反转**:她假抱怨("I'm returning this."),正话反说塞卖点,最后揭晓"应该买两件"。适合相见恨晚的款;不说价格。单人最顺。钩子 4
  四问:痛点(假抱怨)→ 塑品(正话反说)→ 促单(应该买两件)
- **F11 反常识断言**:一句反常识("我穿睡裤去上班。"),再证明为什么可以。适合面料、穿法和常识反着来的款(家居面料能出门、运动款能上班)。钩子 3、4|样本 #106
  四问:开头(反常识)→ 塑品(为什么可以)→ 促单
- **F12 看着贵**:"That had to be expensive." 或 "Everyone thinks this is designer.",近看质感和做工。适合看着贵、用着便宜的款;不报价格,不说"XX 的平替 / dupe"。钩子 6、4|样本 #21 #40 #76
  四问:塑品(看着贵)→ 证据(近看做工)→ 促单
- **F05 同类的坑**:点出同类衣服的坑("别的高腰裤后腰都空"),当场证明这件不一样。只说"别的同类",不点名。钩子 5、2|样本 #36 #37
  四问:痛点(同类的坑)→ 塑品(比普通款强在哪)→ 促单

## 五、身份与场景
- **F17 身份点名**:叫出人群 + 一个痛点("高个的姐妹,终于有条够长的裙子")。适合人群明确的款(娇小、高个、大码、上班族、新手妈妈);单人最顺。钩子 7|样本 #15 #18 #21 #78
  四问:开头 + 痛点(叫出人群)→ 塑品 → 促单
- **F29 跟拍做一件事**:带着时间和要做的事开场("十分钟后开会"),跟着她做,卖点在真实动作里发生。适合通勤、出行、日常款;第三视角、前置自拍。钩子 10、14
  四问:促单的痛点当开头(时间紧)→ 塑品在动作里 → 促单回扣
- **F34 一套多场合**:"One outfit, three plans.",只演眼前这一个,别的场合只说。适合百搭基础款、套装、能上班也能约会的款。钩子 11、10|样本 #104 #105
  四问:塑品(一件顶几件)→ 痛点(不用每次想穿什么)→ 促单
- **F07 向往画面**:开场就是理想画面(海边、露台、傍晚街头),再讲为什么好穿。适合度假、约会、季节氛围强的款;证明颜色那一格用自然柔光;第三视角、固定机位。钩子 1、13|样本 #55
  四问:塑品(理想画面)→ 利益 → 促单(季节、假期)

## 六、情绪与极简
- **F19 情绪爆发**:一句强情绪("Whoever put pockets in this dress, thank you."),再说为什么这么激动。情绪饱满但只演七成,不喊。钩子 8
  四问:塑品(惊喜的设计)→ 痛点(以前没有)→ 促单
- **F28 极简**:短句,一句一个动作,说清楚就够。适合基础款(T 恤、打底、背心、袜子)。钩子 2、1|样本 #34 #35
  四问:痛点 → 塑品 → 促单,一句一个动作

## 动作别空转
- 每个动作都要让人看到一个好看的地方或一个卖点:转一下是为了看版型或背面,走两步是为了看面料怎么动。
- 没有目的的转圈、走来走去,不算。
