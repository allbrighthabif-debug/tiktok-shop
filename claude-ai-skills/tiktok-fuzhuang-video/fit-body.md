# 尺码、身材、结构和服装铁律

服装靠"信任这个人"卖:观众最怕买错码、上身不好看。这个文件管五件事,各步骤按需查:
- 第 1 步:规格卡里的尺码,核对主角的码
- 第 2 步:尺码和显身材的台词,用动作修饰身材
- 第 3 步:搭配修饰身材;参考图里的长度、结构
- 第 4 步:结构和动作怎么写进即梦

## 一、尺码台词怎么说
**依据只从这些来**:尺码表、详情页(模特身高和码、版型说明)、面料成分、用户给的评论截图、角色卡。没有依据的尺码台词一律不写。
**没有尺码表**:不说码、不说偏大偏小;只说她的身高,再用手比长度落在哪。

**六种说法,每种都有条件**
1. **参照型**:报她的身高(体重可选)和穿的码。
   - 条件:角色卡有身高;她穿的码按尺码表确实合适(见下面"主角的码怎么核对")。
2. **选码建议型**:告诉观众怎么选码。
   - 条件:详情页或评论明确这么说。不自己推"偏大偏小"。
3. **长度型**:用她的身高说明衣服落在哪。
   - 说的时候手比在落点。
   - 条件:落点按第四节估算,和尺码表的衣长对得上。
4. **松紧型**:有没有弹力、勒不勒、腰后空不空。
   - 条件:面料成分里有弹性纤维(spandex / elastane),或者设计上有松紧腰、抽绳;同时配一个动作证明。
5. **顾虑回应型**:透不透、会不会往上跑、会不会卷边。
   - 条件:详情页写了(双层、有内衬、防卷边条)。**AI 画面只是演示,不能当依据**。
6. **诚实提醒型**:主动说一个小缺点,马上给办法。这一句最能建立信任。
   - 条件:缺点有依据(尺码表显示偏短、详情页说偏小、评论集中提到);办法要真实可行。

**可以说的夸法**:谁穿谁好看、不挑身材、不挑年龄;均码的款说 "one size fits most"(说法见 `words.md` 第八节)。

**不能说**
- 没依据的 "true to size"、"runs small"
- 编出来的使用经历:"洗了十次都不缩""穿了一整个夏天";洗后缩不缩、起不起球,只按详情页说("pre-shrunk"写了才说不缩)
- 保证式:"it'll fit you"、"guaranteed"

**主角的码怎么核对**
- 优先用三围对:角色卡的胸围、腰围、臀围,落在尺码表哪个码的范围里,就说哪个码。
- 只有"平时穿的码"时:看尺码表同名码的范围正不正常;详情页说偏小的,按尺码表该大一码就说大一码。
- "I sized up" 只在尺码表确实需要她穿大一码时说。
- 对不上(比如按尺码表她穿平时的码会紧):在第 1 步提醒用户,不硬写成合身。
- 美国常见对照,只作参考,以尺码表为准:XS≈0-2、S≈4-6、M≈8-10、L≈12-14、XL≈16;大码 1X≈14W-16W、2X≈18W-20W、3X≈22W-24W;牛仔裤数字码按尺码表的腰围对。
- 西语人群说身高体重也常用英尺、磅,按角色卡的数字写好再放进台词。

**拍的人怎么把尺码问出来**(按关系现写,一句 6 个词以内;问句算拍的人唯一的问句)
- 闺蜜:问她是不是大了一码、是不是小码
- 男友 / 老公:怀疑会不会紧、能不能坐下
- 同事:怀疑透不透
- 路人:直接问穿的什么码(陌生人问尺码最自然)

## 二、显身材怎么写、怎么拍
**效果只写"设计依据 + 推测效果"**,不写成保证。设计和效果的对应:
- 高腰 → 腿看起来更长
- V 领、方领、挂脖 → 脖子和肩颈线条更清楚,脸显小
- 收腰、系带、腰封 → 腰线出来
- A 字下摆、阔腿 → 胯和大腿不显
- 抓褶、裹身 → 小肚子不显
- 有垂感、不贴身 → 整体利落,不显肉
- 竖向线条、开衫敞开、上下同色 → 整个人拉长
- 后中缝、后片抓褶、提臀剪裁 → 臀型更好看
- 内置胸垫、宽底边 → 胸部有支撑

**领口、袖子、裤裙**(台词用美区说法,`words.md` 第六节有品类名):
- V 领 → elongates my neck, frames my face|圆领 → classic crew neck, goes with everything|方领 → square neckline, shows off my collarbones
- 娃娃领 → Peter Pan collar, so sweet, a little vintage|一字领 → off-the-shoulder, date-night ready|POLO 领 → sporty-preppy
- 泡泡袖 → puff sleeves, so romantic, hides my arms|落肩 → drop shoulder, relaxed, easy|蝙蝠袖 → batwing sleeves, cozy, drapey|灯笼袖 → balloon sleeves, dramatic in the best way
- 直筒裤 → straight-leg, not tight anywhere, hides it all|阔腿裤 → wide-leg, swishy, floaty|微喇 → kick flare, legs for days|高腰 → high-waisted, hits right at my waist
- A 字裙 → A-line, cinches the waist and flares out, pear-girl friendly|伞裙 → skater skirt, twirl-worthy|百褶裙 → pleats move when I walk

**台词**:说成她自己在意的地方被照顾到了,用大白话,短句。
- 思路:说出是哪个设计替她把那个地方照顾好了(高腰、抓褶、垂感),一句说完。
- 顾虑说成自己的担心(比如担心手臂、小肚子);遮肉、显瘦、藏小肚子可以说(`words.md` 第八节);不说"胖的人别买"这种贬低别人的话。
- 不用空词:flattering 单独用不算卖点,要跟上它照顾到了哪里。

**画面**:一镜到底里,显身材靠这些动作(一格只做一个):
- 侧身停一下 → 腰线、收腹、臀型
- 手叉腰 → 腰线
- 走向镜头 → 腿线、高腰效果
- 转身停在背面 → 背部设计、臀型、后腰不空
- 坐下再站起来 → 腰头不卷、不勒,裙长坐下不走光
- 下蹲或弯腰 → 不紧绷、后腰不露
- 抬手够高处 → 上衣不往上跑
- 双手叉腰扭一下 → 松紧腰的弹力(手插进腰头往外拉,即梦容易做坏,见 `actions.md` 不建议清单)

**真实边界(平台红线)**
- 参考图和即梦里,她的身材按角色卡画,**不为了衣服好看把她画瘦、腰画细、腿画长**。
- 衣服在她身上的松紧和长度,要和她穿的码在尺码表上的位置一致:在码的上限就偏合身,在下限就偏宽松。
- 塑身、提臀、收腹的效果,画面不能比商品真实能做到的夸张。

## 三、用搭配修饰主角身材
先看角色卡的身材,挑 1-2 个要修饰的地方,用搭配、发型、姿势处理(搭配细节见 `styling.md`)。商品本身的效果不夸。角色卡写 curvy / hourglass 的,胸、腰、臀是要露出来的长处,不按"胯宽""胸大"去遮。
- **娇小**:高腰、短款上衣、上下同色、裸色或尖头鞋、裙长在膝上、小比例印花;避开拖地阔腿、把腿截断的中长裙加过膝靴。
- **高个**:长款、阔腿、长裙、大比例印花都撑得住;平底鞋也行。
- **腿短 / 上身长**:高腰,上衣塞进去或选短款,鞋和下装同色。
- **胯宽**:上身亮色或有设计,下身深色、A 字或阔腿;避开臀部有大口袋装饰的紧身浅色下装。
- **肩宽**:V 领、插肩袖;下身加一点体积(A 字、阔腿)平衡。
- **胸大**:V 领、裹身、胸前不加装饰和口袋,有支撑。
- **胸小**:胸前有设计(褶、荷叶边、口袋)、方领、一字领。
- **小肚子**:抓褶、高腰、裹身、垂感面料、上衣只塞一角;避开低腰紧身、贴肚子的薄针织。
- **手臂**:袖长到肘、泡泡袖、落肩、蝙蝠袖;避开细肩带配紧身。
- **大码**:合身而不是宽大(太宽反而显大),留一个明显的腰线,垂感面料,竖向线条。

**人群和主角身材要对得上**:人群是大码、midsize,主角却很纤细(或者反过来),尺码台词和显身材的说服力都会掉。第 1 步对不上就在提醒里写一句。

**美区常见身材类型**(按身材说,不按族裔推断)
- 用法:商品明显面向某种身材时,用来找这种身材买衣服的常见痛点、该说哪些尺码信息;主角的身材只按角色卡。
- **普通美国成年女性**:平均身高约 5'3.5"(161 cm)、体重约 170 磅(77 kg),常见穿 14-18 码(美国疾控中心全国健康调查的平均数)。大多数观众是 midsize 到大码,主角很纤细时,大多数人群代入感弱。
- **高个、腿长**:腿占身高的比例长、躯干相对短,肩偏宽。常见痛点:衣服不够长、裤长不够、肩线窄、裙子后面短一截。该说:长度落在哪、有没有长款分码。
- **腰臀差大、臀翘**:胯、臀、大腿丰满。常见痛点:腰合适了臀不合适、后腰空、臀部紧、大腿磨。该说:有弹力、后腰不空;塑身衣(faja)的结构。
- **小个子、躯干长腿短**:骨架小。常见痛点:衣长盖住腰线显腿短、裤子太长。该说:短款、高腰、九分、有短款裤长。
- **midsize、大码**(跨人群):常见痛点:腰头卷、往上跑、大腿磨、腋下被挤、面料贴肉显肉。该说:不卷不勒、有弹力、有垂感。
- **画图提醒**:生图和即梦容易默认画成亚洲模特的比例(腿短、骨架小)。主角的身材比例按角色卡,在第 3 步同框图的提示词里写清楚。

## 四、长度落在哪(估算)
参考图、即梦、台词里的"落在哪"要一致,而且要和尺码表对得上;尺码表和模特图冲突时以尺码表为准。尺码表有衣长、裙长、内长时,按主角身高 H 粗估(误差约 ±5 cm / 2 in;1 in = 2.54 cm):
- **上衣、连衣裙**(衣长一般从肩颈交界量起),下摆落点大概在:
  - 衣长 ≈ 0.22H → 腰
  - 衣长 ≈ 0.30H → 胯骨
  - 衣长 ≈ 0.37H → 臀下
  - 衣长 ≈ 0.46H → 大腿中部
  - 衣长 ≈ 0.55H → 膝盖
  - 衣长 ≈ 0.66H → 小腿中部
  - 衣长 ≈ 0.80H → 脚踝
- **半裙**(从腰头量起):裙长 ≈ 0.24H → 大腿中部;≈ 0.33H → 膝盖;≈ 0.45H → 小腿中部;≈ 0.58H → 脚踝。
- **裤子**:她的内长(裆到地)≈ 0.45H。裤子内长比这个长 → 裤脚堆在鞋面或拖地;短 → 九分、露脚踝。
- 算出来落在两个部位之间,就写"之间"(比如"大腿中部到膝盖之间")。
- 尺码表没写长度:看详情页模特图落在哪;模特比主角高很多,落点就往下挪。
- 算出来的落点用在三处:第 3 步同框图提示词(平铺图时写进即梦【衣服】)写 "hem lands at mid-thigh" 这种落点,不写英寸;即梦里写同样的落点;台词说落在哪时,手比在同一个位置。
- 长裤和鞋一起看:阔腿长裤配高跟或厚底,裤脚盖住鞋面一半;配平底鞋就要短一点的裤长。

## 五、各品类重点
下面的"动作"是可选的,按这件衣服该做就做(`02-script.md` 第五节第 3 条)。
**上衣(T 恤、衬衫、针织、背心、吊带)**
- 看:领口、肩线落在哪、衣长、袖长、透不透、扎不扎(针织)、塞不塞进去都好看。
- 常见顾虑:透、起球、扎人、领口洗了变形、腋下和手臂。
- 动作:抬手、塞衣角、手抓一把面料松开、站到窗光前。

**下装(牛仔裤、长裤、半裙、短裤、瑜伽裤)**
- 看:腰头高低、臀和腰合不合(腰后空不空)、长度、弹力、口袋。牛仔裤看腰围码、有没有短 / 常规 / 长的裤长分码。
- 常见顾虑:腰后空、勒肚子、下蹲透、往下掉、大腿摩擦、太长太短。
- 动作:下蹲、坐下起身、走路、转身看臀和后腰、双手叉腰扭一下。

**连衣裙、连体裤**
- 看:长度、腰线、有没有内衬和安全裤、上厕所方不方便(连体裤)、风一吹会不会走光。
- 动作:转身让下摆散开、坐下、弯腰;裙摆飘动只到大腿中部以下,不拍走光角度。

**套装**
- 看:两件是不是分开卖码(上下不同码)、能不能分开穿。
- 台词可以说"一套穿出几套"(分开搭),但画面里只演一种穿法。

**内衣(文胸、带胸垫的背心)**
- 看:杯型、有没有钢圈、肩带能不能调能不能拆、底围宽窄、穿在紧身衣服下面看不看得出。
- 罩杯参照(报她的罩杯和穿的码)只在角色卡有罩杯、尺码表对得上时说。
- 展示:默认外面搭一件(开衫、衬衫敞开),或者手里另外拿一件同款展示结构;镜头不对着胸部特写。

**塑身、安全裤**
- 看:压力大小、防卷边条、如厕开口、会不会往下掉、腿口会不会勒出印。
- 效果只说设计(高弹、双层、防卷边),不说减重、减几寸、燃脂、矫正体态这类功效。
- 展示:默认穿在衣服里面,靠轮廓和动作证明(紧身裙下面平整、坐下不卷边);结构用手里另外拿一件同款展示。需要露出的,只到掀起裙摆一角、大腿中部为止,一下就放下。

**泳装**
- 看:遮盖度、胸部支撑、高腰、挂脖、能不能调;抗氯、下水不透只按详情页说。
- 场景必须是真能穿泳装的地方(泳池边、海边);动作正常走、转身、坐下,不做挑逗姿势,不演下水。

**大码**
- 语气自信;遮肉、显瘦可以说,说成穿着自在、有安全感;卖点多在不勒、腰后不空、不往上跑、有弹力、面料不贴肉。
- 主角身材要是大码人群能代入的,见第三节"人群和主角身材要对得上"。

**男装**:不在本 skill 范围。

**生图或即梦被拦时**(内衣、泳装、塑身常见):换成外搭版本(外面加开衫、罩衫、T 恤),或者改成手里拿同款展示,不硬闯。

## 六、复杂结构的衣服怎么写
**哪些算复杂结构**:系带、绑带、交叉裹身、不对称、斜肩单肩、镂空、抽绳、叠层、可拆(肩带、袖子)、两穿(露肩 / 不露肩)、褶皱、开衩、一排扣子、拉链位置、内衬、安全裤、胸垫。

**结构描述怎么写**
1. **不写通用品名,逐个写结构**:不只写"中长连衣裙",写"方领;细肩带可调;背后一整片松紧褶;穿着者右侧有一道开衩,开到膝盖;下摆落在小腿中部"。只写品名,AI 就会画成常见款。
2. **写清方向和层次**:哪片压哪片、在她身体哪一侧、从哪里到哪里。**一律按穿着者自己的左右写**。
3. **小心镜像**:同框图左半边的正面里,她的左边在画面右边;右半边的背面里,她的左边在画面左边。检查图时按这个换算,不按画面左右想当然。
4. **正反面对得上**:前面的系带,背面能不能看到带子绕过来;前面有开衩,后面有没有;领口前深后浅还是前后一样。
5. **写一次,后面原样用**:第 1 步在规格卡【结构】里写中文;第 3 步写成英文放进参考图提示词;第 4 步原样放进即梦的【衣服】。不每次重写,重写一次衣服就变一次。

**动作和结构**
- 不演结构操作:系带子、扣扣子、拉拉链、调肩带、拆袖子、换穿法都不演,只展示穿好的样子;外搭类正在穿按 `actions.md` 第 9 类。
- 可拆、两穿这类卖点标"难拍":台词可以说,画面只演一种穿法。
- 结构在动作里怎么动要写:裹身款走路时下摆会开合(注意走光角度)、垂下的系带会摆、抽绳的绳头会晃。

**即梦容易画坏的结构**:镂空、蕾丝、细带交叉、密褶、复杂印花、透明拼接、一排小扣子。处理:这些地方近景只给 1-2 秒,动作放小,不做快速翻转;第 3 步出图后先对这些地方。

## 七、服装类铁律
1. 面料、尺码、弹力、长度、价格只从商品图、详情页、尺码表取;看不出来的问用户,不猜。
2. 效果只写"设计依据 + 推测效果",不写成保证;塑身不写减重、减寸、燃脂、医疗功效。
3. AI 画出来的上身效果不能超过真实:身材按角色卡,松紧和长度按尺码表,塑身效果不夸张。
4. 主角说的码必须和尺码表对得上;谁穿谁好看、不挑身材、不挑年龄可以说,均码说 one size fits most。
5. 不编使用经历(洗了多少次、穿了多久);洗后缩不缩、起不起球只按详情页说。
6. 台词可以提品牌(当场景、当比较),不说"XX 的平替 / dupe",不说在别家买的;画面里衣服、配饰、道具上不出现别家 logo。
7. 内衣、泳装、塑身不性感化:不对着胸部、臀部、私密部位特写,不用卧室挑逗场景,动作只做正常的走、转身、坐。
