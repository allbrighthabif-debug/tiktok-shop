# 展示动作库

第 2 步写画面、第 4 步写时间轴时从这里挑。

**女主说到卖点时,手在那里、在介绍那个地方,不空手站着念。下面的动作都是参考,不是必选清单:按这件衣服和场景挑,也可以用库外的动作。**
塑品动作按这件衣服定:该转就转、该扭就扭、该坐就坐、该捏就捏,让人感受到这件衣服值;不为了展示站好摆拍,每套不一样(`02-script.md` 第五节第 3 条)。

**怎么用**
- 每个动作标了三样:**稳 / 慎用**(即梦能不能做好)、**小 / 大**(说话时能不能一起做)、**双手**(自拍不能用的标出来)。
- **默认只从"稳"里挑**;"慎用"的一条视频最多用一个,只给 1-2 秒、动作放小、这一格只做它。
- **小动作**(手在衣服上、手势、换重心、胯一顶、侧身、身体轻轻晃,脚下不挪步):说话时可以做。
- **大动作**(转身、坐下、下蹲、走位):放到另一个人说话的格;单人拍法里,配一句 3-5 个词的短句,边做边说。不为了做大动作留空白;只有"绝不能错的动作"那一格和背面停 2 秒那一格女主可以不说话,用画外音或笑声填上。
- **自拍只有一只手**:标"双手"的不能用;第三视角、固定机位都能用。
- 不建议的动作放在最后,每个都给了替代动作。

**用手介绍衣服的手法(先从这里挑)**
每种标了能让人看到什么、即梦稳不稳;一条里换着用,不重复。每个手法写"一次"(点一次、捏一下停半拍松开),不来回摸;看细节约 2 秒,不一闪而过,也不慢动作;松手以后写面料怎么落回来(自然垂下、回弹,不自己飘)。
- 拎:拎起下摆一角再放下 → 垂感、长度|稳;拎起裙摆两边 → 裙摆有多大|稳|双手
- 翻:翻一下袖口 → 袖口里的设计|稳;翻开衣襟露出内衬 → 内衬|慎用;翻起领子 → 领子背面|慎用
- 撑:双手把外套前襟往两边一撑 → 里面的搭配、廓形|稳|双手;手插在口袋里往外一撑 → 口袋深、版型宽|稳
- 拢:把衣襟往里一拢、裹紧 → 合身、显腰、保暖|稳
- 甩、抖:甩一下袖子或外套下摆、抖一下裙摆 → 面料怎么动|稳
- 扯、抻:扯开裤管 → 有多宽|稳;捏住袖口往外一拉、松手弹回 → 弹力|稳
- 捏:捏起一小块面料 → 厚薄|稳
- 托、递:手托起一截袖子或下摆,送到镜头前 → 细节、做工|稳
- 比:手比一下下摆落在哪 → 长度|稳;手里拿另一个颜色贴在身上比 → 颜色|稳(多色款)
- 立、推、卷:把领子立起来 → 领型|稳;袖子推到小臂 → 袖口、休闲感|慎用;卷一下裤脚 → 裤长、内里|慎用
- 插:手插进口袋站着或走 → 有口袋、松弛感|稳
- 拍:拍一下口袋 → 口袋|稳;拍掉衣服上的灰 → 顺带看面料|稳
- 托起再松开:托起一截面料再松手,让它自己垂下来 → 垂感|稳
- 整理:拽一下下摆整理平 → 版型、长度|稳;整理一下帽子 → 卫衣帽型|慎用(只用于卫衣)
- 对光:把袖子对着光 → 薄不薄、透不透|稳
- 扇:拎着衣襟扇两下风 → 透气、轻薄|稳
- 转:手腕转一圈 → 袖口|稳
- **摸**(手掌抚过、手指划过)和**指**(隔空指、指尖点一下):
  - 指适合:小细节、镜头还没过去时,把眼睛带过去(领口的小扣子、鞋);转身以后反手指一下后背;套装一手指上衣、一手指裤子;和拍的人互动时笑着指一下对方;说"this"时指尖点一下,点完马上接别的手法。
  - 指不用在:画面左下角、购物车;镜头已经拍清楚的地方。

**1. 按衣服部位**
- 领口、肩:
  - 手指顺着领口线滑一下 → 领口形状|稳|小
  - 把头发拨到一侧露出领口或锁骨 → 领口、肩颈|稳|小
  - 点一下锁骨上的项链 → V 领落点|稳|小
  - 上半身往镜头倾一点再讲(近大远小)→ 领口、胸前、袖口这些上半身细节|稳|小
  - 耸一下肩再放下 → 肩线合身、落肩|稳|小
- 胸前:
  - 手平放在胸口轻压一下 → 有支撑、有胸垫|稳|小
  - 垂眼看一眼再抬眼(说话时头不低)→ 带出胸前的设计|稳|小
  - 手掌从胸下顺着前襟往下抚一次,正常速度 → 合身、版型|稳|小(守 `SKILL.md` 铁律的边界)
- 袖子、袖口:
  - 手腕转一圈,露出袖口 → 袖口设计|稳|小
  - 甩一下泡泡袖、灯笼袖 → 袖型|稳|小
  - 双臂张开 → 袖型、落肩、腋下不紧|稳|大|双手
  - 袖子盖住手(sweater paws)→ 针织软、宽松|稳|小
  - 一只手的手指点一下另一只手的腕骨 → 袖口落在哪|稳|小
  - 把袖子推到小臂 → 袖口、休闲感|慎用|小
- 腰:
  - 手顺着腰线往下抚 → 显腰、收腰|稳|小
  - 双手叉腰 → 腰线、腰头不勒|稳|小|双手
  - 叉腰扭一下 → 腰头不卷、有弹力|稳|小
  - 手放在小腹前,又拿开 → 小腹平整、遮肉|稳|小
  - 手指沿腰头前沿从中间往两侧划 → 高腰、腰头|稳|小
  - 提起上衣前摆一点露出裤子腰头,停 1 秒放下 → 高腰、腰头设计、上衣长度|稳|小
- 臀、后腰:
  - 侧身停一下 → 后腰贴不贴、臀型|稳|大
  - 背身回头看一眼 → 后腰、臀型|稳|大
  - 侧身时手从后腰顺着衣服滑到臀线,正常速度一次 → 后腰贴合、裤子后面的版型|稳|小(守 `SKILL.md` 铁律的边界)
  - 侧身站,背挺直、下巴微收,停一下 → 身材线条,手不碰身体|稳|小
  - 手拍一下后口袋 → 后口袋位置|慎用|小
- 下摆、裙摆、裤脚:
  - 拎起裙摆一角再放下 → 垂感、面料|稳|小
  - 踢一下裙摆 → 裙摆的动感|稳|小
  - 跨一大步 → 裤管摆动、开衩|稳|大
  - 扯一下裤管展示宽度 → 阔腿|稳|小
  - 手比一下下摆落在哪 → 长度|稳|小
  - 双臂自然垂下,看下摆落在指尖哪里 → 衣长、裙长|稳|小
  - 手掌顺着大腿外侧裤缝往下滑到膝盖,开口那一下抬眼 → 侧面版型|稳|小
  - 手不碰衣服,胯左右小幅摆两下,让裙摆、裤脚自己晃 → 垂感|稳|小
- 口袋:
  - 手插进口袋站着 → 有口袋|稳|小
  - 手插口袋走两步 → 口袋能用、有型|慎用|大
  - 拍一下鼓起来的口袋 → 口袋能装|稳|小
- 背面设计:
  - 撩起头发露出背 → 背面设计|稳|小
  - 转过去停住 → 背面|稳|大
  - 从肩上回头看镜头 → 背面 + 情绪|稳|大
- 面料整体:
  - 手指捏起一小块面料 → 厚薄、质感|稳|小
  - 捏着面料搓一下 → 软|慎用|小
  - 抓一把再松开看回弹 → 弹力、不皱|慎用|小
  - 手掌平抚一下衣服 → 面料顺滑、不起皱|稳|小
  - 捏起袖口贴到下巴旁 → 颜色显白、衬肤色|稳|小
  - 指尖顺着滚边或车线描过去 → 做工|稳|小
- 鞋和裤脚:
  - 脚尖往前点地、脚踝转一下 → 鞋和裤脚怎么落|稳|小

**2. 按要证明的卖点**
- 软:袖子盖手;脸轻轻蹭一下袖子(稳,小)
- 有弹力:下蹲(稳,大);伸手够高处(稳,大);抬腿上台阶(慎用,大,场景里得有台阶)
- 不透:走到窗光前站住(稳,大);侧身站在光里(稳,大)
- 不皱:坐下再站起来,手一抚就平(稳,大)
- 有垂感:走动、转身,看下摆落下(稳,大)
- 显腰:叉腰、侧身停一下、手顺腰线往下抚(稳)
- 显腿长:侧着从镜头前走过(稳,大);侧身一条腿往前伸(稳,小)
- 遮肉:侧身;手放小腹前又拿开(稳)
- 能动、舒服:伸懒腰(稳,大);快走几步(稳,大);盘腿坐下(稳,大)
- 长度:站直,手比一下落点(稳,小);坐下看长度(稳,大)
- 袖长:双手举过头,袖口还盖着手腕(慎用,大;尺码表或评论能证明袖长够才用,高个子的号最有用)
- 口袋:手插口袋;拍一下口袋(稳,小)
- 颜色:走到自然光下转一下;手里拿同款另一个颜色贴在身上比(稳,小,多色款用)
- 轻薄:把袖子对着光,透出手的影子但看不到皮肤(稳,小;不和"不透"打架才用);捏起一层面料轻轻搓(稳,小)
- 不扎:袖子贴着脖子或脸蹭一下,表情放松(稳,小)
- 保暖:双手缩进袖子里抱住胳膊,再放松(稳,小);先搓热双手,再贴到毛衣上(慎用,小)
- 回弹:一只手捏住另一边袖口往外拉开,松手让它弹回,另一只手臂自然抬在胸前(稳,小)
- 可调温、半开扣:手指顺着领口那排扣子滑下来,把领口往外翻一下露出扣子(稳,小;不演解扣、扣扣)
- 别人的手来证明(第三视角):拍的人的手捏一下面料、拉一下袖口(稳,小;次数不限,每次做的不一样,`02-script.md` 第七节)

**3. 走路、坐姿、借环境**
- 走路:放慢走、边走边回头、上下楼梯(慎用)、推门出来、走过去又折回来(稳,大)
- 坐姿:坐下翘腿、坐在高脚凳上、坐进车里、坐在台阶上(稳,大)
- 借环境:靠墙站、倚在栏杆上、抱臂靠着门框、在镜子前侧身比量(稳,小)

**4. 配饰联动**
- 摘墨镜、墨镜推到头顶(稳,小)
- 拨一下耳环(稳,小)
- 包换到另一边肩上,露出腰线(稳,小)
- 把外套搭到肩上(慎用,小)
- 帽檐压一下(稳,小)

**5. 通用展示动作**(不挑衣服、哪件都能用:展示"这一身",带出她的态度)
用法:接上拍的人那句话以后、被夸、结尾用得最多;第一帧不用(第一帧是她在做的真事,`02-script.md` 第八节);塑品段和上面的手法一起用(手在衣服上讲,身体和态度用这里的)。比耶这类一条最多一次;同一个号不连着几条用同一个;按号卡的主风格挑。说话时不点头,点头放在说完以后。
- 亮相:双手手心朝上往衣服两边一摊(ta-da)(稳,小);胯往一边顶着站(稳,小);手掌从上到下扫一遍"这一身"(稳,小);比耶或双手比耶(稳,小;放在眼角旁快速比一下更新);甩一下头发(稳,小);走着走着突然定住(稳,大);走两步回头定格(稳,大);倒吸一口气、身体往后一仰(稳,小);笑着推开镜头再放下(慎用)
- 被夸、得意:chef's kiss(稳,小;有点年代感,走幽默人设的号才用);clock it:拇指和中指指尖在胸前对点三下(慎用,小);手在脸旁扇风"太好看了受不了"(稳,小);手按在胸口(稳,小);捂嘴笑(稳,小);往后一仰笑(稳,小);耸肩摊手(稳,小);抱臂耸肩"没办法,就是这么好"(稳,小);手指点一下太阳穴"我很会买"(稳,小);不敢相信地摇头(稳,小,不说话时做);双手捧脸(稳,小);捂脸(稳,小,不跟价格放一起);开心地踩小碎步或小跳一下(稳,大);抖一下肩(稳,小);对镜头挑眉,手指腰线或下摆(稳,小);手指比枪 finger guns(稳,小)
- 站姿定格:一条腿膝盖往里一弯;肩膀放松左右晃;脚踝交叉站;放松地往后一靠;靠着吧台或柜台(都稳)
- 和拍的人:冲拍的人甩头发(稳,小);笑着推一下拍的人(稳,小);一把抓住拍的人的胳膊,惊喜时用(慎用);对拍的人飞吻,情侣号用(慎用)
- 结尾:嘴角一勾、说完点个头(稳,小);慢慢点头表示满意(稳,小);竖大拇指(稳,小);比心(慎用,手指容易做坏)
- 按风格(对上号卡的主风格,不同的号自然用不同的动作):街头风:眼前比耶、懒散地一靠、抬膝跺脚(慎用)|工装风:敬个礼|西装外套:宽站姿|学院风:脚踝交叉站
- 只适合单人拍法(第三视角不用):托腮、隔空击掌、对镜侧身、假装调整镜头(固定机位开场)
- 不用:双手交叠端在身前的 demure 式、6-7 梗手势(成年人做显得尴尬)、单手叉腰的茶壶定格 pose(过时)、双手搭在胸前(被读成性暗示)、喊着推销、夸张地指屏幕或购物车、拍大腿、捶胸、站军姿、单眼眨眼、翻白眼(只保留"翻完白眼马上笑")、手捂镜头转场换装

**6. 和另一个人互动**(第三视角,或固定机位有人走进画面时)
- 把手里的东西塞给拍的人(稳,小;场景里本来就有的东西,饮料不是默认)
- 拽他胳膊往前走(稳,大)
- 笑着推开镜头(慎用,小)
- 和他击掌(稳,小)
- 让他伸手捏一下面料、拉一下袖口(稳,小;写法见 `02-script.md` 第七节)
- 拍的人伸一根手指点一下她的肩,她转身展示(稳,小;转身有了理由,不像自己在摆拍)
- 她展示完回头看拍的人,等他打分,他在画外说话(稳,小)
- 拍的人摊开手掌,她把袖子或下摆搭上去(慎用,小)

**7. 按品类的专属动作**
- 针织:袖子盖住手;抱臂搓一下胳膊(暖)
- 牛仔:侧身看后腰;往前跨一大步,看裤腿怎么落
- 裤子(说话时能做):重心换到一条腿、顶胯、膝盖往里一弯或往外一转、手提一下腰头
- 喇叭裤:脚尖往外一摆,喇叭口张开;交叉步慢走两步(慎用)
- 阔腿裤:扯一下裤管;跨一大步;一只脚往前滑一下再滑回,裤腿荡起来
- 半裙:双手轻扶裙子两侧,转一下胯看裙摆
- 印花 T:双手把胸前图案两侧撑平,亮给镜头
- 连衣裙:拎裙摆行个屈膝礼;转半圈停住
- 外套:掀开一边露出内衬(慎用);把领子立起来
- 套装:一手指上衣,一手指裤子;一手捏上衣下摆、一手捏裤腰,并到一起看同色同料
- 泳装:走在泳池边,回头看(不演下水)
- 塑身、安全裤:侧身看轮廓;坐下起身(不掀衣服,见 `fit-body.md` 第五节);上身左右慢转,看边缘不卷

**8. 带情绪的展示**(让介绍不干巴)
- 得意地拍拍口袋
- 转完半圈停住,等裙摆落下再开口
- 嘴上说"还行吧",手却把衣服抚平了三遍
- 被夸以后低头拽一下衣角
- 对镜头挑眉,手指腰线
- 照完一眼走开,又忍不住回来再照一眼

**9. 有条件能做的**
- **正在穿外搭**(2.5 做得到;2.0 mini 测试时一律写"已经穿好"):
  - 只限外搭类:外套、开衫、马甲、当外套穿的衬衫、围巾、帽子。
  - 从已经穿上一半开始(一只袖子已经伸进去、围巾已经搭在脖子上),只演剩下的那一下(另一只胳膊伸进去、拉上肩、理一下领子、绕一圈围巾);不从拿在手里、放在车里开始。
  - 单独占一格,这一格她不说重要台词,台词给拍的人或用笑声填上;一条一两次。
  - 穿好以后和 @图片1 一样(敞着就敞着)。
  - 生成出来袖子扭、手穿模或衣服变样,就改成"第一帧已经穿好"。
- **针织衫滑下一边肩**:
  - 只用在宽领、落肩、一字领这类本身就能露肩穿的针织衫上。
  - 滑到肩头就停,像随手慵懒地一垮,不往下拉、不演脱。
  - 镜头不对着胸口;内衣、泳装、塑身不用。
  - 一条最多一次。

**10. 按面料**(先想这种面料卖的是什么:软、暖、挺、垂、透、弹,再挑能让人看见它的动作;同一种面料换着用,不每次都摸;节奏是关键处停半拍、约 2 秒)
- 长毛绒、羊羔绒、抓绒(卖软和暖):软——把毛领拉起来贴着脸颊蹭一下,手掌顺着毛抚过去,手指陷进绒里停半拍;暖——冷的场景里把前襟往身上一裹、毛领贴着下巴、肩膀一松,手插进口袋,呼出一口白气笑出来(稳)
- 羽绒、棉服、绗缝(卖蓬和暖):双手轻轻一拍或一挤,看它鼓回来;绗缝、压纹让指尖顺着纹路划过去,侧光把纹理照出来(稳)
- 粗针毛衣(卖软和厚):袖子盖住手;捏起一小块看厚度;镜头凑近看针脚;不扯针脚,看着像拉坏了(稳)
- 罗纹、细针织、弹力面料(卖弹):双手往两边一拉,停半拍,松手看回弹(稳)
- 呢子、羊毛大衣(卖挺括和厚):手掌平抚前襟看挺括,捏起衣襟看厚度;走动时看下摆怎么摆(稳)
- 牛仔(卖厚实和版型):捏住一角搓一下;弹力牛仔往外拉一下;指尖划过车线(稳)
- 棉 T、针织衫(卖厚薄和不透):捏起一块看厚薄;拉一下领口看回弹(稳)
- 缎面、丝绸(卖垂顺和光泽):侧身对着光,让光在面料上流过去;拎起一角松手看它滑落;不用力捏,会皱(稳)
- 雪纺、薄纱(卖轻和飘):拎起一层对着光看透出来的手影;走动时看飘(稳)
- 皮革、仿皮(卖质感):指尖划过表面,捏一下看软(稳);麂皮:手指一划,划出深浅印再抹平(慎用)
- 灯芯绒(卖纹理):指尖顺着条纹划过,侧光(稳)
- 天鹅绒(卖光泽):手抚过去显出深浅反光,再抚回来(慎用)
- 亮片、珠片(卖闪):转身或走动时在光里闪;手抚一下亮片翻色(慎用)
- 蕾丝(卖精致):指尖托起边缘对光看镂空,近景要短,容易画坏(慎用)

**11. 说话时的身体和手**(她说话的每一格都能用;讲品和不讲品都适用)
- 重心在左右脚之间慢慢换(稳,小)
- 一只手轻搭在身侧裤缝或裙侧,另一只手做动作,两只手不对称(稳,小)
- 说到重点词,上身往镜头稍微倾一下再回正(稳,小)
- 头发和脸周围:把头发别到耳后、手指卷一下发尾、拨一下刘海(稳,小)
- 不讲品的句子(开头、促单):手在胸前轻轻转一下,像跟朋友聊天(稳,小);说"三个理由"这类时掰手指(慎用,即梦常画错手指数)
- 边走边说时,胯随步子自然小摆(稳);站在原地刻意顶胯像擦边,不做
- 说完手顺势收回:插兜、顺着腰线垂下、轻搭在身侧,不僵在半空

**12. 冷天的身体**(秋冬卖外套、针织,用身体演"暖")
- 缩一下肩、手缩进袖子、搓手哈一口气、下巴埋进领子或围巾、原地跺两下脚(都稳,小;哈白气见 `scenes/snow.md`)

**13. 促单手势**(不指画面角落和购物车)
- 说"you"时,食指朝镜头点两下(稳,小)
- 说"same one"时,拇指往自己身上勾两下(稳,小)
- 说"come get it"时,四指朝自己勾两下(慎用,小;勾成一根手指像挑逗)

**不建议的动作**(即梦做不好,用替代动作)
- 手指插进腰头往外拉 → 双手叉腰,扭一下
- 从口袋里掏出手机、钥匙 → 手插口袋,拍一下鼓起来的口袋
- 把上衣塞进去一角 → 生图时就画成塞好的样子
- 小跑 → 快走几步
- 弯腰捡东西 → 下蹲
- 踮脚 → 删掉(小屏看不出来)
- 系带子、扣扣子、拉拉链、调肩带、脱衣服、换上衣裤子裙子 → 只展示穿好的样子(外搭类正在穿、针织衫滑肩见第 9 类)
- 360 度转圈 → 转过去停住,再转回来
