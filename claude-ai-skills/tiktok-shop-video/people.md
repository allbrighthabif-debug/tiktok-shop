# 人物外形参考(美国普通人)

写人设(第 1 步上)、人物描述(`03-image.md` 第六节、即梦提示词【人物】)和复刻换人(`replicate.md`)时用:先按人设的族裔挑一组,再按职业挑一组,两组各取 1-2 样拼起来,再加人设自己的视觉记忆点。是参考,不整组照搬;同一个人在多条视频里保持同一套。"AI 易错"那几条写进提示词的"不要"里。

**通用写法**:像手机随手拍的普通人,衣服有穿过的褶皱和磨损。皮肤按 `03-image.md` 第六节第 4 条写(毛孔若隐若现、不磨皮);下面写到脸上的晒斑、雀斑、黑眼圈、汗、潮红不默认加,人设选了它当记忆点才写。
**不要**:娃娃脸、塑料皮肤、模特化、浓妆、对称的卡通脸、AI 光晕、手指变形、多余肢体。
**底线**:不夸张、不漫画化,不评价长相和肤色,不拿族裔开玩笑;同一族裔里也写出个人差异,不要只画一种典型样子。

## 一、按族裔
### 墨西哥裔
- 年龄:年轻一代偏街头休闲,中年偏务实生活感
- 发型:深棕中长自然微卷发,随意低马尾或半扎,带碎发 / 两侧推短、顶部 3-5cm 自然抓起的短发 / 黑茶色中分及肩发,发尾微外翘
- 穿着:灰色水洗宽松连帽卫衣 + 深蓝直筒微磨损牛仔裤 + 黑色工装夹克
- 鞋和配饰:穿出折痕的全白 Air Force 1、Converse 帆布鞋;细金属圆环耳环、银质小十字架项链、智能手表
- 记忆点:暖橄榄或小麦色皮肤,有真实毛孔和晒斑;浓密自然的眉毛;说话时手势多、接地气
- AI 易错:肤色被调成发脏的橘色;不要帮派或单一劳工的刻板形象

### 中美洲裔(萨尔瓦多、危地马拉、洪都拉斯)
- 发型:齐肩黑发,发质粗硬有自然光泽 / 很短的寸头 / 碎发较多的随手高马尾
- 穿着:军绿或白色基础 T 恤 + 敞开穿的蓝黑或红黑格纹法兰绒衬衫 + 黑色束脚休闲裤
- 鞋和配饰:深灰或黑色耐磨徒步鞋、舒适健步鞋;细红绳手链、超市帆布托特包
- 记忆点:穿着以实用舒服为主,没有刻意搭配;像社区超市、街区里常见的普通居民
- AI 易错:和墨西哥裔画成一模一样;格子衬衫纹理糊掉或扭曲

### 加勒比裔(波多黎各、多米尼加)
- 发型:自然蓬松卷发 / 利落的 box braids 编发 / 低渐变短发,顶部留卷
- 穿着:明黄或宝蓝复古印花短袖 T 恤 + 浅灰宽松卫裤
- 鞋和配饰:Vans Old Skool、Jordan 1 低帮;金色或银色中等粗细项链、亮色棒球帽
- 记忆点:颜色大胆;表情丰富、自在;卷发和编发很有辨识度
- AI 易错:画成夸张的说唱歌手;卷发和编发糊成面条状

### 非裔
- 发型:干净的寸头 / 紧凑的自然短卷发 / 顺滑中长细编发或贴头皮编发
- 穿着:没有大 logo 的纯黑厚连帽卫衣 + 深卡其直筒工装裤
- 鞋和配饰:New Balance 990 灰色复古跑鞋;简约金属耳骨环、纯色棒球帽
- 记忆点:自然哑光的皮肤光泽;廓形干净,街头和通勤之间;眼神松弛
- AI 易错:深色皮肤打光发灰失真;发际线边缘糊;不要堆大 logo

### 白人(郊区、中西部、南方)
- 发型:天然金棕或浅栗色微卷中长发,随性 / 侧分短发,顶部 4-6cm 自然纹理 / 抓夹半扎,两侧碎发
- 穿着:燕麦色华夫格长袖 + 水洗旧牛仔夹克 + 黑色微修身休闲裤
- 鞋和配饰:白色板鞋、黑色高帮帆布鞋;细金或银项链、玳瑁圆框眼镜或墨镜
- 记忆点:脸颊和鼻梁自然的红润和浅雀斑;邻家日常感,没精心打扮
- AI 易错:好莱坞式完美假脸;皮肤苍白如纸;雀斑像贴图

### 亚裔
- 发型:黑茶色纹理碎短发 / 锁骨发微卷,发尾蓬松 / 露额头的清爽短发或背头
- 穿着:藏青圆领针织衫 + 下摆露出的白 T + 浅灰垂坠直筒西裤
- 鞋和配饰:白色德训鞋、基础低帮板鞋;细银戒、简约金属腕表
- 记忆点:黑发顺、发流清楚;都市日常、干净利落
- AI 易错:书呆子刻板形象;眼睛被刻意画成眯缝眼

## 二、按职业(上班时的样子)
### 护士
- 发型:高马尾或低丸子头 / 内扣齐肩短发 / 清爽短发
- 穿着:藏青或天蓝刷手服(有日常褶皱)+ 白色打底衫
- 鞋和配饰:全黑或全白厚底缓震跑鞋(Hoka、Brooks);卡通卡套伸缩工牌、硅胶电子表、胸袋插几支彩色笔
- 记忆点:眼下淡淡的值班黑眼圈;口袋里插着剪刀、小手电、便签本;动作利落
- AI 易错:工牌字变乱码、挂绳错位;画成时装模特

### 建筑工人
- 发型:汗湿微乱的寸头 / 头巾包住头发 / 后脑扎一小束
- 穿着:亮橙或亮黄反光背心 + 洗得发白的灰蓝短袖 + 棕色双层膝盖帆布工装裤
- 鞋和配饰:有水泥和泥土痕迹的钢头工作靴;贴着贴纸的安全帽、挂脖护目镜、沾灰手套
- 记忆点:脸和手臂明显的晒痕分界线;体格结实;衣服鞋子上洗不掉的灰和磨损
- AI 易错:衣服崭新发亮;反光条画错;安全帽变形

### 卡车 / 外卖司机
- 发型:被棒球帽压扁的短发 / 后脑随手束发 / 微卷短发
- 穿着:深灰速干 Polo + 弹力工装短裤或多袋工装裤
- 鞋和配饰:记忆棉防滑轻便鞋;胸前挂偏光墨镜、防晒冰袖、腰上挂钥匙串
- 记忆点:靠车窗那只手臂晒得更黑;动作快、赶时间
- AI 易错:画成邋遢流浪汉;墨镜反光成怪色块

### 仓库分拣员
- 发型:平头 / 没碎发的低马尾 / 清爽短碎发
- 穿着:荧光黄短袖工装 T 恤 + 深黑多口袋工装长裤
- 鞋和配饰:全黑钢头安全鞋;腰上扫码枪套、单耳无线耳机
- 记忆点:走路快;额头脖子有薄汗,神情专注
- AI 易错:闲散站姿;扫码枪和手臂粘在一起

### 餐厅后厨
- 发型:发网或厨师帽盖住的短发 / 收在帽子里的发髻 / 额角汗湿碎发
- 穿着:白色或黑色双排扣厨师服 + 黑白千鸟格裤 + 防水围裙
- 鞋和配饰:黑色防滑一脚蹬厨师鞋;脖子上挂擦汗毛巾
- 记忆点:脸被炉火烤得潮红有光;围裙上有面粉和酱汁痕迹
- AI 易错:米其林摆拍感;双排扣不对称、格纹错乱

### 美发美甲师
- 发型:冷棕挑染层次短发 / 几何短发 / 有设计感的低发髻
- 穿着:黑色长款修身针织衫 + 黑色多口袋围裙
- 鞋和配饰:软底乐福鞋或白色平底鞋;自己做的精致美甲、几何金属耳环、围裙插着剪刀和梳子
- 记忆点:手指灵巧;健谈、留意细节
- AI 易错:浓妆艳抹;拿剪刀的手指变形重叠

### 老师
- 发型:栗色及肩卷发 / 鲨鱼夹低马尾 / 男士侧分短发
- 穿着:燕麦色针织开衫 + 白色棉衬衫 + 深色直筒裤或及膝裙
- 鞋和配饰:平底乐福鞋;挂颈胸卡、圆框眼镜、皮表带指针表
- 记忆点:眼神温和;手里拿着改作业的红笔或备课本
- AI 易错:凶巴巴的老学究;镜框和书本线条画歪

### 办公室上班族
- 发型:及肩直发 / 干练中马尾 / 男士短背头
- 穿着:挽袖到手肘的浅蓝或白衬衫 + 藏青或深灰九分直筒西裤
- 鞋和配饰:低粗跟单鞋或深棕德比鞋;细边眼镜、通勤托特包或电脑包、智能手表
- 记忆点:手拿外带咖啡杯或笔记本电脑,步子快
- AI 易错:全套黑西装打领带;咖啡杯和笔电边缘扭曲

### 全职妈妈 / 全职爸爸
- 发型:随手扎的丸子头或抓夹 / 自然披散微卷 / 低马尾
- 穿着:宽松套头卫衣 + 黑色瑜伽裤
- 鞋和配饰:一脚蹬休闲鞋、羊毛健步鞋;大容量双肩妈咪包、手腕套着备用发圈、挂满钥匙的腕绳
- 记忆点:有点累但很亲和;一切以方便、耐脏为先
- AI 易错:画成精致名媛;瑜伽裤画成反光塑料

### 大学生(18-22 岁)
- 发型:蓬松自然卷长发 / 赶早课随手扎的高马尾 / 微乱短碎发
- 穿着:大学字母复古连帽卫衣(宽松)+ 浅蓝直筒牛仔裤或卫裤
- 鞋和配饰:Vans、New Balance 574;挂满徽章和小公仔的双肩包、挂脖头戴耳机、帆布袋
- 记忆点:随性、没有职场修饰感
- AI 易错:画成街拍博主;背包带和耳机粘在一起

### 健身教练
- 发型:高马尾或拳击辫 / 微汗短碎发、寸头 / 丸子头
- 穿着:修身速干背心或运动内衣 + 高腰哑光健身裤或运动短裤
- 鞋和配饰:训练鞋或跑鞋;蛋白粉摇摇杯、运动手环、迷你弹力带
- 记忆点:体态挺拔,线条紧致但不夸张;健康的晒色
- AI 易错:画成爆筋健美怪;健身裤怪异反光褶皱

### 退休老人(60 岁以上)
- 发型:蓬松整洁的银白短发 / 淡白短卷发 / 微白后梳短发
- 穿着:针织开衫 + 格纹棉衬衫 + 松紧腰直筒休闲裤
- 鞋和配饰:软底防滑健步鞋;挂绳老花镜、皮表带手表、保温杯
- 记忆点:眼角嘴角自然的笑纹;动作从容
- AI 易错:画成病态衰老;皱纹像刀刻一样僵硬
