# 框架库

框架 = 钩子后面的整条视频结构:每一段干什么、大概几秒。本库 30 个框架,按"这条靠什么打动人"分 10 类机制,**不分品类**,任何商品都能套。

## 怎么用
1. **先选机制,再选框架**:这条视频靠什么打动人(痛点、对比、效果、好奇、身份……),在那一类里挑一个框架。**选完核对"适合"那一行,和商品、拍摄形式对不上就换。**
2. **时长**:下面秒数按 25 秒写,实际按本条时长等比例缩放(默认 20-22 秒)。**全片不超过 30 秒。**
3. **CTA 位置**:每条软 + 硬两次(短于 18 秒只放结尾一次)。软 CTA 放在主卖点第一次证明之后,硬 CTA 约 80% 处到结尾,都叠在展示画面上说,不单独占一段;硬 CTA 可以放在最后收口。下面各框架标的"CTA 写法"是硬 CTA 的口吻。详见 cta.md。
4. **商品 3-6 秒内出现**(platform-2026.md)。每个框架的第一段都要满足这一条。
5. **轮换**:同一个对话里的几条换着用不同框架;用户说以前用过哪个,也避开。
6. **价格**:框架里的价格,别家、商店、修理厂的可以报真实数字;我们商品自己的价格、原价、折扣百分比不报,用"没花多少""一顿午饭钱""现在在打折"。CTA 不用命令句(见 cta.md)。
7. 框架是骨架,内容用商品事实和分析素材填。库里没合适的,可以自己编结构,交付时标"库外新写"并说明每段在干什么。
8. 用户说"换个框架"或"再出几个结构":按不同机制列候选,每条一行(框架名|每段干什么),每轮不重复。

## 5 条底层心法
1. **错方案觉醒**:不是"你有痛点,我卖解药",是"你之前失败是因为用错了方法"。观众从"我好笨"变成"原来是被旧方法坑了"。
2. **降门槛是 demo 类商品的必备段**:看完痛点,观众最怕"我不会装、太麻烦"。要有一段"安装超简单、不用工具、放上就能用"。
3. **差一点**:最爽的那一下(结果、价格、反转)往后压,全程让人觉得"就快揭晓了"。开头承诺的东西一定要兑现。
4. **旧方案对比四种起手**:演笨拙(手忙脚乱)、说痛点(原盒发霉)、纠正坏习惯(整晚开着灯)、对比价格(修理厂要 $150)。
5. **视觉证明比口头说服重要**:不要告诉观众它有多好,直接演示给他看。每条视频必须有一个"视觉证明时刻"(切番茄证明刀快、吸泥水证明吸力大、泼水证明防水),静音也能看懂。参数罗列(电机转速、电池容量)留不住人。

## 一、痛点驱动(先让人难受)

**F01 痛点 + 方案 + CTA**(三段基础版)
0-5s 痛点钩,商品同画面 → 5-23s 商品解决问题 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:痛点人人都有、一句话能说清的商品 | 常搭钩子:2 痛点共情、5 避坑 | 样本 #23 #25 #83 #97

**F02 轻度痛点 → 升级痛点 → 抛出产品**
0-3s 轻度痛点(小麻烦),商品在画面里 → 3-8s 升级痛点(把后果放大:更贵、更脏、更危险、更丢人)→ 8-23s 产品出场解决 + 1-2 个证据 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:痛点平时被忽视、放大后才让人紧张的商品 | 常搭钩子:2 痛点共情、5 避坑

**F03 痛点 + 效果验证 + 降门槛 + CTA**(demo 铁三角)
0-4s 多重痛点罗列 → 4-12s 效果验证(打火机测气流、前后对比)→ 12-23s 降门槛(安装简单、不用工具) → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:需要安装、看着麻烦的商品 | 常搭钩子:1 结果先行、2 痛点共情 | 样本 #69

**F04 痛点画面 + 拦截 + 使用细节**
0-4s 恶心、烦人的痛点画面(拽出一团头发)→ 4-14s 商品把问题挡住 → 14-23s 吸盘、折叠等使用细节 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:卫浴、清洁、除味这类"眼不见为净"的小工具 | 常搭钩子:2 痛点共情

## 二、竞品驱动(踩同类替代品,不踩现状)

**F05 竞品痛点 + 新方案**
0-4s 观点、效果或人群钩 → 4-12s 专踩别的同类有多坑(挑型号、起泡、要带线)→ 12-23s 我的商品解决 → 23-25s 收尾(硬 CTA 收口,或一句反应)
和痛点驱动的区别:痛点踩"没有它多惨",这个踩"别的同类多坑"。
适合:有明确同类竞品的商品 | 常搭钩子:4 反差反转、5 避坑 | 样本 #22 #93

**F06 价格断崖 + 踩老款 + 高密度演示 + CTA**(收割款)
0-3s 价格断崖钩 → 3-9s 踩传统老款 → 9-23s 快速切多个场景演示 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:价格有冲击力、用法多的商品 | 常搭钩子:6 价格利益

## 三、向往驱动(先给美好画面;不适合"没有它会出事"的商品)

**F07 美好愿景 + 使用细节 + CTA**
0-4s 理想画面,商品在画面里("浴室像新装修")→ 4-23s 使用细节 + 为什么有效 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:让生活变好看、变舒服的商品 | 常搭钩子:1 结果先行、8 真心推荐 | 样本 #95

**F08 美好愿景 + 降门槛 + 效果验证 + CTA**
0-4s 理想画面 → 4-11s 傻瓜式安装 → 11-23s 效果验证 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:家居神器、收纳 | 常搭钩子:1 结果先行

## 四、反差 / 反转驱动

**F09 假抱怨反转**(正话反说)
0-3s 假抱怨("我要退了这个")→ 3-15s 正话反说顺便塞卖点("不是因为它 5 秒就热……")→ 15-23s 揭晓真相(其实是买贵了、相见恨晚) → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:低价福利款、相见恨晚型 | 常搭钩子:4 反差反转 | 样本 #90 #95

**F10 旧方案笨拙对比**(可做对话)
0-5s 演旧方法手忙脚乱,商品在一旁 → 5-13s 新方案登场,轻松搞定 → 13-23s 多场景演示 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:消耗品、替代旧做法的商品 | 常搭钩子:4 反差反转、9 身边人证明

**F11 反常识断言**
0-4s 反常识一句("你穿睡裤过机场?")→ 4-23s 解释 + 卖点 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:用法或外观和常识反着来的商品 | 常搭钩子:3 好奇悬念、4 反差反转 | 样本 #83 #93

**F12 锚价"聪明购物者"**
0-4s 高价锚钩("看着像 $60,我花的远没那么多")→ 4-23s 展示质感和细节 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:平替、看着贵用着便宜的商品(**锚价必须真实**)| 常搭钩子:6 价格利益 | 样本 #49

## 五、好奇 / 反常识驱动

**F13 反常识 + 逻辑自洽 + 真诚人设**(清仓、福利款)
0-4s 反常识钩("亏一块钱卖对生意有好处")→ 4-13s 逻辑自洽(库存、沉没成本)→ 13-23s 真诚人设(怕过时变垃圾、宁亏也希望有人用) → 23-25s 收尾(硬 CTA 收口,或一句反应)
心法:说出商家的难处,给极低价一个合理理由,打消"便宜没好货"。
适合:清仓、福利、低价引流 | 常搭钩子:3 好奇悬念、6 价格利益

**F14 八卦钩 + 降门槛 + 效果**
0-4s 八卦钩("邻居老婆偷偷告诉我")→ 4-11s 降门槛 → 11-23s 效果验证 → 23-25s 收尾(硬 CTA 收口,或一句反应)
心法:不是我在卖,是我把偷学来的告诉你。
适合:生活小工具 | 常搭钩子:9 身边人证明、3 好奇悬念

**F15 多用途清单**
0-3s "这个 $X 的东西我找到 3 种用法,第 3 个最离谱" → 3-23s 倒数展示每种用法,各配一个场景 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:一物多用的商品 | 常搭钩子:11 盘点清单 | 样本 #47 #27

**F16 榜单压轴**(Gemini 调研)
0-3s "X 大好物榜单"钩,**主推款在开头画面里露出** → 3-14s 快速过前几项 → 14-23s 主推款压轴,讲它最硬的卖点 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:能和同类或同场景商品放在一起比的商品 | 常搭钩子:11 盘点清单

## 九、效果证明驱动

**F22 效果可视验证 / 前后对比**
0-3s 效果甩脸或前后反差定格("便携空调到底多冷,我证明给你看")→ 3-15s 商品出场,演示转变过程 → 15-23s 左右或前后画面极致对比(一半用一半不用、金属结冰) → 23-25s 收尾(硬 CTA 收口,或一句反应)
CTA 写法:利益点
和怀疑打脸的区别:不带怀疑情绪,直接甩效果。
适合:效果看得见的商品 | 常搭钩子:1 结果先行 | 样本 #22 #24 #47

**F23 怀疑打脸 / 极端测试**
0-4s 自问怀疑("是智商税吗?")或替观众说出怀疑 → 4-15s 不间断实测,可以做极端测试(拉扯、泼水、用力刮)→ 15-23s 揭晓反转结果 → 23-25s 收尾(硬 CTA 收口,或一句反应)
CTA 写法:不情愿式 CTA("我也不想承认,但……")
适合:看着像智商税的低价品,或看着夸张的高价品 | 常搭钩子:4 反差反转、5 避坑 | 样本 #28 #43 #68

**F24 满足感 / ASMR**(Gemini 调研)
0-3s 脏乱、原始状态的视觉冲击,或 ASMR 原声,商品已在手 → 3-15s 沉浸式清理、刮擦、收纳过程,极少说话 → 15-23s 焕然一新的成果特写 → 23-25s 收尾(硬 CTA 收口,或一句反应)
CTA 写法:一句话 CTA
心法:看得爽就能看完,画面本身就是证据。
适合:清洁、收纳、切割这类过程解压的商品 | 常搭钩子:1 结果先行(可以没有口播钩,靠声音和画面)

**F26 开箱**(Gemini 调研,改成单品)
0-3s 拆包裹特写,商品包装入镜 → 3-15s 取出商品,展示外观和核心功能 → 15-23s 第一反应和真诚评价 → 23-25s 收尾(硬 CTA 收口,或一句反应)
适合:包装有看头、第一眼有惊喜的商品 | 常搭钩子:3 好奇悬念、8 真心推荐

**F27 回复评论**(Gemini 调研)
0-3s 屏幕挂一条观众评论 + 第一句直接回应("是的,它真能……")→ 3-15s 直接演示或拿出证据回答疑问 → 15-23s 强调问题已解决 → 23-25s 收尾(硬 CTA 收口,或一句反应)

**F29 跟我过一天(日常植入)**

适合:随身用、每天用的商品;有具体工作或生活场景的人群 | 常搭钩子:10 故事开场、2 痛点共情 | 常配拍摄形式:跟拍、第一视角

**F28 极简三段**
0-5s 痛点钩(短句)→ 5-23s 效果展示(短句) → 23-25s 收尾(硬 CTA 收口,或一句反应)
CTA 写法:短句

**F30 复购开场 + 十层理由**(用户提供的爆款框架)
0-2s 复购场景钩,商品在画面里(正在下单第二个、抽屉里已经有一个、拆第二个快递)→ 2-4s 稀缺性(上次差点没抢到)→ 4-6s 信任背书(身边人、评论都在说)→ 6-8s 质量升级(这一款比以前的、普通的强在哪)→ 8-11s 感官体验(上手捏、穿、用,证明画面)→ 11-13s 概念塑造(一句好记的说法,如"厨房里的第三只手")→ 13-15s 权威对比(跟贵的、专业的比不输)→ 15-18s 解决痛点(证明画面)→ 18-20s 人群泛化(家里谁都在用)→ 20-23s 场景拓宽(快切 2-3 个场景)→ 23-25s 收尾(硬 CTA 收口,或一句反应)
心法:先甩结果"我又买了",第一秒就信了一半;后面每一层补一个"为什么值得";最后用人群泛化、场景拓宽把"跟我有关"的人放到最大。
- 每段一句短话(8 个词以内),靠画面快切,镜头策略通常选跳剪。
- 短于 20 秒:省掉概念塑造、权威对比、质量升级,只留复购、稀缺、感官、痛点、泛化或场景。
- 复购是主观吹,可以说;稀缺、背书(销量、评论数)、质量升级必须规格卡或详情页上有,没有就省掉这段,不编。权威对比不点名别家牌子,"和贵的一样"要有依据;我们自己的价格不报数字。
- 人群泛化只在后段,前面照样打透一个人群。
适合:有销量、有口碑的复购型商品,收割款 | 常搭钩子:8 真心推荐、9 身边人证明 | CTA 写法:真实紧迫(回扣稀缺)

## 两个容易混的段落
- **效果验证**:硬核证明"有用"(打火机、结冰、前后对比)
- **场景演示**:覆盖多种用途,证明"百搭"(西瓜、餐盘、烤盘都能用)
按需要选,不要混着写。
