# 第 1 步:文案 + 分镜(分镜规则)

分镜和文案在第 1 步一起写、一起交(交付格式在 `01-copy.md` 第十一节)。本文件管画面怎么安排:镜头方案、开场、证明画面、情绪、场景、参考图。只让用户看懂怎么拍;细节写进第 3 步的视频提示词。

## 一、输入
- **文案**:和分镜同时写,每句台词都要有对应的画面。
- **拍摄形式**:按 `01-copy.md` 第四节定;用户说"换个形式",台词和画面一起重写。
- **商品图**:证明动作只能拍商品真有的功能;商品的外观、结构以商品图为准。
- **用户已有的参考图**(可选):用户手上已经有想用的场景图或人物图,就照这张图来安排画面和动作。

某句台词拍不出来,就换台词或换画面,直到两者对得上(按"画面先行")。已经定稿后再发现拍不出来,说明哪一句有问题、建议怎么改,等用户确认再改。

## 二、先定镜头方案
**1. 视线**:看台词是对谁说的,和谁拿手机无关。
- 对观众说("you guys need this")→ 看镜头
- 对画面里的人说、自言自语、被抓拍 → 不看镜头
- 两人对话 → 主要看对方,偶尔瞟一眼镜头

**2. 镜头、机位高度和景别**:跟拍摄形式走。全片按 iPhone 17 手机实拍(见 `iphone17.md`),镜头栏写用哪个镜头。
| 形式 | 默认镜头 | 默认机位 | 画面稳不稳 |
|---|---|---|---|
| 前置自拍 | 前置 | 略高、俯角,近景 | 手持,轻微晃动 |
| 第一视角 POV | 主摄 1x(空间窄用 0.5x) | 从眼睛的高度往下看手 | 手持,轻微晃动 |
| 固定机位 | 主摄 1x | 平视或略低,中景 | 稳,不晃 |
| 第三方手持 | 主摄 1x | 平视,中景到全身 | 手持,轻微晃动 |
| 跟拍 | 主摄 1x | 平视,中景,人在走 | 手持,跟着走 |
| 画外音 + 纯商品画面 | 主摄 1x | 俯拍或平视台面,近景到特写 | 固定或手持轻微晃动 |
| 开箱 | 主摄 1x | 俯拍台面或 POV,开头近景拍快递盒,拿出商品时到特写 | 固定或手持轻微晃动 |
- 机位和形式对不上 = 一眼假(自拍却给了平视全身)。
- 只用手机拍得出来的运镜:推近、拉远、随手横摇、跟着走、低角度、特写。不用环绕 360°、升空俯冲、螺旋这类要设备才拍得出的运镜。

**3. 镜头策略**(**不设默认**,按拍摄形式和证明内容选,标签行写半句理由;不管哪种,都是即梦**一次生成整条**,最长 30 秒,不分段、不拼接):
| 策略 | 适合 | 怎么排 |
|---|---|---|
| 一镜到底 | 第三方手持、跟拍、对话互动;证明的是一个连续过程(拆开到装好、戴上拉下);要像偷拍、情绪真实 | 一条连着拍完,时间只表示动作往前推进 |
| 跳剪 | 前置自拍口播;要证明好几个卖点;前后对比;换场景;时间紧、信息多 | 一个画面一个镜头,镜头之间硬切;露脸、只出手都可以 |
| 多镜头连续 | 有情节、要换机位 | 镜头一 / 二 / 三,写清楚从哪里换到哪里 |
- 可以混用:比如开头一镜到底跟拍,进入卖点证明后跳剪。

**4. 景别怎么变(不能突兀)**
景别从远到近:全景(整个人带环境)→ 中景(腰部以上)→ 近景(胸口以上)→ 特写(脸,或手加商品)→ 大特写(商品局部)。
- **一次只变一档,不跳级**:全景不能一下跳到特写,中间要经过中景、近景。
- **一镜到底**:景别靠人的动作变,不靠切镜。拍的人往前走 / 往后退,或者主角把商品凑近镜头、走近 / 走远、转身、换只手、开始一个新动作;每次变化用 1-2 秒完成,跟着动作走,不突然。人不能站着不动一直说。
- **跳剪 / 多镜头**:相邻两个镜头只差一档景别,或者景别一样但换个角度;机位挪够 30 度,不然像卡了一下;切换点选在动作进行到一半的时候。
- **每 2-3 秒画面有一个变化(不管哪种镜头策略都要)**:切镜、景别变一档、换一个新动作、商品凑近镜头,有一种就行;不要整条一个景别、一个姿势。

## 三、开场 3 秒
开场画面配合钩子那句台词,两者说的是同一件事。
**第一帧优先级**:人在场景里 > 单独一个人;商品效果出现在场景里 > 单独展示商品。不用商品白底展示、商品摆拍开场。

**三条铁律**
1. **人已经在动**:开场那一下人正在做一件真事(推车、拎袋子、走路、喝咖啡、翻东西),不能摆好姿势站着等镜头。
2. **快**:开场的揭示动作在头 0.5-1 秒内完成,不慢慢移 2-3 秒。
3. **不放空镜头**:没有信息的空环境最多 1 秒。

**开场式**(挑一个,同一个对话里的几条换着用):
| 开场式 | 怎么拍 |
|---|---|
| 横移带出人 | 镜头快速横移,带一点运动模糊,一下把人带进画面 |
| 环境带到人 | 镜头先落在和场景相关的物件上,随手一带扫到正在做事的人 |
| 冷开场 | 第一帧就是动作最高潮(正在倒、正在撕、正在拉) |
| 一记冲击 | 第一帧就是结果、奇观,或前后对比同框 |
| 手先入画 | 手拿着商品快速进画面,人不露脸 |
| 边走边说 | 台词叠在走动的画面上,像自言自语 |
| 场景开聊 | 场景一立住,马上说第一句对话 |
| 问题现场 | 第一帧就是那个麻烦(乱、脏、坏、漏) |

- 写视频提示词时说"手持自然带过",不说"whip pan / 专业运镜"(即梦会拍出炫技感)。

**第三方手持、跟拍的开场(最容易拍呆)**
拍的人是一个真实在场的人(朋友、同事、家人),不是摄影师。开场要像"他顺手拿起手机抓拍到的",不是"主角站好等他拍":
- **镜头第一帧就在动**:拍的人在走、在转身、刚举起手机,画面带一点晃动;不从一个稳稳的构图开始。
- **主角不看镜头等拍**:第一帧主角正忙着自己的事,是被拍到的;要对镜头说话,也是先做事,再边做边转头说。
- **构图不完美**:人可以不在正中间、可以被门框或路人挡一下、可以先拍到半个身子再跟上。
- **拍的人离得近**:离主角 1 米左右,近景为主,跟着主角动;主角是在对拍的人说话、表演。不从远处固定拍(像监控)。
- **拍的人有存在感**:画外一句话、一声笑、跟着主角走的脚步,都能证明"有人在拍"。
- 反例(呆):主角站在画面正中,面对镜头,手里拿着商品,等一秒后开口说话。

## 四、证明画面
**段落配什么画面**(框架每一段先按这张表想画面,再写台词):
| 段落 | 画面类型 |
|---|---|
| 开头(为什么要用) | 开场式(第三节)里挑一个,人已经在动 |
| 痛点(不用会怎么样) | 问题现场:看得见的糟心事和它的后果(第八节"看不见的变成看得见的") |
| 塑品(为什么用这款) | 下表的证明画面;要比的时候用前后对比、同框对比 |
| 促单(为什么马上用) | 商品在手里或画面里;动作自然(接着用、看镜头说、放下),指向左下角可选 |

**卖货靠画面,不靠嘴说。**证明画面要让观众不听台词、眼睛就能看到效果。优先从下表挑最直观的那一种:
| 类型 | 例子 |
|---|---|
| 前后对比 | 用之前乱、脏、坏 → 用之后整齐、干净 |
| 极端测试 | 泼水、拉扯、踩、装满,东西都没事 |
| 效果特写 | 怼近拍:水珠滚落、污渍一擦就掉、密封严丝合缝 |
| 一气呵成的过程 | 一个动作就搞定,以前要好几步 |
| 容量数量 | 往里装,一直装,还能装 |
| 大小对比 | 和手、手机、硬币放一起比 |
| 结构细节 | 卡扣一按、拉链一拉、折叠收起 |
| 多场景切换 | 同一个东西在厨房、车里、户外都能用 |
| 真人反应 | 别人第一次用,愣住,然后惊讶 |
| 问题现场 → 解决 | 先看到麻烦,下一秒被解决 |
- **密度**:全片每 3 秒左右一个能直接看到效果的卖点画面;超过 5 秒没有,就补一个或删掉那段。
- **静音也看得懂**:关掉声音,光看画面也知道这个卖点是什么;靠嘴说、画面看不出来的,不算证明。
- **证明动作比台词早半拍**:手先开始捏,捏到最软那一下,台词正好说出来。
- **非证明句,商品也别离开太久**:讲痛点、讲故事时,商品可以在手边、在副驾、拿在手里没在用,但不连着好几秒完全看不到。
- 用户给了 Gemini 的商品分析(可视化卖点画面清单),优先用里面转化力高的画面,从高往低用。
- **说硬 CTA 时**:手里或画面里有商品;动作不规定,接着用商品、看着镜头说、把商品放下都行,指向屏幕左下角(购物车位置)只是可选的一种。
- **按文案规则来**(`01-copy.md` 第五节):主卖点 2 次证明,角度不同;次卖点各 1 次,1.5-2 秒快切,台词叠在画面上。
- **爽点就是证明画面本身**:全片最爽的一下,给足时间(至少 2 秒),观众看得清。
- **商品怎么用,按真实用法写**:穿、戴、摘、打开、装、拆这类动作按真实的方向和先后安排;看不出来就问用户。
- **动作要符合手能做什么**:前置自拍和 POV 只有一只手能用;要双手的动作,换机位或拆成一段固定机位。
- **商品 3-6 秒内出现在画面里**。
- **商品的样子不能变**:logo、包装文字、结构以商品图为准;有 logo 的那一面不做快速翻转;图上看不清的字,不要求画出清楚版。
- **人自己做得到**:两只手的动作分别写清左手、右手各做什么;一个人对自己做不到的动作不写(比如双手同时捏住自己两只袖口往外拉)。
- **东西要有来路**:道具第一次被拿起之前,场景里就写好它放在哪("右下角软凳上放着……");不写"从画面下方举起""拿出"这种凭空出现。
- **方向要顺手**:从哪边进来、用哪只手、放到哪边要顺,不横跨身体;左右一律按画面的左右写。
- **一个时刻只有一个大动作**:转身和打开盖子不同时做。但大动作要带一个小动作防呆板(低头确认一下、头发滑下来一缕)。
- **镜头动和人动分开写**:"镜头慢慢推近" 和 "她拧开盖子" 写成两句,不混在一句里。
- **固定不动的镜头至少 2 秒**,观众才看得清细节。

**表演要原生,不像拍广告**
- 不把商品举到脸旁边正对镜头展示;不一直笑着对镜头说;动作不用标准、干净。
- 边干自己的事边说,商品是顺手拿起来的。
- 留一点不完美:说到一半被打断、自己笑一下、手一滑没拿稳、回头看一眼别处。
- 开头直接从做事的中间开始,不说"Hi guys"、不自我介绍。

## 五、情绪(写成看得见的动作)
即梦看不懂"开心、惊讶、满意",只看得懂动作。画面那一栏**不写情绪词**,写成动作:
- **情绪 = 眼神 + 手 + 身体距离 + 节奏 + 语气词**,每次挑 2-3 样写。
- **表情有触发、有先后**:不写"她微笑",写"她低头看到结果,眼睛先亮一下,嘴角才慢慢扬起"。
- **放得开,情绪起伏要大**:吐槽就翻白眼、捂脸,惊喜就凑近镜头、拍一下大腿,得意就挑眉晃一晃商品。幅度靠具体动作给,不写"狂喜、暴怒、大哭"这种词(即梦会演崩)。全条从头到尾情绪要有起伏,不是一张脸用到底。
- **少靠脸,多靠手和身体**:想炫耀又装淡定 → 嘴上说"还行吧",手把东西抚平了三遍。

**情绪只从下表选**,不自己编;第 3 步视频提示词里的语气和表演,照抄表里的写法。
| 情绪 | 声音 | 脸和身体 |
|---|---|---|
| 开心 | 明亮,句尾上扬,带笑声 | 笑出牙,眼睛弯,肩膀跟着一耸 |
| 兴奋 | 音调提高,语速加快 | 眉毛抬高,眼睛睁大,身体往前一冲 |
| 惊喜 | 倒吸一口气,"wait—"停住 | 猛地凑近镜头,手捂嘴或拍一下大腿 |
| 得意 | 语速稍快,重读形容词 | 先自己看一眼再转向镜头,挑眉,把商品在镜头前晃一晃 |
| 吐槽 | 语速快,重读抱怨的词 | 翻白眼,撇嘴,手一摊或捂脸 |
| 怀疑 | 拖一下"hmm",语调往下 | 皱眉翻标签,往后退一步打量 |
| 服气 | 停一下,"okay okay" | 摇头笑出声,双手一举投降,再点头 |
| 真诚安利 | 声音压低一点、放慢,像跟朋友说真心话 | 看着镜头,身体往前凑一点 |
| 急着催 | 说得快、重 | 眉头一紧,身体往前凑 |
| 离不开 | 随口说,边说边干别的 | 不看就伸手拿 |

- **能量默认偏高**:美区日常说话音调起伏大、语速偏快、爱笑。按我们觉得"自然"的程度写,放到美区就显得冷淡。
- **放慢类情绪(真诚安利)一条最多 1 句**,只给最关键的那一下;算时长时这句按慢速算,不然会超时、拖节奏。

- **情绪线**:每条定一个"起点 → 转折 → 终点"(比如怀疑 → 惊讶 → 服气),转折就放在主卖点第一次证明那里。每格画面按当前情绪写动作,不是每格都同一张脸。
- 西语人群情绪更外放,动作和语气词更多。

## 六、场景要求(找图清单只在用户要时给)
先看 `scenes/00-index.md`,按商品和人设挑 1 个场景文件(用法见 `scenes/rules.md`),再写一行场景要求。**默认不出找图清单**;用户说"我去找图""搜什么"时才按下面的格式给。

**场景要求**:从证明动作倒推。要在水槽边演示,场景里就得有水槽;要边走边用,就得是能走动的地方。写清楚:
- 地点类型
- 必须有的道具和空间(证明动作要用到的)
- 时间段和光线
- 生活感:真实的地方是"刚用过、还没收拾"的样子,不是样板间

**找图清单(只在用户说"我去找图""搜什么"时给)**:每张图一块,格式:
```
场景图|找什么样的:一句话(地点、必须能看到的东西、光线)
  Pinterest 搜:"……" / "……" / "……"
  挑图看:……(一两个判断标准,比如"门要正对镜头""要有自然窗光")
人物图|找什么样的:一句话(年龄、身份、穿着、气质)
  Pinterest 搜:"……" / "……" / "……"
  挑图看:……
```
- **每张图给 3 个英语搜索词**,从具体到宽泛:第一个最贴近(地点 + 关键物件 + 风格),第三个是搜不到时的保底。搜索词要像真人在 Pinterest 会搜的短词组(3-6 个英语单词),不写整句。
- 加 `candid` / `iphone photo` / `aesthetic` 这类词能搜到更生活化的图;不加 `stock photo`、`studio`。
- 清单末尾附一句 Pinterest 找图提示:找到一张接近的图,点进去往下看"更多类似内容",或者用图片右下角的放大镜框选图里的场景、人物,搜相似的图,比换关键词更快。
- 通常 1 张场景图 + 1 张人物图;有第二个场景才加一张。
- 人物图写清:大概年龄、身份、穿着、气质,不写具体长相。
- 人群是拉美裔时,关键词加上对应的元素:花砖(talavera tile)、陶土地砖(saltillo tile)、暖色墙、绿植多、墙上的家庭照、摆得满满的。
- 用户已经发了参考图,就不列清单,写一句"场景按你的图"。
- **用户说"我去找图""搜什么"**:不管在哪一步,马上只给找图清单,不重复场景要求。

## 七、参考图(路线 A,用户要才走)
- **默认路线 B**:不生图,不问用户选 A 还是 B。第 1 步定稿后直接进第 3 步,场景按挑好的场景库文件写进视频提示词。
- **用户说"我去找图""做参考图"**:转路线 A,先给上面的找图清单;用户发回图后进第 2 步(`03-image.md`),照图重做场景图和人物图。
- 用户只发了参考图、没说要生图:不生图,第 3 步照着图把场景和人物写进视频提示词。
- B 的风险是长相、场景细节全靠即梦理解文字,多抽几次挑;同一个人物要在多条视频里保持一致时,建议用户走 A。
- **首帧图**默认不需要。只有开场必须是某个精确画面(比如前后对比同框)时才建议,写明原因。

## 八、交付
分镜不单独交付,和文案一起按 `01-copy.md` 第十一节交。第二到第五节的镜头、动作、情绪细节在内部想好,写进第 3 步的视频提示词。
- 每段画面一行,不超过 25 个字;不出表格。
- 自检在内部做(开场在动、证明够数、手能做到、一时刻一动作),有不过的才用一句话说出来。

## 九、改分镜
- 按 `01-copy.md` 第十二节:讨论时只回答;改动明确时只出改动的那几段;用户说"出完整版"才给整版。
- **"换开场"**:列 3 个不同开场式,每条一行 `开场式|第一帧画面`,挑中后只改开场那几格。
- **"换场景"**:从场景库换一个场景文件,重写场景要求(用户在走路线 A 时连找图清单一起重写),画面里跟场景有关的描述同步改。
- 改到台词:画面同步改。

## 十、这一步的偷懒信号(出现就重写)
- 景别跳级(全景直接到特写),或者一镜到底里景别没有人的动作带着就突然变了
- 超过 3 秒画面没有变化(没切镜、景别没变、没有新动作)
- 非证明句也在照台词字面演,或者用了复杂手部动作
- 商品举到脸旁正对镜头展示、人一直笑着对镜头,像拍广告
- 超过 5 秒没有能直接看到效果的卖点画面,或者证明画面要靠台词解释才看得懂
- 某一句台词没有对应的画面
- 出了表格,或者一段画面写成一大段
- 开场是人站着等镜头,或者空镜头超过 1 秒
- 第三方手持、跟拍的开场:镜头第一帧稳稳不动、主角正对镜头等着开口
- 主卖点只拍了一次,或者两次是同一个角度
- 画面里出现"开心、惊喜、满意、自信"这类情绪词
- 人物全程没有情绪起伏,一张脸用到底
- 前置自拍、POV 里出现要用双手的动作
- 场景要求写成一大段(应该一行),或者里面没有证明动作要用的道具
- 用户说要去找图,却只给了场景要求;或者用户没要,也出了找图清单
- 同一次回复里给了生图提示词或视频提示词
