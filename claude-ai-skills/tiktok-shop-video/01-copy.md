# 第 1 步:文案 + 分镜(文案规则)

第 1 步文案和分镜一起写、一起交:本文件管台词怎么写,`02-storyboard.md` 管画面怎么安排,两个都读完再动笔。交付格式见第十一节:一行标签 + 每段画面和台词 + 逐句中文 + 情绪线、场景 + 一行自检。分析、方案、检查都在内部做,用户说"展开方案"才输出。每句台词都先想好画面再写(第八节"画面先行");镜头运动、表情、光线细节写进第 3 步视频提示词。

## 一、输入
- **用户挑中的方向**(第 1 步上,`00b-direction.md`):场景、购买理由、开场都照这个方向写;参考爆款时没有这一项。
- **确认过的商品规格卡**(第 0 步,`00-spec.md`):商品事实的唯一依据。数字、尺寸、材质、功能、用法都照卡写(我们自己的价格不进台词);卡还没确认,不动笔。
- **商品图 / 详情页截图**:规格卡的来源。
- **分析要点**(Gemini 等做的,截图或文字,格式不限):痛点、爽点、买家原话、顾虑等素材。没有也能写,但【人群分析】里要写明"无分析素材,以下为推测"。里面的"可视化卖点画面"清单,证明画面按转化力从高往低用;"意想不到的用法"可以当方向。
- **人群**:第 0 步用户选定的人群场景(或用户自己指定的)。
- 素材直接取用,不复述、不总结给用户看。

## 二、素材分三类
| 类 | 来源 | 能不能写进台词 |
|---|---|---|
| 事实 | 商品规格卡(来自商品图、详情页) | 能。数字、尺寸、材质、功能、用法**只从规格卡取**;我们自己的价格不进台词(见第八节"CTA 和结尾") |
| 证据 | 分析里的买家原话、评论 | 能,当说法和证据用。分析里标 [推测] 的只当方向 |
| 推测 | 自己推的人群痛点、场景、说话方式 | 能写成场景和情绪,但在【人群分析】里标"推测" |

- 商品图上没有的功能,不能写(没有依据的"能兼容 X""能防 Y"都不行)。
- 分析里标了违规风险的说法,不出现。

## 三、人群分析(每条都在内部做;用户说"展开方案"才输出)
按用户给的人群推:是谁(年龄、身份、处境、说话口吻)、在什么场景用、最痛的一点、最想要的一点(好看、被夸、省事……)、最能打动他们的卖点(**就是本条的主卖点**)、他们会怎么说(一句,目标语言)、这条是拉新还是收割。每项标来源:[事实] [分析] [推测]。

**语言按人群定**:拉美裔 → 西语;二代拉美裔、双语家庭 → 英西混说;其他 → 英语。西语按西语样本重写,不从英语直译。

## 四、拍摄形式(第一个定,用户指定了就用用户的)
拍摄形式决定谁说话、说多少、手能做什么,文案要按它来写。
| 形式 | 适合 | 手能做什么 | 即梦生成难度 |
|---|---|---|---|
| 前置自拍 | 单人对观众说话、吐槽、安利(前置镜头对着脸拍,不是照镜子) | 一只手拿手机,只能单手小动作 | 易 |
| 第一视角 POV | 手上的演示、不露脸 | 一只手拿手机,另一只手操作 | 易 |
| 固定机位 | 纯演示、教程,双手都要用 | 双手自由 | 易 |
| 第三方手持 | 能拍全身、走动;拍的人可以是对话的另一方 | 双手自由 | 中 |
| 跟拍 | 边走边做事、跟着过一段生活 | 双手自由 | 中 |
| 画外音 + 纯商品画面 | 演示类商品(清洁、厨房、收纳、小工具),卖点靠手上操作就能证明;人不露脸,只出手和商品,台词是画外旁白 | 双手自由(手机固定或别人拿着拍) | 易(没有脸,不会脸崩、嘴型对不上) |
| 开箱 | 颜值高、包装好看、第一眼有惊喜的商品;或买家最担心"实物和图不一样"的商品。拆快递 → 拆包装 → 第一次拿出 → 第一反应 → 上手试 | 双手自由(固定或 POV) | 中(拆包装的手部动作容易变形) |
- **画外音 + 纯商品画面**:旁白也要口语,像边做边随口说,不像广告配音;手上带人设痕迹(美甲、戒指、工作服袖口)。
- **开箱**:拆包装最多占 3 秒,商品 3 秒内必须露出来;拆的动作写简单(撕开胶带、掀开盒盖、拿出来)。
- 用户没指定就推荐一个,优先生成难度低的;两人同框对话最难生成,只在对话明显更好时用。
- 证明动作要符合"手能做什么"(前置自拍做不了双手拧开罐子这种动作)。

## 五、框架段落里要装的东西
**按选中框架的段落顺序写。**下面这些都放进框架的段落里,不另起一套结构:
1. **钩子**:框架第一段的第一句,3 秒内。
2. **一条线**:痛点 → 主卖点 → 爽点。开头说的痛,就是主卖点解决的痛,也是证明画面拍出来的那一幕。
3. **主卖点证明 2 次,角度不同**:比如一次演示、一次真实场景实测(或对比、或别人的反应)。
4. **次卖点 2 个,各证明 1 次**:1.5-2 秒快切,台词叠在画面上。
5. **软 CTA + 硬 CTA**(见 `cta.md`)。
6. **结尾**:可以用硬 CTA 收口(真实紧迫 + 回扣),也可以是一句反应、回扣开头或最强的那个画面。硬 CTA 收口时,它就是最后一句,后面不再拖。

素材各自负责什么:
| 素材 | 在视频里的作用 |
|---|---|
| 痛点 | 让人停下、有代入感,放在钩子或紧跟钩子 |
| 替代方案差在哪 | 踩旧方法,商品出场之前 |
| 卖点 | 中段,主卖点加次卖点 |
| 爽点 | **就是证明画面本身**,全片最爽的一下 |
| 痒点(好看、被夸、有面子) | 一句话叠上去,不单独占一段 |
| 顾虑 | CTA 前后回应一个;或者当"回复评论"的开头 |
| 不贵(不报数字)、为什么现在买、送礼多买 | 硬 CTA |
| 买家原话 | 台词的说法来源;也可以直接当钩子 |

不是每块都要出现,每块只挑最强的一条。

## 六、时长和节奏
- **默认 20-22 秒**,最长 30 秒(即梦单条上限)。15-18 秒的短版:次卖点减到 1 个,其余不变。
- **字数按语速算**:英语约 3 词/秒 → 20 秒约 60 词,22 秒约 66 词,30 秒约 90 词;西语约 3.3 词/秒 → 20 秒约 66 词,22 秒约 73 词,30 秒约 100 词。这是上限也是目标:字数明显不够,即梦会用拖长音、停顿填时间,宁可缩短时长。有纯画面段落的框架,字数按比例减。
- **台词叠在画面上走**:软 CTA、次卖点、顾虑回应,都是一边播证明画面一边说,不单独停下来占时间。
- **拉新和收割分配不同**:拉新款在痛点和"原来还有这个"上多给时间,"不贵"轻轻带过;收割款在证明和顾虑回应上多给时间,"不贵、在打折"重点讲。

## 七、动笔顺序
1. **照挑中的方向写**:场景、痛点场景、人设(视觉记忆点、日常痕迹、说话性格)、购买理由、开场、卖点画面都照方向来,不重新另想一套。参考爆款时照原片骨架。
2. **不重复**:同一个对话里出的几条,钩子族、框架、CTA 说法、方向互相错开;用户说这个品以前用过哪个钩子、框架,也错开。
3. **人群分析**(内部做)→ 补全方向里没写的:主卖点和那条"痛点 → 卖点 → 爽点"的线。
4. **定拍摄形式**(第四节)。
(参考爆款时,第 5、6 条不做,钩子和结构按原片,见第十三节。)
5. **选钩子**(`hooks.md`):先问"这条最硬的是什么",一个主族,最多一个辅助族。
6. **选框架**(`frameworks.md`):先选机制再选框架;**选完核对框架的"适合"那一行和这个商品、这个拍摄形式对得上,对不上就换。**
7. **先想画面,再按框架的段落写台词**:钩子、主卖点两次证明、次卖点,每一处先在内部想好一句话的画面,过第八节"画面先行"的五条,过了再写台词。
8. **定 CTA**(`cta.md`):软、硬各一句;软 CTA 按 6 种类型轮换,软硬不说同一个词。
9. **找样本**(`voice-samples.md`):按标题搜 2-3 条同类商品或同类说话人,优先短样本,只学怎么说话。
10. **定时长和字数上限**。
11. **回头检查**:卖点都说到了"获得"那一层;"敢吹"至少 2 处;痛点是具体场景。

## 八、写作规则
**画面先行(最重要,每句都查)**
台词是叠在画面上说的。画面拍不出来,台词写得再好也没用。每一处先在内部写一句"画面是什么",过这五条:
1. **手机小屏一眼看得懂**:冲突和证明靠人的身体动作(缩、躲、跑、停住、推开),或一眼能看懂的对比(同框、前后)。不靠小道具、小字、细微表情,那些在屏幕上看不清。
2. **看不见的东西变成看得见的**:风、冷、热、味道、声音、疼、累这些,拍不出来;要换成它们造成的可见后果(头发被吹乱、呼出白气、捂住鼻子后退、捂耳朵、揉着手腕停下、瘫坐下来)。
3. **即梦做得出来**:一个时刻一个大动作;不写手指的精细操作、东西掉进小容器、液体精确倒进小口这种细动作;不写需要特效的奇观。
4. **商品看得见**:商品 3-6 秒内在画面里,证明画面里商品是主角。
5. **用法是真的**:台词和画面里怎么穿、戴、摘、开、装、拆,都按商品真实用法;看不出来就先问用户。
想不出能过这几条的画面,这句台词就换。展开方案时,每处画面各用一句话列出来。

**开头**
- 第一句就是钩子,没有铺垫。检验:删掉第一句,视频还成立 = 不合格。
- 用 `hooks.md`"开头三拍"时,三拍合起来算钩子(3 秒左右说完);顺着说那句是在把话题说清楚,不算铺垫。
- 商品 3-6 秒内出现(台词或画面)。

**痛点要具体**
- 痛点写成一个具体的糟心时刻(什么时候、在哪、正在做什么、出了什么看得见的事),照挑中方向的痛点场景;不写"很麻烦、不方便、很难"这种空话。
- 痛点之后加一句后果放大(更贵、更脏、更累、更丢人、更耽误事),再让商品出来解决。

**敢吹(带货最原始的东西)**
一个真心觉得这东西牛的人,兴奋地跟你吹它。正确但不燃的文案卖不动。
- **每条至少 2 处吹**:一处在开头或高潮,一处在收尾或 CTA 前。
- **怎么吹**:第一人称的主观感受(`best money I've spent all year` / `I'm obsessed` / `no me arrepiento`);以前和现在对比(以前每天……现在……);别人的反应(同事问了三次在哪买的、全家都在抢);夸张的行动(我又回去多买了两个、已经推荐给我妈了)。
- 吹的那几句配"兴奋"或"得意"情绪。
- **底线**:主观感受随便吹;客观事实(功能、数字、折扣、断货)只照规格卡,平台红线照旧。

**塑品:为什么偏偏是这款**
- 除了说商品自己的好(F 特征 → B 好处 → 获得),还要让观众知道为什么买这款,而不是随便一个(A)。
- A 的说法不固定,挑最顺的一种,也可以不比:跟旧的、普通款比(旧杯子半天就凉,这个一下午还烫嘴);跟老办法比(以前用夹子夹,一碰就掉);用前用后比;不比,直接秀一个别家没有的点(一按就弹开)。新奇小物、低价冲动品、时长太紧时,演示用起来爽就够了。
- 比的时候不点名、不露别家牌子,只说"我旧的那个""普通的那种";用前用后对比按 `platform-2026.md` 加 results may vary:剪辑时加一行屏幕小字 `Results may vary`,发布文案里也带上;即梦提示词里不写文字。

**每句都要干活(最常犯)**
- 每句台词只能是这四种之一:**痛点、卖点、证明、CTA**。抖机灵、夸人、感叹、接话、气氛句("你今天真好看""真羡慕""不会吧?")一律删掉,钩子除外。
- **卖点证明句,画面必须同步证明**:每个卖点在它被演示的那一刻说出来。说"盖子一按就开"时手正在按盖子,说"底下是防滑的"时正翻过来给镜头看。证明动作比台词早半拍开始,台词落在结果那一下。
- **其他句子不用照字面演**:痛点、讲故事、情绪反应、促单这些句子,画面跟着人物和场景自然走,和台词相关、不矛盾就行(说"昨晚又没睡好",画面是她揉着脖子走进厨房,不去演昨晚);画面还可以补台词没说的(讲痛点时商品已经在手边)。这几句的动作要简单(揉、叹气、靠回去),复杂的手部动作留给证明画面。
- **卖点说成感受或结果,用大白话**:轻、不漏、不烫手、一擦就干净;不绕弯、不写段子。
- **卖点翻译到"获得"那一层**:功能(是什么)→ 好处(有什么用)→ 获得(买了之后生活变成什么样)。台词说"获得",功能只在证明画面里带一下当证据。例:双层密封杯盖 → 不漏 → 往包里一扔就走,电脑文件再也没被泡过。获得通常是:省时间、省钱、省心、舒服、有面子、终于不乱了。
- **谁说话,按拍摄形式定**:
  - **前置自拍、第一视角、固定机位**:默认一个人从头说到尾。
  - **第三方手持、跟拍**:拍的人可以在画外说 1-3 句短话,每句不超过 6 个词,每句都要有用:引出卖点("Wait, what is that?""Wait, it does what?")或引出软 CTA("¿Dónde lo compraste?")。不能是纯捧场("真羡慕""你今天真好看")。主角说大部分台词,卖点由主角说出来、演出来。拍的人不入镜,只有声音。
  - **两人同框对话**:只在对话明显更好时用(见下面"对话体")。

**中间**
- 至少一个来自商品事实的具体数字或名称。
- 有真实顾虑时,回应一个。
- 中段要有让人看下去的理由:下一个证明、一个小悬念、还没揭晓的结果。

**说话方式**
- **口吻按人设的说话性格写**(冷幽默就短句、反讽;话痨热情就语气词多、一句接一句),全条保持同一种性格。
- 一句只讲一件事,尽量不超过 12 个词;长短句交替;不连续 3 句同一个句式。
- 情绪靠语气词、停顿、重复、自问("wait—""okay okay""I know!"),允许口语补丁和不完整的句子。

**有画面感的形容词(要多用)**
台词要让观众"感觉到"商品:摸起来、看起来、用起来、拿起来是什么样。只禁空洞的广告形容词(见第九节),有画面感的形容词必须有。
- 摸起来:soft、squishy、fluffy、smooth、silky、ice cold、warm;suavecito、calientito、fresquito、esponjoso
- 看起来:shiny、spotless、puffy、paper-thin、sparkly;limpiecito、brillante
- 用起来:light as air、one click、snaps right in、crispy;ligerito、facilito
- 重量大小:heavy-duty、tiny、fits in one hand、chunky;chiquito、pesadito
- 前面加程度词更像真人:so、super、literally、crazy、insanely;súper、bien、re
- 也可以用比喻,但要是生活里的东西:soft like a marshmallow、cold like it's been in the freezer。
- **每条至少 3-4 个**,而且放在证明画面那几句,边演示边说(手正在捏时说 "it's so squishy")。

**必须口语**
- 用缩写:it's、I'm、gonna、wanna、y'all、can't;西语用口语说法(pa'、ta' bien、ándale)。
- 每条至少 3 处填充词或口头禅:okay so、like、literally、honestly、ngl、wait、lowkey;西语 o sea、la neta、mira、ay、no manches。
- 允许不完整的句子、自己打断自己、小吐槽。
- 检验:念出来像给朋友发的语音吗?像读稿、像广告,就重写。

**不像广告**
- 先说自己的事(怎么发现的、出了什么糗、谁抢了我的),卖点在讲的过程中顺带说出来;不按卖点清单一句一句念。
- 不能连续两句都是"它能……""It has……""It comes with……"开头的功能介绍。
- 删掉铺垫、重复、空话。每 2-3 秒要有一个新信息。
- **单人口播时**,卖点包在"我的发现、我的经历、我的意外"里讲,不用商家式陈述句("采用 X 面料""适合 X 场合")。

**CTA 和结尾**
- **促单分两种**,至少用一种:
  - **机制促单**:折扣、库存、活动、赠品,只用规格卡上真有的;没有就不编。
  - **痛点促单**:结尾再提一遍不买的后果,再带出购物车("还想再泡一次电脑?反正我是不等了")。
- **台词里不报我们商品自己的价格**:具体价格、原价、折扣百分比都不说;可以说不带数字的(`it wasn't expensive`、一顿午饭钱、两杯咖啡的钱、现在在打折、没花多少)。别家的、商店的、修理厂的价格可以报真实数字("修理厂要 $150")。规格卡照样记价格,用来判断有没有折扣、能不能做机制促单。
- 按 `cta.md`:软 CTA 放在主卖点第一次证明之后,顺带一句;硬 CTA 在约 80% 到结尾,用"我"的口吻说清在哪买和真实紧迫,不用命令句,可以用硬 CTA 收口。视频短于 18 秒只在结尾放一次。
- CTA 后面只放有用的内容:回应一个真实顾虑、最强的那个证明,或者回扣开头。不用弱卖点或"好了我走了"凑时间;没有值得放的,就缩短视频。

**对话体(两个人以上说话时;只在对话明显更好时用,不是默认)**
1. 场景状态从头到尾一致(已经穿上了,就不能再说"我今天要穿它")。
2. 情绪和反应要归功于商品。删掉商品,这段戏还成立 = 重写。
3. 不要机械的一问一答:一个人可以连说两三句,另一个人只回一个词、一声笑;可以说半句;边做事边说。
4. 卖点由对方的追问、惊叹勾出来("Where'd you get that?""Wait, it does what?"),每个卖点当成一句 3-6 个词的回话给。软 CTA 最自然的来法就是对方问"在哪买的"。
5. 后半段必须落到:商品 + 卖点、在哪买、为什么现在买。

**美区雷区**
- 政治(枪、堕胎、疫苗、性别)、种族口音玩笑、"cheap Chinese product" 自嘲。
- `platform-2026.md` 的"不能碰"。

## 九、去 AI 腔(交付前逐条扫描,发现就重写那一句)
英语、西语台词:
- 二元对比外壳:It's not just X, it's Y / Not only… but also… / X isn't just for Y
- 广告模板句:Say goodbye to… / Whether you're X or Y… / Look no further / Introducing…
- 空洞形容词:amazing, incredible, seamless, elevate, transform, luxurious, game-changer, must-have, level up, revolutionary
- 假亲切铺垫:Trust me / Here's the thing / Let me tell you / Let's dive in
- 机器式三连:fast, easy, and effective 这类三个形容词排比
- 口号式结尾:Because you deserve it. / Your [X] will thank you.
- 独立使用的 "stop scrolling"(和人群连用可以,见 hooks.md)
- 广告按钮腔 CTA:Shop Now / Order Now / BUY NOW / Click the link now / Don't miss this offer、叫观众去点的命令句(Tap the cart / Grab yours,见 `cta.md`)

中文翻译也要像人话:不用"不是 A,而是 B""不仅……更……""真正""其实""本质上""更重要的是""关键在于";按意思口语化翻译,不逐词硬翻。

## 十、交付前检查(内部逐项跑;交付只写一行打勾,有问题的项用一句话说明)
1. 像广告、像段子吗?在堆空洞的广告形容词、演冲突?念出来像给朋友发的语音吗?有画面感的形容词够 3-4 个吗?有没有不干活的句子(不是痛点、卖点、证明、CTA)?→ 重写
2. 有具体事实吗?全是空话?→ 重写
3. 一条线通吗?开头的痛、主卖点、证明画面是不是同一件事?
4. 平台指标(`platform-2026.md`):停下、看完、下单、分享,每项引用原句;分享放不下可以写"无,原因:……"
5. `platform-2026.md` 的"不能碰"逐条对照
6. 字数没超上限;软、硬 CTA 的秒数位置对
7. 和样本、同品历史文案没有连续 6 个词相同
8. 删掉商品,这条视频不成立
9. 第九节 AI 腔全部查过
10. 钩子、每次证明都有一句过了"画面先行"五条的画面
11. **四问 + FABE**(只用来检查,不当写作顺序,不按 F、A、B、E 一句一句排):为什么要用(开头)、不用会怎么样(痛点)、为什么用这款(塑品)、为什么必须马上用(促单),四问都答到了吗?塑品里 F、B、E 都有吗?A 需要的话有吗?证据拍得出来吗?少哪个补哪个,补的时候还是包在人物自己的事里说

## 十二、改稿
- **用户在讨论、提问、提想法时**:只回答和讨论,不出新版。
- **改动明确时**("第三句换一下""开头换成 X"):只出改动的那几段(画面和台词一起),说明改了哪里,不重复整版。
- **用户说"出完整版"**:才给完整的一版。
- 用户改哪里只动哪里;改了台词,对应的画面一起改。
- **"换钩子" / "再出 N 个"**:列候选,每条一行 `族|[短画面]|第一句|中文`;组合不同的族、句式、素材,相邻两条不能只是换说法;每轮不重复,也不和这个对话里已出的重复。用户挑中后,只换开头,顺手调一下后面一两句让它接上。换完超出字数上限,可以压缩其他句子,但要在末尾说明改了哪几句。
- **"换个框架"**:按不同机制列候选,每条一行 `框架|每段干什么`,挑中后重写正文,钩子不变。
- **"换 CTA"**:只换 CTA 那两句。
- **"换个形式"**:换拍摄形式,按新形式重写(谁说话、证明动作、字数都会变)。
- **"换个人群"**:重做人群分析,主卖点和那条线跟着变,重写全文。
- 确认要明确:"1 / 定了 / 可以 / 就这个 / 确认"。"还行 / 不错"不算,追问"这版定了吗"。

## 十三、参考爆款(用户给了爆款分镜或脚本,说"照这个做"是仿写,说"反写"是换立场)

### 仿写("照这个做")
用户给的爆款分镜、脚本(反推的也算)当骨架,不再从钩子库、框架库里另选。
- **保留爆款的**:结构和节奏(每段干什么、几秒)、钩子类型、开场方式、镜头顺序、情绪起伏、软硬 CTA 放的位置。
- **用户给了 Gemini 拆出的"可复制骨架"**:按骨架逐段填我们商品的画面和台词;原片每个卖点画面都换成我们商品对应的画面,卖点画面不能比原片少;骨架里标了"原商品特有"的,不照搬。
- **必须换成自己的**:
  - 商品的功能、数字、用法:全部照规格卡。爆款里说的是别人商品的,不照搬。
  - 台词:按本文件的写作规则重写。意思可以像,但不能连续 6 个词和原片一样。逐句用三招:
    1. **近义词、相似词**:关键词换成意思相近、美国人嘴上真说的说法;不用词典里的书面词(一换就有 AI 味)。
    2. **加形容词**:有画面感、摸得着的形容词,按第八节,全条 3-4 个。
    3. **延伸**:往下多说一点,补我们商品的具体场景、细节或结果,照规格卡,不编。
    - 改完每句按语速核对(英语 3 词/秒,西语 3.3 词/秒),要装进原片那一段的秒数;超了就少延伸,只在关键句延伸。延伸后一句超过 12 个词,拆成两句(第八节"说话方式")。
  - 人物、场景:换掉,不照搬原片的人和地方。
- **爆款里有你商品做不到的画面或卖点**:在那一段标"(原片:……,我们的商品做不到,改成:……)",交付时一起给用户看。
- **和本 skill 的规则冲突时**:规格卡、"每句都要干活"、"画面先行"、平台红线优先;其余按爆款来。
- 标签行的"框架"写"参考爆款",钩子写原片的钩子类型;交付前多查一项:台词和原片没有连续 6 个词相同。
- 用户有原片或灰模视频的话,第 3 步传进即梦当参考视频(见 `04-video.md`"用灰模视频复刻")。有灰模时,每段的秒数和原片拆解的镜头切换点对齐,每段台词的长度按那一段的秒数写。

### 反写(用户说"反写",附爆款文案或脚本)
换的是立场,不是词。顺着爆款写容易像抄,反着写才有新爆点。第 0 步规格卡照常;第 1 步上不选方向,改成选立场:
1. 一句话拆出爆款的核心观点。
2. 给 3 个新立场:**相反**(不是 X,而是 Y)/ **反常识**(大家以为的 X 其实不对)/ **冲突**(两种人、两种做法、两个人顶起来)。每个配一个开头,按 `hooks.md`"开头三拍"写:爆款原观点顺着说 → 刹车 → 新立场。
3. **停**,等用户"选 N"或回 1 按推荐的。
4. 用户挑了之后,按本文件写完整文案和分镜:结构、节奏可以借爆款的,观点按挑中的立场,台词全部新写。
- 立场怎么反,最后都落回我们的商品:反的是"为什么买它"的理由,不是反对商品。
- 新立场要真实,正文能证明(照规格卡);不为了冲突说过头,不点名贬低别家品牌和商品。
- 标签行的"框架"写"反写爆款"。

选立场的交付格式:
```
当前:反写 选立场|下一步:等你挑一个

爆款核心观点:……
立场 1 相反|新观点:……|开头:"顺着说……" → "But…" → "拉回来……"(原文 / 中文)
立场 2 反常识|……
立场 3 冲突|……

推荐:立场 N,理由一句
回"选 N"挑一个 / 回 1 按推荐的继续
```

## 十四、这一步的偷懒信号(出现就重写)
- 没有有画面感的形容词,台词只剩功能介绍
- 念出来像读稿、像广告:没有缩写、没有口头禅,句子太工整
- 连续两句是"它能……"开头的功能介绍
- 台词停在"它有 X 功能",没说出观众买了之后获得什么
- 没照挑中的方向写,场景、人设、痛点另换了一套
- 痛点写成了形容词,没有时间、地点、动作、看得见的后果
- 整条没有一句吹的,读下来像说明书
- 参考爆款时:结构没按原片走、照搬了原片的台词或别人商品的卖点、做不到的画面没标出来
- 台词或画面里的商品规格、用法和规格卡不一致
- 用户还在讨论、提想法,就输出了完整版
- 某段只有台词没有画面,或者画面超过一行
- 有句子不是痛点、卖点、证明、CTA 之一(抖机灵、捧场、接话、感叹)
- 另一个人(包括画外拍的人)的台词在捧场、接话,而不是引出卖点或软 CTA
- 第三方手持、跟拍时拍的人说了超过 3 句,或者卖点是拍的人说出来的
- 台词在说一个冲突或效果,但画面上什么都没发生(靠小道具、看不见的东西、即梦做不出的细动作)
- 标签行有空项,或者"样本"写的编号在样本库里不存在
- 主卖点只证明了 1 次,或者两次是同一个角度
- 用户说"展开方案"时,人群分析没标来源,或者指标说不出对应的原句
- 同一个对话里几条用了同一个钩子族、框架或软 CTA 类型
- 出现商品图上没有的数字或功能
- 台词报了我们商品自己的价格、原价或折扣百分比
- CTA 用了叫观众去点的命令句
- 同一次回复里给了生图或视频提示词,或者画面里写了镜头运动、表情、光线细节
