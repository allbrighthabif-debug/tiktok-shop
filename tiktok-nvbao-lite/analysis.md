# 第 1 步:商品分析

卖鞋时先读 `shoes.md`,和这里冲突以它为准。

只给要看的:评论原话(有才出)、规格卡、【方案】(默认 2-3 个完整方案;用户已有明确方向时可以只给一个)、待核实;第一次做再加号卡。选题自检、买家画像、四问、FABE、九条、部件清单、顾虑、即梦能不能做,都在内部做,不写出来;用户发"出分析"才完整列出来。交完停;规格卡从用户确认起锁死。

**内部顺序**:确认产品和人物信息(规格、待核实的关键结构、号卡)→ 想清这条内容怎么发生、购买欲怎么形成(谁在做什么、为什么会注意到这只包、有什么值得继续看)→ 选合适的拍法和地点 → 第 2 步连贯写台词和关键动作 → 分配时间 → 第 4 步转成即梦提示词并检查。不先锁地点和风格再往里填内容。

## 一、输入
- 商品图、详情页:商品事实的唯一来源。
- 尺寸图:没有就问;用户说没有,尺寸写"缺",台词不说尺寸,只用实物比(放得下平板这类必须图上有依据)。
- 号卡:用户贴了就照用;第一次做、没有号卡,按第五节起一张。
- **活动信息**:券、折扣、买赠、包邮,有哪些、是不是长期的;用户没说就问一句,没有就写"无"。标题里的 Black Friday 这类短期活动不进台词。
- **评论**(可选,截图或用户粘贴的原话都算,按同一套处理):先出【评论原话】,再融进下面各项,原话附在用到的地方。评论是中文译文时,台词里还原成自然的英文口语。
- 图上有几个颜色、几只包,问清卖的是哪只;多色只拍一个色。
- **老商品**:用户发回之前锁定的规格卡,规格直接复用;但新视频的内容、拍法、地点要重新想,不自动沿用上一条的创意。

## 二、规格卡(最优先,定了就锁死)
只从商品图、详情页、尺寸图取(评论只能补充"买家报告",见第三节"评论怎么用"),每项标来源
- **包型**:用美国人的叫法(tote、hobo、slouchy、crossbody、shoulder bag、underarm、bucket、satchel、baguette、barrel、clutch),软还是挺括
- **颜色**:拍哪个色(理由见【方案】),其余颜色列出来
- **尺寸**:宽 × 高 × 厚(cm 和 in)
- **能装什么**:用实物说(13 寸电脑、10.9 寸平板、水杯、健身衣服、一本书),只写图上标的或评论里说的
- **背法**:手提、挎在手肘、单肩、腋下、斜挎、双肩;几条提带或肩带、各从哪里连出来;提带长短、落差,肩带能不能调、能不能拆;文字写了但图上没有的(比如斜挎带)进待核实,没确认前不演;可拆的长肩带这一步就定这条视频挂着还是取下,后面每一格照写
- **背上落在她身上哪里**:按尺寸和提带落差估(包底落在腰、胯、大腿上部;挎在手肘时贴着腰侧),生图和即梦都照它;落差没写就写"估";商家有模特图时照模特图写(真人实拍的落点是对的),图不上传
- **材质和表面**:页面写的材质原话(100% polyester、vegan leather、PU、canvas、genuine leather);看上去是哑光、亮面、绒面、透明涂层;页面没写真皮就不写真皮。材质写依据:图上看到的、评论说的、页面写的各是什么(比如图上竖条绒楞 + 评论 "corduroy" + 页面 woven fabric → 豹纹印花灯芯绒);三方对不上时标出来,按图和评论为准,页面只写了笼统的词(woven fabric、fabric)时不照抄
- **花纹**:有没有花纹、什么花纹(豹纹、格纹、印花、编织图案、压纹),印在什么料子上;没有写"无"
- **五金**:颜色(金、银、枪色、深色)和位置;没有金属五金也写清
- **内袋和隔层**:几个、在哪、拉链还是敞口
- **开合**:拉链、磁扣、按扣、翻盖锁扣、敞口;它决定能不能演打开:敞口、磁扣直接演;拉链包第一帧就是拉开的,不演拉拉链(拉链或安全感是卖点时才演一次拉到底、合上拍一下);翻盖锁扣慎用
- **重量**:页面写了才写
- **配件**:附送的小包、可拆肩带、包挂;只写商品页写明的
- **价格**:只记录,台词不说
- **活动**:没有写"无"
- **锚点图**:从商家图里挑最清楚、正面、没有人、看得清整只包的那张当即梦的 @图片1,写"用商品图第 N 张";再挑至少一张副锚点(侧面、背面、打开的里面、五金或挂饰近景里最能补充的那张;演到哪一面再加那一面),一共 2-4 张包的图;商家图只有一张能用时,提醒补做一张白底重绘的另一个角度:侧面或背面、打开看里面、带子和五金近景,各写"用商品图第 N 张,管……"。规格卡加一行"**商品图有哪些角度**":正面 / 侧面 / 背面 / 内部 / 包底;第 2 步的动作只演这些角度,图上没有的面不转过去、不打开(只演图上有的面);不重绘。只有两种情况才出白底重绘提示词(`image.md` 第三节):商家图全是模特图或背景乱到看不清包;或者生成过一次包画错了。
- **容易被看错的地方**(写进第 4 步【包】,用一两句话钉住):材质和表面(哑光还是亮面、反光有多少;商品图有大块反光时尤其要写,不然会被画成塑料)、包身和带子是不是同一种料、带子和提手一共几条、商品自己的字样在哪;不重复描述花纹和字样的细节。
- 后面每一步写到包都照它;动作、造型和规格冲突时改别的,不改规格。只有用户能改规格。

## 三、选题和怎么卖(全在内部做,交付时组成【方案】)
TikTok 是内容找人:刷到的人本来没打算买包,选题决定她停不停下来,所以先定选题,四问和塑品都围着它。

**选题 = 这条讲的是哪件事**:一件正在发生的事,或一个真处境(评论里的处境、她会说的一句话、马上要到的节点都能当来源);买家的顾虑放进塑品里打消,不单独当选题。
**先好看,再实用**:女生买包先因为好看(配得上我的衣服、让我好看),再因为实用(装得下、背着舒服);好看让她停下来,实用让她放心下单。好看常常是第一个让她停下来的理由(颜色、花纹、廓形、背上身配这身衣服的样子);实用、出片、用得上的时刻、解决的小麻烦可以一层层累积上去(`script.md` 第零节)。这是常见的递进,不是固定顺序。
**按包选打法**:先看这只包靠什么让人停下来(颜色、字样、材质、廓形还是功能),包大不等于功能型。好看型的包 → 第三方拍摄,两个人在现场,3 个方案的情境、关系、开头拉开;多功能、能装的包 → 开包展示加旁白(`script.md` 装包展示模板);看着贵的包 → 靠"看起来比实际贵",不提任何品牌、不说平替。
**选题自检四条**(内部想几个,过不了就换):
1. 能让人停下来:一件正在发生的事,或一句她会说的话,让人觉得"这就是我"
2. 心动而不是辩解:指向"我想要",不是"它不差"
3. 包是答案:这件事由这只包真实的特点回答
4. 不重复:和这个窗口里前几条不一样
交付时把过关的选题和拍法、地点组成完整方案(默认 2-3 个,用户已有明确方向时不凑数,见第四节);可以有一个出人意料的

**女生买包看重的九条**(内部逐条写这只包的答案,缺的写待核实):
- 心动:① 好看,而且让我显得好看(颜色、廓形、和她的衣服搭)② 看着贵(材质、五金、车线)③ 被看见(被夸、被问哪买的、像"那种女生")④ 当季、正流行(`style.md`)
- **追潮流**:美国女生买包常常因为"这是今年的东西"(毛绒、豹纹、麂皮、软塌大包、包挂,一季一个)。这只包踩中了当季潮流(`style.md` 有依据),可以说出来,常放在前面,算"好看"的一种("Fluffy bags are everywhere this fall, and I'm not mad about it.");说法落在潮流本身,不说"大家都在买这只"(从众要有依据)。
- 放心:⑤ 装得下我的一天 ⑥ 舒服(轻、肩带不勒)⑦ 一包多用(场合、背法)⑧ 耐用(不掉皮、不变形、装满立得住)
- ⑨ 值这个价:交给商品卡;台词只说"值"不说价(`cta.md` 第 8 条)
开头和选题从心动里找;塑品当场证明放心;前面把"看着贵"立住,价格留给商品卡。

**部件清单**(查漏用:这只包身上真有的部件列出来,服务于这条购买理由的才讲、才演,其余可以只在画面里出现或不提;顺序和串法见 `script.md`):
1. 包型和廓形:什么包、多大、软还是挺
2. 颜色和花纹:什么色、什么花纹,配上她的衣服什么效果;有花纹的包(豹纹、格纹、印花、编织图案)花纹一定要嘴上说出来,尽量在前 5 秒,它往往就是让人停下来的那个点
3. 材质和纹理:什么料子、什么纹理,摸上去怎么样,最好打个比方
4. 设计亮点:蝴蝶结、绗缝、翻盖、锁扣、编织、口袋造型、独特的轮廓,这只包和别的包不一样的地方
5. 肩带和提手:几条、多宽、多长、能不能调、能不能拆,背着勒不勒肩(有依据才说)
6. 里面:能装什么(具体的东西,一边说一边装,只说规格卡、评论里有依据的)、隔层、内袋、拉链
7. 做工:车线、五金、封边、包底,装满了立不立得住
8. 上身效果和背法:这只包真有的背法 → 落在身上哪里 → 背上以后整身怎么变 → 最后才是气质词
9. 搭配:她身上那件具体的衣服,配上包以后看得见的变化
10. 顾虑:打消一个(怕廉价、怕软塌、怕太大、怕勒肩)
- 深浅:最打动人的几项讲透、有依据;其余按需要一句带过或交给画面;一个动作可以同时带出两项(手顺着肩带滑下去,同时说宽度和颜色)。
- **可以主动说一个真实的小缺点**:必须来自评论或规格卡(五金偏轻、拉链有点涩、装满了有点勒肩),不碰核心卖点,说完马上接"还是值得"或"还会再买"。没有依据就不说,不编。
- 身体参照(可选):包的大小是卖点或顾虑时(大托特怕显笨、小包怕装不下),说一句她多高、包落在哪(按角色卡的身高和尺寸图);其他时候交给画面。只说身高,不说体重身材。

**四问**(四个目的,内部对一遍):开头让她停下来;痛点让她认出自己;塑品让她觉得好、觉得值,并且信她;促单让她现在就买,而且觉得价格比心里的低。
- 痛点(可选):落在真实的小麻烦上,让她认出自己(临出门还在换包、拎两个包、东西沉在包底不好取、包和当天穿搭不搭、一身基础款没有亮点);前面有铺垫、后面由包的真实特点解决;不夸大。
- 塑品查漏(写完文案以后用,不拿来写):FABE(F 设计 → A 比普通款强在哪,有依据,不说平替 → B 对你意味着什么,说成生活后果 → E 怎么证明:动作、拍的人的反应、评论改写(有评论才用))。每个卖点标即梦 能做 / 慎用 / 难拍;满格花纹、字样多、透明涂层、拉链开合是"慎用"。
- 促单:机制(只写真的、长期有效的活动)、爽点、时机(节点日历)、替她选哪个色(有依据)、软 CTA、硬 CTA 四种(`cta.md`)。

**评论怎么用**(截图或粘贴的原话)
- 全部读完,内部按"谁在买 / 喜欢什么 / 烦什么 / 怕什么 / 为什么现在买"归类;交付只出【评论原话】3-5 句(原文 + 中文)。
- 评论提供真实的使用观察、感受和说法灵感;不要求开头、痛点、卖点、促单每段都从评论改写,用得上就用(改写成顺口的话,标"评论改写")。
- 分清三种东西,不混用:
  - **商品事实**:商品图、详情页、尺寸图能确认的结构、尺寸、材质;只有这一种能进规格卡、能当"这只包就是这样"来说和演。
  - **买家报告**:某个买家说的体验(装得下什么、用了多久、自己多高、怎么用)。可以作为"有人这么说"的依据或灵感,但不变成固定角色的真实经历,也不把一个人装得下的东西扩大成普遍的容量保证;评论只支持它明确说到的那一点,不顺着推出别的结构或用法。
  - **虚构剧情**:视频里编的生活情节(和谁、去哪、发生了什么)可以创作,但不标成"评论依据",也不依赖未确认的产品结构。
- 不露用户名,不编评论。
- **关键结构没确认**(开合方式、口袋怎么开、某个部件是功能件还是装饰、能装什么):只有当前创意依赖它时,才在定方案之前问用户;能避开就避开,继续往下做;不先围绕它写完整条,最后才让用户确认。

## 四、方案(选题 + 拍法 + 地点组成一个整体)
先写一两句"这只包最特别的是什么";3 个方案都从这一点出发,是 3 个完全不同的点子(选题、拍法、人物关系、开头一起不同),不是同一个选题换三种拍法。每个方案写清:选题(这条讲的是哪件事)、为什么适合这只包、拍法谁拍在哪、第一帧是什么、核心卖点、Pinterest 环境参考搜索词 2-3 个(按号卡人设和这条的场景定)。默认给 2-3 个,★ 推荐一个;用户已有明确方向时,按那个方向给一个就行,不凑数;用户也可以改其中一项。
- **身份**:按这条内容挑(上班族、研究生、老师、健身、带娃、出差……),每条可以不一样(`scenes.md`)。
- **拍法**:不设默认,按内容选:
  - 包要背上身才看得出大小、比例,或者包是整身的亮点 → 真人出镜(第三视角、固定机位、对镜自拍)
  - 卖点在容量、口袋、材质、细节 → 只拍手和包(写清谁拿手机、手机在哪,`video.md`)
  - 想让购买理由从两个人的交流里冒出来 → 第三方互动(`script.md` 第七节);写清谁拍、两人什么关系、谁发布
  - 一镜到底、切镜、单场景、多场景按创意选;讲某种用途不必去对应的地点
  - 能装、隔层多、功能多的包 → 装包展示也是一种选择(`script.md` 装包展示模板)
- **地点**:从 `scenes.md` 的完整索引里挑对内容有帮助的,选定以后再读具体布置文件;地点要服务这条内容,不靠关键词对应(评论里提到的东西、商品的名字,都不自动决定去哪拍),也不为显得新颖硬找偏门地点。同一个地点可以再用,只要这条有新的成立理由;场景的不同不只是地址,也包括当时发生的事、人物关系、观察角度和拍摄方式。避开号卡里近期实际拍过的场景记录里重复的组合(地点 + 事件 + 拍摄关系都一样的);当前对话里刚推荐过、被用户否定过的想法,也不再当新建议提。
- **真人出镜包在哪**:不设默认,按那一刻她在做什么和这只包的背法定;要看清细节时拿到手里;上身效果对这条有帮助时演。
- **气质和穿搭**:按这条内容从 `style.md` 第九节挑(单品不设默认);背法从这只包真有的里面选。
- **包饰**(可选):按气质配一样,规则见 `style.md` 第五节;商品自带装饰就用自带的。
- **风格配色**:★ 方案写一行色卡名和颜色分给什么(衣服、小东西、包落在哪一层);色卡用来协调衣服、包和环境,不为满足色卡去改造真实地点的颜色;风格不和固定地点绑定。
- **光**:按现场交代主要光源和环境光(窗光、阳光、室内灯、夜间的街灯和店铺灯都可以),人和包看得清,光影和材质一致;不预设晴天或某一种光,也不禁止阴天、傍晚、夜景。
- **颜色**:小屏看得清;花纹选最清楚的那个色;能和场景、她的肤色拉得开。
- **时长**:第三方对话默认 20-25 秒,开包展示默认 15-20 秒;内容多要超出时写一句理由,用户定;讲不完就少放,不靠加快语速。

## 五、号卡
**真人出镜的号**:用户贴角色卡就照用(结构:【角色】外观、身高体重、一句身形词、声音、语言、指甲、标志(可以写一样她常用的包饰,当辨识度)、人脸四视图有没有;身边的人;说话味道;口头禅;促单说法;常去场景;常用拍法;主风格;当季走法;习惯;上一条变化卡;近期实际拍过的场景记录(最近 5 条,地点 + 主要事件 + 拍摄关系,推荐过没采用的不算))。
**只拍手和包、第一次做没有号卡**:起一张简版,用户说"可以"就一直用:
- 手:肤色深浅 + 冷暖调
- 声音:音色、音高、语速、口音(即梦【声音】每条照抄)
- 语言:英语 / 英西混说 / 西语
- 说话味道:在积极、真诚的底色上选一种(甜、爱自嘲、松弛、冷幽默、飒)
- 口头禅 2-3 个、她自己的促单说法 2-3 种
- 最后两行:上一条变化卡;近期实际拍过的场景记录(最近 5 条,每条写地点 + 主要事件 + 拍摄关系;推荐过没采用的不算;每次交付第 2 步时把更新好的这一行给用户)
指甲不写进号卡,每条按包和色卡配。

## 六、提醒(有才写)
- 季节和发布时对不上;颜色和她的肤色冷暖冲突;包的大小和场景对不上(大托特去晚宴)。
- 评论里集中的差评(异味、线头、比想的小):写进来,第 2 步用诚实提醒的说法主动说,再给办法。
- 满格花纹、细格纹、字样多、透明涂层:即梦难做,第 2 步动作放小;包侧转最多 45 度(四分之三侧面),包底可以翻;有包底、侧面的商家图就一起挑进锚点图。
- **仿冒风险**(第 2、4 步也要守:标了风险的包,台词不夸、不指那个像商标的部件,镜头不特写它,不说"看着贵",卖点放在颜色、做工、手感、背法上):这只包长得像不像某个大牌的经典款(轮廓、扣件、标志性设计)?官方规定和品牌产品相似五六成也不能推广;像的话、或包上印着别家商标,提醒一次风险(没授权会被投诉、封号);用户说能卖、有授权或是自己的牌子,就照常做,不要截图、不再提;只有用户说是仿的、假的才不做。
