# 美区生活场景参考库
遵循 SKILL.md。先选实际房间与使用情境，再选布置、光线和少量物件。风格不等于族裔、收入、信仰或家庭结构。下面各项独立可选，不整套机械粘贴。

## 1. 房间骨架
| 空间 | 可用骨架 | 与产品相关时可加的生活细节 |
|---|---|---|
| 厨房 | 橱柜、台面、灶台；小公寓或带中岛布局 | 切菜板、杯子、抹布、实际用到的食材 |
| 客厅 | 沙发、茶几、边柜、窗户 | 一本书、遥控器、随手搭的毯子 |
| 餐厅 | 餐桌椅、吊灯、边柜 | 餐垫、餐具、水杯 |
| 卧室 | 床、床头柜、衣柜或梳妆镜 | 充电线、搭好的衣物、日常用品 |
| 浴室 | 洗手台、镜子、淋浴区 | 牙刷杯、毛巾、实际用到的护理品 |
| 洗衣房 | 洗衣机、收纳架、晾衣空间 | 洗衣篮、待叠衣物、洗衣用品 |
| 车库 | 工具台、储物架、停车空间 | 本片工具、收纳箱、自行车 |
| 后院/门廊 | 户外座椅、围栏、遮阳或门口空间 | 盆栽、水壶、按情境使用的烤炉 |

## 2. 独立选择视觉风格
- 中性简约：白灰米色、原木、简洁线条、适量留白。
- 暖色装饰：暖米或陶土色、彩色织物、陶瓷、木质细节；可以很整洁，不自动加入宗教或节庆物件。
- 其他：按用户参考选择复古、现代、小户型等，不受两种风格限制。
光线跟时段和窗位走，晴天、阴天、夜间室内光都可；保持手机拍摄质感。生活痕迹少量且相关，不强制脏乱或固定数量。

## 3. 可选文化、家庭与节庆元素
仅在用户明确指定、实拍参考中出现，或已确认创意需要时选用。不能因肤色、语言或暖色布置自动加入。
- 文化工艺：Talavera花砖、手绘陶器、serape织物等，各自单选，不绑定整套家居。
- 烹饪元素：comal烙盘、molcajete石臼或具体食材，按实际菜品与产品用途选择，不推断居住者身份。
- 宗教陈设：圣像、念珠、十字架等，仅按明确参考或已确认设定放置，不作为普通暖色装饰默认项。
- 家庭元素：家庭照片、儿童用品、多人餐位，按已知家庭情境选择；不从族裔推断多代同堂。
- 节庆/人生仪式：圣诞、万圣节、亡灵节、Las Posadas、Quinceañera等，按明确活动选；不把人生仪式当年度节日，不将节庆绑定风格。涉及具体日期、习俗或热点时另行核对，不默认当前正在发生。
- 品牌与包装：产品本身继承实拍。背景品牌只在参考或创意确需时出现，其余使用通用物件，避免抢产品注意力。
