# 第4步：完整文案（文件名保留历史兼容）
遵循 [SKILL.md](SKILL.md)。本步从选定钩子展开，不在这里排全片分镜。

## 输入与确认
读取当前本片记录、产品依据、选题、拍法和选定钩子。默认钩子未选定就返回第3步；用户已提供明确钩子可直接沿用。用户授权整套时，可自行选方向继续工作稿，明确尚未逐项确认。
按品类、语言、拍法检索 voice-samples.md，只读相关样本及使用边界，标明实际参考编号。该文件约1500行，不整份读入：先读开头约50行的使用边界与品类速查，再按样本标题 `### 编号 [品类]` 搜索定位（如 `grep -n "^### .*厨房" voice-samples.md`，西语样本搜 `西语`），只读命中样本到下一个 `###` 为止。借结构和语气，不抄经历、价格、测试、促销；没有匹配样本可交探索稿。

## 写作
1. 从商品事实及来源推导用户收益，安排对应展示。对“牢固、能装、方便”等表达给出具体支撑，不能用AI图像证明承重、降噪、疗效、长期效果或实际穿着体验。
2. 按选题选择结构，不默认限制一个卖点：
   - 一个主卖点＋多个证明：不同细节、场景或真实材料共同支撑一个购买理由，逐层给信息，避免换词重复。
   - 多个卖点＋各自证明：每个卖点有对应依据和展示支撑，围绕同一使用需求或选题串联，不堆无关功能。
3. 保留已选钩子原文。正文兑现开场预期，中间持续给具体细节和小答案；不拖简单答案。需要改钩子先作为明确改动提出，不静默替换。
4. 留自然可复述的核心表达，不强押韵或塞价格。关键顾虑才回应，不编缺点；一个主要购买行动，通常在价值成立后，不固定尾3秒。
5. 台词用目标市场语言，读起来顺口；去空话和机械排比，允许自然口头语及合理重复。虚构人物不冒充真实买家，不编购买或长期使用经历；人物尺寸不是商品选码实测。

## 输出顺序
1. 完整目标语言连读台词；多人对白标明说话人，无镜头、机位和时间轴插入。
2. 简短说明结构选择、各卖点对应的依据与证明方式、实际借鉴的样本编号。证明方式只是意图，不展开分镜。
3. 词/字数、预计朗读时长及估算依据、必要停顿；不是实际音频计时。总时长和模型单次生成时长分开，避免靠过快语速硬塞。
4. 当前版本、关键待核实项与检查结论。默认等待全文确认，再进入第5步；整套授权下可继续，标工作稿。
无口播任务交完整视觉叙事与必要贴片，不强写口播。

## 检查
钩子一致、兑现清楚、卖点各有支撑、细节不跑题、口吻自然、事实有依据、关键顾虑已处理或不适用、时长合理、CTA清楚。发现问题局部修正，不打主观分或预测爆单。
