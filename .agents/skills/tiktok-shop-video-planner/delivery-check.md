# 交付检查：给出证据，不打主观分
遵循 SKILL.md。按当前交付阶段检查，不要求脚本阶段先通过成片检查。内部逐项看，交付时简述关键证据与问题，不机械输出长表。

| 检查项 | 判断方法与所需证据 | 不通过时的局部修正 |
|---|---|---|
| 商品分析展示 | 新产品是否可定位到已交付的事实与来源、卖点、痛点/动机、场景、展示细节、待核实项；不得仅用内部思考或一句概括代替 | 先补齐分析交付；默认停止等待继续，不附钩子或全文 |
| 阶段与授权 | 默认已展示商品分析且用户要求继续才出方向与钩子，已选钩子才写全文、已确认全文才写分镜；整套授权工作稿不能冒称已确认，按实际用户要求判断 | 返回缺失阶段或恢复当前稿，不补造确认记录 |
| 钩子交付格式 | 钩子候选仅编号、原文、中文对照及可选短标题；内部检查事实与可兑现性，不逐条展示画面、观看预期或正文兑现说明 | 删除多余说明，画面留到第5步；用户明确要求解释时才补充 |
| 台词与素材绑定 | 分镜/执行稿对白逐句对应当前文案；图号存在且用途明确，区分计划编号与实际上传编号；2.0/2.5分别标能力状态 | 补漏词、恢复原文、修正映射或标待绑定/待适配 |
| 观看理由与兑现 | 指出开场具体句子/画面，以及正文兑现的句子或时间段；无谜题的结果展示指出吸引点和后续增量 | 改模糊开场、补真实兑现或删拖延段 |
| 购买理由 | 按所选单主卖点或多卖点结构，逐项引用收益句和相关产品依据，说明展示细节如何支撑它；核心形容词与功能声称是否对应具体展示和可信依据，AI示意不得作为实测证据 | 删除跑题或无支撑卖点，补依据或收窄承诺 |
| 可复述表达 | 指出观众可以复述的实际一句；不是“好用、高级”等空词，且不捏造价格/效果 | 改成具体收益表达，不强写金句 |
| 台词自然 | 指出拗口、书面、重复空转的具体句子及修改；无明显问题可举代表句说明口吻，不凭“真人感强”打勾 | 改该句，不因不喜欢整份重写 |
| 事实与顾虑 | 事实性声称能对到状态卡来源；未知项省略或标注；关键顾虑引用回应句/镜头，无关键顾虑标不适用 | 核实、删承诺或改成不越界表达 |
| 时长与动作 | 各段台词字/词数、预计朗读时间及动作安排是否装得下；说明是估算还是实际音频计时，不能伪称实测 | 缩句、减动作或调整时长；可同时发生的不机械相加 |
| 版本一致 | 状态卡当前版本对应交付稿；用户改过的句子、图号、人物与场景引用已同步 | 更新受影响部分，旧稿标被替代 |
| 生成设计 | 产品、人物、空间参考可定位，动作与运镜不冲突；模型适配单列核验状态 | 补参考或简化动作，不冒充成片验收 |
| 成片质量 | 只有拿到图/视频才查产品形状标签、人物身份、手部接触、空间、音画同步，指出具体图或时码 | 修对应图/片段；未拿到写待生成后检查 |
| 主要购买行动 | 指出具体CTA句/贴片和出现位置，与用户目标一致；探索开场阶段可不适用 | 补明确行动或移到价值成立的位置 |

状态仅用：通过（附依据）、需修改（具体位置与动作）、待验证（缺什么）、不适用（原因）。没有证据不写“全部通过”。
脚本或提示词设计通过可以交付，不因尚未生成卡住前期工作；成片未查看不得称“可直接发布”。事实性占位与关键未知项发布前需核实或移除。检查发现局部缺陷只修对应部分，效果优劣仍由实际测试验证。
