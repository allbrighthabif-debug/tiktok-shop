# 本片状态（轻量记录）
遵循 [SKILL.md](SKILL.md)。默认在当前对话维护，用户要求保存作品时才另存；不覆盖本模板，不建素材资产库，不把未来字段变成问卷。

## 只记录当前已知项
- 本片ID、当前阶段、当前版本、用户授权推进范围。
- 商品分析交付位置/版本、是否已展示、用户是否要求继续；无记录不假称已看过。
- 产品事实与来源；痛点/收益、使用场景、展示细节；创作假设与待核实项分开。
- 选题、拍法/主视角/说话关系、目标语言与全片时长；结构为单主卖点多证明或多卖点各自证明。
- 即梦版本（2.0/2.5）、入口、模式、单次时长及能力核验状态；OpenAI生图入口按需记。
- 钩子候选、选定编号与原文、版本、确认状态；不要求钩子交付附画面、观看预期或兑现说明。
- 完整当前文案或可定位消息/文件、版本、确认状态与时长估算。
- 分镜版本、引用的文案版本、分段安排。
- 本条图片用途与计划编号、实际文件/用户图位置、视觉检查状态、上传编号映射；没有实图则明确待生成/待绑定。
- 即梦执行稿/成片/发布包的位置及其引用版本；缺项留空。
- 本次修改、受影响产物、已同步或待同步事项。

## 推进与更新
状态区分工作稿、已确认、待核实、待同步。新产品先完整展示商品分析，默认停止等待用户要求继续，再定方向与出钩子；整套授权仍先展示分析。用户选钩子后才默认写全文，确认全文后才默认做分镜；整套授权可继续工作稿但不假称确认。用户提供已定稿时直接接入，不强制重走上游。
每步先核对当前记录与必需输入，交付后同步。未变内容不反复展示，通常简述当前阶段和待处理项。
用户修改以最新要求为准，只同步影响部分：
- 产品事实/卖点变化 → 检查钩子、文案、分镜、图和发布包。
- 钩子变化 → 检查正文兑现、开场画面与时间安排。
- 文案变化 → 检查朗读时长、分镜及执行稿对白；默认修订文案仍需确认后推进。
- 人物/场景/图变化 → 检查画面与引用；不因此擅改台词。
- 版本/模式变化 → 重新核验素材限制、分段与执行设置，不自动改写创意。
- 标题/标签变化 → 通常不回改文案。
旧产物标被替代或待同步；用户要求暂停同步就记录待同步。上下文缺失先恢复可定位稿，无法确定才问缺项，不凭记忆声称已确认。
