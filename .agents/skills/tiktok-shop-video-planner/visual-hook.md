# 第5步：开场画面设计
遵循 SKILL.md。在完整文案确认后的分镜阶段读取，不用于第3步钩子文案交付。第3步只展示钩子原文与中文对照，不附本文件的画面或分析。

开场画面配合已选台词，不另造不相关噱头。可用产品近景、结果先行、前后差异、进行中的动作、局部揭晓、问题现场、后期大字、当场演示、情境悬念等；类别开放。
破圈可依靠产品奇观或情境共鸣，不必隐藏产品。静态画面有吸引力就不硬加运镜；避免无信息空镜、自我介绍或站好才开始。

内部检查：第一眼为什么停下、预期是否具体、正文是否兑现、信息量和等待是否匹配、脱离标题是否成立。除非用户要求，不单独输出“观看预期/正文兑现”说明。
把开场安排直接并入第5步分镜：[时间区间][主视角][机位][画面与动作][已确认台词]，必要时标后期贴片，不额外交付一套开场分析表。
英语贴片默认每屏≤8词，其他语言按阅读负担调整。生成底图默认无后期贴片。运镜细则见 step7-storyboard.md，生图提示词留第6步 image.md。
用户修改钩子时检查正文兑现及已有分镜，按当前授权同步，不擅改确认台词。
