# 第6步：OpenAI 生图与改图提示词
遵循 [SKILL.md](SKILL.md)。从第5步本条参考图需求出发，只补缺图；默认交提示词，不因写了提示词就称图片已生成。用户明确要求实际生成时按可用工具执行。

## 先识别入口和用途
区分 ChatGPT 生图、当前可用生图工具与 OpenAI API；提示词可表达共同意图，参数只使用实际入口支持项。用户指定其他工具时按其规则适配，不混用参数。
每张图标用途：首帧/尾帧、人物身份、商品外观、场景或风格参考。9:16是本片构图需求，不是对所有模型原生尺寸的保证；确切尺寸及输出格式单列核验，见 model-capabilities.md。

## 可粘贴提示词
先说明产物及用途，再写主体、构图、场景光线、关键细节和保持项。可使用自然段或 Scene / Subject / Details / Constraints，不把格式当特殊语法。
- 引用图按编号分配作用：哪张提供商品、人物、服装或背景；明确组合关系及不可引入的元素。没有参考图不编图号或声称已锁定身份。
- 商品结构、数量、标签和比例以实拍为准；看不清的关键细节不脑补。有文字须给准确内容、位置和必要排版，生成后逐字检查。底图默认不带后期贴片，不额外添加logo或水印。
- UGC明确要求真实照片、生活手机拍摄质感，描述实际光线、自然肤质和构图；避免仅堆8k、masterpiece等词。catalog按需要用棚拍，不把UGC风格套到商详。
- 人物写可见范围、视线、动作和与商品的接触关系；按需读 character.md。场景按需读 scenes.md，跨图保留布局与光向。手部关节、接触及裁切合理，不强求全部手指完整入镜。
- 单张图描述一个可见状态；连续动作和甩镜时间进程留给视频提示词。用于视频的图应与分镜起始状态相容。

## 改图与一致性
先查看目标图。写清 Change only… 与 Keep…，包括身份、商品几何、标签、服装、构图、光线及背景中的必要保持项。
独立姿势/场景变体可从干净锚图分支；局部修正可以上一张已验收结果继续编辑，每次复核漂移。不要把“避免连续加工”变成禁止多轮编辑。若必须像素级不变，单靠提示词不能保证，应采用入口支持的局部编辑/合成方法并检查结果。
正常成年试穿或时尚展示按实际内容描述，不用换词规避内容限制。

## 交付与检查
交付图片数量与每张用途、输入参考映射、每张提示词；API参数另列，不夹入自然语言当作已设置。实际参数缺核验就不承诺。
拿到图后检查商品细节与标签、身份、空间、手部和构图，指出具体问题；未拿到只报告提示词设计检查。合格图交给第7步绑定实际素材编号，不建立素材资产库。
更新 video-state.md 本条图的计划编号、实际位置和检查状态；按 delivery-check.md 检查。
